# [Class 9] General - Chapter 103: Coordinate Geometry ( निर्देशांक ज्यामिति)

## 🌟 Core Concepts (मुख्य अवधारणाएँ) 📊

1.  **Introduction (परिचय):**
    *   Kisi point ya object ki position plane mein batane ki zaroorat. (Need to describe the position of a point/object in a plane).
    *   Ek reference point (like number line) kaafi nahi hai plane mein. (One reference point isn't enough in a plane).
    *   Example: Street aur House number (Fig 3.1), Dot on paper (Fig 3.2). Dono examples mein location fix karne ke liye do information chahiye. (Both examples need two pieces of information to fix a location).

2.  **Cartesian System (कार्तीय पद्धति):**
    *   Developed by René Descartes. Isliye ise Cartesian System kehte hain.
    *   **Coordinate Axes (निर्देशांक अक्ष):**
        *   Do perpendicular lines (दो लंबवत रेखाएँ): Horizontal line (X'X) ko **x-axis** (x-अक्ष) aur Vertical line (Y'Y) ko **y-axis** (y-अक्ष) kehte hain.
        *   **Origin (मूलबिंदु):** Jahaan dono axes intersect karte hain (O). Coordinates: (0, 0).
        *   Positive Directions: OX (right) aur OY (up).
        *   Negative Directions: OX' (left) aur OY' (down).
    *   **Coordinate Plane (निर्देशांक तल):** The plane containing the axes (xy-plane or Cartesian plane).
    *   **Quadrants (चतुर्थांश):** Axes plane ko 4 parts mein divide karte hain:
        *   Quadrant I (+, +)
        *   Quadrant II (–, +)
        *   Quadrant III (–, –)
        *   Quadrant IV (+, –) (Anticlockwise direction mein numbering).

3.  **Coordinates of a Point (बिंदु के निर्देशांक):**
    *   Kisi bhi point P ki position (x, y) se represent hoti hai. Yeh ek **ordered pair** (क्रमित युग्म) hai.
    *   **x-coordinate (x-निर्देशांक) or Abscissa (भुज):** Point ka perpendicular distance y-axis se (x-axis ke along measure kiya gaya). Positive agar OX direction mein, negative agar OX' direction mein.
    *   **y-coordinate (y-निर्देशांक) or Ordinate (कोटि):** Point ka perpendicular distance x-axis se (y-axis ke along measure kiya gaya). Positive agar OY direction mein, negative agar OY' direction mein.
    *   Convention: Hamesha (x, y) likhte hain, pehle x-coordinate, phir y-coordinate. Example: (4, 3) is different from (3, 4).

## 📘 Key Learnings (मुख्य बातें) 📈

*   **Kisi Point ki Position Locate Karna:** Plane mein kisi point ki exact location batane ke liye humein do perpendicular lines (axes) ke reference mein uski distances batani hoti hain.
    *   Example (Fig 3.10): Point P ke liye, y-axis se distance (PN = OM) 4 units hai (yeh x-coordinate hai) aur x-axis se distance (PM = ON) 3 units hai (yeh y-coordinate hai). Toh P ke coordinates hue (4, 3).
    *   Point Q ke liye, y-axis se distance (OR = SQ) 6 units hai lekin negative x-direction mein, toh x-coordinate -6 hai. Aur x-axis se distance (OS = RQ) 2 units hai lekin negative y-direction mein, toh y-coordinate -2 hai. Toh Q ke coordinates hue (–6, –2).

*   **Signs in Quadrants (चतुर्थांशों में चिह्न):**
    *   Agar point First Quadrant (I) mein hai, toh dono coordinates positive honge (+, +). Example: (4, 3).
    *   Agar point Second Quadrant (II) mein hai, toh x negative, y positive hoga (–, +). Example: (–3, 4).
    *   Agar point Third Quadrant (III) mein hai, toh dono coordinates negative honge (–, –). Example: (–5, –4).
    *   Agar point Fourth Quadrant (IV) mein hai, toh x positive, y negative hoga (+, –). Example: (3, –4).
    (Refer Fig 3.13)

*   **Points on Axes (अक्षों पर बिंदु):**
    *   **x-axis par koi bhi point:** Uska y-coordinate hamesha 0 hoga. Coordinates honge (x, 0). Example: Point A (4, 0) in Fig 3.12.
    *   **y-axis par koi bhi point:** Uska x-coordinate hamesha 0 hoga. Coordinates honge (0, y). Example: Point B (0, 3) in Fig 3.12.
    *   **Origin (मूलबिंदु):** Iske coordinates (0, 0) hote hain kyunki yeh dono axes se zero distance par hai.

*   **Diagram Interpretation (आरेख समझना):** Diye gaye diagram (like Fig 3.11, Fig 3.14) se points ke coordinates (abscissa aur ordinate) pehchanna aur likhna. Ya diye gaye coordinates se point ko diagram mein identify karna.
