# [कक्षा 9] सामान्य - अध्याय 4: दो चरों वाले रैखिक समीकरण

## 🌟 मुख्य अवधारणाएँ (Core Concepts)
विस्तृत अवधारणा पदानुक्रम 📊

1.  **रैखिक समीकरण (Linear Equation):**
    *   **एक चर वाला रैखिक समीकरण (Linear Equation in One Variable):**
        *   रूप: `ax + b = 0`, जहाँ a ≠ 0.
        *   हल: अद्वितीय (केवल एक) हल होता है। (उदाहरण: 2x + 5 = 0 का हल x = -5/2 है)।
        *   निरूपण: संख्या रेखा पर दर्शाया जा सकता है।
    *   **दो चरों वाला रैखिक समीकरण (Linear Equation in Two Variables):**
        *   **परिभाषा:** कोई भी समीकरण जिसे `ax + by + c = 0` के रूप में लिखा जा सकता है, जहाँ a, b और c वास्तविक संख्याएँ हैं, और a और b दोनों शून्य नहीं हैं।
        *   **चर (Variables):** सामान्यतः x और y से दर्शाए जाते हैं, लेकिन अन्य अक्षरों का भी उपयोग किया जा सकता है (जैसे s, t, p, q, u, v)।
        *   **हल (Solution):** चरों (x, y) के मानों का एक युग्म जो समीकरण को संतुष्ट करता है। इसे क्रमित युग्म (ordered pair) (x, y) के रूप में लिखा जाता है।
        *   **हलों की संख्या:** अपरिमित रूप से अनेक हल (Infinitely many solutions) होते हैं।

2.  **मानक रूप (Standard Form):**
    *   दो चरों वाले रैखिक समीकरण का मानक रूप `ax + by + c = 0` है।
    *   दिए गए समीकरण को मानक रूप में बदलना और a, b, c के मान ज्ञात करना।

## 📘 प्रमुख सीख (Key Learnings)
विस्तृत व्याख्याएँ उदाहरणों सहित 📈

**1. दो चरों वाले रैखिक समीकरण को पहचानना और लिखना:**
*   **परिभाषा:** वह समीकरण जिसे `ax + by + c = 0` के रूप में व्यक्त किया जा सके, जहाँ a, b, c वास्तविक संख्याएँ हैं और a और b दोनों एक साथ शून्य नहीं हैं, दो चरों वाला रैखिक समीकरण कहलाता है।
*   **उदाहरण:**
    *   भारत और श्रीलंका के बीच नागपुर में खेले गए एक दिवसीय क्रिकेट मैच में, दो भारतीय बल्लेबाजों ने मिलकर 176 रन बनाए। यदि एक बल्लेबाज के रन x और दूसरे के y हों, तो समीकरण होगा: `x + y = 176`। इसे मानक रूप में `x + y - 176 = 0` लिख सकते हैं। यहाँ a = 1, b = 1, c = -176 है।
    *   अन्य उदाहरण: `1.2s + 3t = 5`, `p + 4q = 7`, `πu + 5v = 9`, `3 = 2x – 7y`।
*   **मानक रूप में बदलना (उदाहरण 1):**
    *   `2x + 3y = 4.37` को `2x + 3y - 4.37 = 0` लिखा जा सकता है। यहाँ a = 2, b = 3, c = -4.37।
    *   `x – 4 = 3y` को `x - 3y - 4 = 0` लिखा जा सकता है। यहाँ a = 1, b = -3, c = -4।
    *   `4 = 5x – 3y` को `5x - 3y - 4 = 0` लिखा जा सकता है। यहाँ a = 5, b = -3, c = -4।
    *   `2x = y` को `2x - y + 0 = 0` लिखा जा सकता है। यहाँ a = 2, b = -1, c = 0।
*   **एक चर वाले समीकरण को दो चरों वाले समीकरण के रूप में लिखना (उदाहरण 2):**
    *   `x = -5` को `1.x + 0.y + 5 = 0` लिखा जा सकता है।
    *   `y = 2` को `0.x + 1.y - 2 = 0` लिखा जा सकता है।
    *   `2x = 3` को `2x + 0.y - 3 = 0` लिखा जा सकता है।
    *   `5y = 2` को `0.x + 5y - 2 = 0` लिखा जा सकता है।

**2. दो चरों वाले रैखिक समीकरण का हल ज्ञात करना:**
*   **हल का अर्थ:** x और y का एक ऐसा युग्म (x, y) जो दिए गए समीकरण को संतुष्ट करता है।
*   **उदाहरण:** समीकरण `2x + 3y = 12` पर विचार करें।
    *   `(3, 2)` एक हल है, क्योंकि `2(3) + 3(2) = 6 + 6 = 12`।
    *   `(0, 4)` एक हल है, क्योंकि `2(0) + 3(4) = 0 + 12 = 12`।
    *   `(6, 0)` एक हल है, क्योंकि `2(6) + 3(0) = 12 + 0 = 12`।
    *   `(1, 4)` हल नहीं है, क्योंकि `2(1) + 3(4) = 2 + 12 = 14 ≠ 12`।
*   **अपरिमित हल:** दो चरों वाले रैखिक समीकरण के अपरिमित रूप से अनेक हल होते हैं। हम एक चर (जैसे x) का कोई भी मान चुनकर दूसरे चर (y) का संगत मान ज्ञात कर सकते हैं।
    *   `2x + 3y = 12` में, यदि `x = 2` लें, तो `2(2) + 3y = 12` => `4 + 3y = 12` => `3y = 8` => `y = 8/3`। अतः `(2, 8/3)` भी एक हल है।
    *   यदि `x = -5` लें, तो `2(-5) + 3y = 12` => `-10 + 3y = 12` => `3y = 22` => `y = 22/3`। अतः `(-5, 22/3)` भी एक हल है।
*   **हल ज्ञात करने का आसान तरीका:**
    *   `x = 0` रखकर y का मान ज्ञात करें।
    *   `y = 0` रखकर x का मान ज्ञात करें।
    *   x या y का कोई अन्य सुविधाजनक मान (जैसे 1, 2, -1) रखकर दूसरे चर का मान ज्ञात करें।

**उदाहरण 3: समीकरण `x + 2y = 6` के चार हल ज्ञात करना:**
1.  `x = 0` रखने पर, `2y = 6` => `y = 3`। हल: `(0, 3)`।
2.  `y = 0` रखने पर, `x = 6`। हल: `(6, 0)`।
3.  `x = 2` रखने पर, `2 + 2y = 6` => `2y = 4` => `y = 2`। हल: `(2, 2)`।
4.  `y = 1` रखने पर, `x + 2(1) = 6` => `x + 2 = 6` => `x = 4`। हल: `(4, 1)`।

**उदाहरण 4: निम्नलिखित समीकरणों के दो हल ज्ञात करना:**
(i) `4x + 3y = 12`
    *   `x = 0` => `3y = 12` => `y = 4`। हल: `(0, 4)`।
    *   `y = 0` => `4x = 12` => `x = 3`। हल: `(3, 0)`।
(ii) `2x + 5y = 0`
    *   `x = 0` => `5y = 0` => `y = 0`। हल: `(0, 0)`।
    *   `x = 5` (कोई अन्य मान) => `2(5) + 5y = 0` => `10 + 5y = 0` => `5y = -10` => `y = -2`। हल: `(5, -2)`। (पाठ्यपुस्तक में `x=1` लेकर `(1, -2/5)` ज्ञात किया गया है)।
(iii) `3y + 4 = 0` (इसे `0.x + 3y + 4 = 0` लिख सकते हैं)
    *   यहाँ `3y = -4` => `y = -4/3`। x के किसी भी मान के लिए y का मान `-4/3` ही रहेगा।
    *   हल: `(0, -4/3)`, `(1, -4/3)`।

## 🧩 सक्रिय अधिगम (Active Learning)

*   **गतिविधि: अनुसंधान-आधारित केस स्टडी विश्लेषण 🔍**
    *   **कार्य:** अपने दैनिक जीवन से 3 स्थितियाँ खोजें जहाँ दो मात्राएँ एक रैखिक संबंध बनाती हों। उदाहरण के लिए:
        1.  कुछ निश्चित संख्या में पेन और नोटबुक खरीदने की कुल लागत (मान लें एक पेन ₹5 का और नोटबुक ₹20 की है, और कुल खर्च ₹100 है)।
        2.  एक टैक्सी का किराया जिसमें एक निश्चित न्यूनतम किराया और प्रति किलोमीटर एक अतिरिक्त शुल्क शामिल है।
        3.  दो अलग-अलग प्रकार के पौधों को लगाने के लिए आवश्यक कुल क्षेत्रफल।
    *   **विश्लेषण:** प्रत्येक स्थिति के लिए, चरों को परिभाषित करें (जैसे, पेन की संख्या = x, नोटबुक की संख्या = y) और स्थिति को दर्शाने वाला दो चरों वाला रैखिक समीकरण बनाएँ (`5x + 20y = 100`)। प्रत्येक समीकरण के कम से कम दो संभावित हल ज्ञात करें और व्याख्या करें कि उन हलों का वास्तविक स्थिति में क्या अर्थ है।

*   **चर्चा: वास्तविक दुनिया के प्रभावों का आलोचनात्मक विश्लेषण 🌍**
    *   **प्रश्न:** कक्षा में चर्चा करें कि दो चरों वाले रैखिक समीकरणों के अपरिमित हल क्यों होते हैं? क्रिकेट वाले उदाहरण (`x + y = 176`) का उपयोग करते हुए, चर्चा करें कि कितने अलग-अलग स्कोर संयोजन संभव हैं? क्या सभी गणितीय हल व्यावहारिक रूप से संभव हैं (जैसे, क्या कोई बल्लेबाज ऋणात्मक रन बना सकता है)?
    *   **विश्लेषण:** इस बात पर विचार करें कि वास्तविक दुनिया की बाधाएँ (जैसे रनों का गैर-ऋणात्मक होना, वस्तुओं की संख्या का पूर्णांक होना) गणितीय हलों के सेट को कैसे सीमित कर सकती हैं। विश्लेषण करें कि समीकरण वास्तविक दुनिया की स्थिति का 'मॉडल' कैसे बनाते हैं।

## 📝 मूल्यांकन तैयारी (Assessment Prep)
केस स्टडी और उदाहरण 📝

**अभ्यास के लिए प्रश्न:**

1.  **मानक रूप और गुणांक:** निम्नलिखित समीकरणों को `ax + by + c = 0` के रूप में लिखें और प्रत्येक स्थिति में a, b और c के मान बताएँ:
    *   `3x = 2y - 5`
    *   `y/2 - x/3 = 1`
    *   `7y = 3`
    *   `x = -8`
2.  **समीकरण बनाना:** एक पिता की आयु उसके पुत्र की आयु के तीन गुने से 5 वर्ष अधिक है। यदि पिता की आयु y वर्ष और पुत्र की आयु x वर्ष है, तो इस कथन को दर्शाने वाला दो चरों वाला रैखिक समीकरण लिखें।
3.  **हल ज्ञात करना:** समीकरण `2x - y = 5` के चार अलग-अलग हल ज्ञात करें।
4.  **हल की जाँच करना:** जाँच करें कि निम्नलिखित में से कौन-कौन समीकरण `x - 3y = 7` के हल हैं:
    *   `(1, -2)`
    *   `(7, 0)`
    *   `(10, 1)`
    *   `(4, -1)`
5.  **अज्ञात स्थिरांक ज्ञात करना:** यदि `x = -1`, `y = 2` समीकरण `3x + ky = 7` का एक हल है, तो k का मान ज्ञात करें।

## 🌏 भारतीय संदर्भ (Bharatiya Context)
राष्ट्रीय आर्थिक/सामाजिक डेटा 📊

1.  **क्रिकेट स्कोर उदाहरण:** जैसा कि पाठ में दिया गया है, भारत-श्रीलंका मैच में दो बल्लेबाजों द्वारा बनाए गए कुल 176 रन (`x + y = 176`) भारतीय खेल संदर्भ का एक सीधा उदाहरण है।
2.  **लागत संबंधी समस्याएं (अभ्यास 4.1):** "एक नोटबुक की कीमत (₹ x) एक कलम की कीमत (₹ y) से दोगुनी है।" इसे समीकरण `x = 2y` या `x - 2y = 0` के रूप में दर्शाना। यह भारतीय बाजार में वस्तुओं की लागत की तुलना करने जैसी सामान्य स्थितियों से संबंधित है।
3.  **किराया और लागत:** भारतीय शहरों में ऑटो-रिक्शा या टैक्सी के किराए की गणना अक्सर एक निश्चित शुल्क और प्रति किलोमीटर शुल्क के आधार पर की जाती है। उदाहरण के लिए, यदि निश्चित शुल्क ₹25 है और प्रति किलोमीटर किराया ₹12 है, तो x किलोमीटर यात्रा के लिए कुल किराया y, समीकरण `y = 12x + 25` द्वारा दिया जा सकता है। यह दो चरों (दूरी और किराया) के बीच एक रैखिक संबंध दर्शाता है।
4.  **सरकारी योजनाएं:** कभी-कभी सरकारी योजनाओं में सब्सिडी या लाभ दो कारकों पर आधारित हो सकते हैं, जिन्हें रैखिक समीकरणों का उपयोग करके मॉडल किया जा सकता है (हालांकि ये अक्सर अधिक जटिल होते हैं)। उदाहरण के लिए, किसी विशेष फसल के लिए किसानों को दी जाने वाली कुल सब्सिडी भूमि के क्षेत्रफल और उपयोग किए गए उर्वरक की मात्रा पर निर्भर हो सकती है।
