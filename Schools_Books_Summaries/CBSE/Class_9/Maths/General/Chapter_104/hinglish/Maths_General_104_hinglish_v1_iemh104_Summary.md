# [Class 9] Maths - Chapter 4: Linear Equations in Two Variables (Do Char Wale Raikhik Samikaran)

## 🌟 Core Concepts (Mukhya Avdharnayein) 📊

1.  **Linear Equation in One Variable (Ek Char Wala Raikhik Samikaran)**
    *   Format: `ax + b = 0` (jahan a ≠ 0)
    *   Solution: Unique (ek advitiya hal) - Example: `2x + 5 = 0` ka solution hai `x = -5/2`.
2.  **Linear Equation in Two Variables (Do Char Wale Raikhik Samikaran)**
    *   **Definition:** Koi bhi equation jo `ax + by + c = 0` ke form mein likha ja sakta hai, jahan a, b, aur c vastavik sankhyayein (real numbers) hain, aur a aur b dono ek saath zero nahin hain (a and b are not both zero).
    *   **Variables:** Usually denoted by x and y, lekin dusre letters bhi use ho sakte hain (jaise s, t, u, v).
    *   **Solution:** Ek ordered pair (x, y) jo equation ko satisfy karta hai. Matlab, jab x aur y ki values equation mein rakhi jayein, toh Left Hand Side (LHS) = Right Hand Side (RHS) ho jaye.
    *   **Number of Solutions:** Infinitely many solutions (anant hal).

## 📘 Key Learnings (Mukhya Baatein)

**1. Pehchan aur Standard Form:**

*   Linear equation in two variables ko pehchanna: Equation mein do variables honge aur unki highest power 1 hogi.
    *   *Example:* `1.2s + 3t = 5`, `p + 4q = 7`, `x + y = 176`.
*   Standard Form (`ax + by + c = 0`): Kisi bhi linear equation in two variables ko is standard form mein convert karna.
    *   *Example 1:* `2x + 3y = 4.37` ko `2x + 3y - 4.37 = 0` likh sakte hain. Yahan, `a = 2`, `b = 3`, `c = -4.37`.
    *   *Example 2:* `x - 4 = 3y` ko `x - 3y - 4 = 0` likh sakte hain. Yahan, `a = 1`, `b = -3`, `c = -4`.
    *   *Example 3:* `2x = y` ko `2x - y + 0 = 0` likh sakte hain. Yahan, `a = 2`, `b = -1`, `c = 0`.
*   **Special Case:** Equations like `ax + b = 0` (linear in one variable) ko bhi two variables mein express kar sakte hain.
    *   *Example:* `4 - 3x = 0` ko `-3x + 0.y + 4 = 0` likha ja sakta hai. Yahan `a = -3`, `b = 0`, `c = 4`.
    *   *Example:* `y = 2` ko `0.x + 1.y - 2 = 0` likha ja sakta hai. Yahan `a = 0`, `b = 1`, `c = -2`.

**2. Equation ka Hal (Solution of an Equation):**

*   Ek linear equation in two variables ka solution ek pair of values (x, y) hota hai jo us equation ko santusht (satisfy) karta hai.
    *   *Example:* Equation `2x + 3y = 12` ke liye:
        *   `(3, 2)` ek solution hai kyunki `2(3) + 3(2) = 6 + 6 = 12`.
        *   `(0, 4)` bhi ek solution hai kyunki `2(0) + 3(4) = 0 + 12 = 12`.
        *   `(1, 4)` solution *nahin* hai kyunki `2(1) + 3(4) = 2 + 12 = 14`, jo 12 ke barabar nahin hai.

**3. Solutions Kaise Nikalein (Finding Solutions):**

*   Ek variable (jaise x) ki koi bhi value choose karo aur use equation mein substitute karke dusre variable (y) ki corresponding value nikalo.
*   *Method:*
    1.  Apni marzi se x ki koi value chuno (jaise x = 0, x = 1, x = -5, etc.).
    2.  Equation mein x ki value daalo. Ab yeh ek linear equation in one variable (y) ban jayega.
    3.  Is naye equation ko solve karke y ki value nikalo.
    4.  Aapko ek solution (x, y) mil gaya.
*   *Example:* `x + 2y = 6` ke solutions:
    *   Agar `x = 0` lete hain: `0 + 2y = 6` => `2y = 6` => `y = 3`. Solution: `(0, 3)`.
    *   Agar `y = 0` lete hain: `x + 2(0) = 6` => `x = 6`. Solution: `(6, 0)`.
    *   Agar `x = 2` lete hain: `2 + 2y = 6` => `2y = 4` => `y = 2`. Solution: `(2, 2)`.
    *   Agar `y = 1` lete hain: `x + 2(1) = 6` => `x + 2 = 6` => `x = 4`. Solution: `(4, 1)`.
*   **Important:** Ek linear equation in two variables ke *infinitely many solutions* (anant hal) hote hain. Aap x ki alag-alag values choose karke anant solutions nikal sakte hain.

    *   **Topic:** Apne aas paas ki 3 alag-alag situations dhoondho jinhe linear equations in two variables se represent kiya ja sakta hai.
    *   *Hint:* Socho kirana store se samaan kharidne ke baare mein (jaise `x` kg chawal aur `y` kg daal ka total cost), ya travel ke baare mein (kuch distance auto se `x` km aur bus se `y` km travel karne ka total time ya cost), ya school canteen mein kharch ( `x` samosas aur `y` cold drinks ka total bill).
    *   Har situation ke liye:
        1.  Variables (x aur y) define karo.
        2.  Linear equation banao.
        3.  Kam se kam 3 alag-alag possible solutions (hal) nikalo.
        4.  Apne results class mein present karo.
*   **Discussion (Charcha): Critical analysis of real-world impacts 🌍**
    *   Cricket match wale example (`x + y = 176`) par vichaar karein.
        *   Kya `x = 200, y = -24` is equation ka solution hai? Mathematically, haan. Par kya yeh real-world situation mein possible hai? Kyun nahin? (Negative runs possible nahin hain).
        *   Kya `x = 80.5, y = 95.5` is equation ka solution hai? Mathematically, haan. Par kya yeh cricket score ke context mein practical hai? (Runs usually whole numbers hote hain).
    *   Isse hum kya seekhte hain? Jab hum real-world problems ko equations se model karte hain, toh mathematical solutions ke alawa yeh bhi dekhna zaroori hai ki kaun se solutions practical ya meaningful hain us situation ke liye.
    *   Discuss karo ki "infinitely many solutions" ka concept real life mein hamesha "infinitely many practical solutions" imply karta hai ya nahin.

## 📝 Assessment Prep (Mulyankan Ki Taiyari)

*   **Case Studies & Problems:**
    1.  **Word Problems:** Statements ko linear equations in two variables mein convert karna.
        *   *Example:* Ek notebook ka cost (`x`) ek pen ke cost (`y`) se double hai. Is statement ko equation form mein likho. (Answer: `x = 2y` ya `x - 2y = 0`).
    2.  **Standard Form Conversion:** Di gayi equations ko `ax + by + c = 0` form mein likhna aur a, b, c ki values batana. (Exercise 4.1, Q2 jaise problems).
    3.  **Finding Solutions:** Ek equation ke liye 3 ya 4 alag-alag solutions nikalna. (Exercise 4.2, Q2 jaise problems).
    4.  **Checking Solutions:** Check karna ki diya gaya ordered pair (jaise (2, 0), (4, 0)) kisi equation (jaise `x - 2y = 4`) ka solution hai ya nahin. (Exercise 4.2, Q3 jaise problems).
    5.  **Finding Unknown Constant:** Agar ek solution (jaise x=2, y=1) diya gaya hai, toh equation mein ek unknown constant (k) ki value nikalna. (Exercise 4.2, Q4 jaise problems - `2x + 3y = k` mein k ki value nikalo agar (2, 1) solution hai).
