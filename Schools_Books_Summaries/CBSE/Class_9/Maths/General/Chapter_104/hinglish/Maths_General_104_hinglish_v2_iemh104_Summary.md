# [Class 9] Maths - Chapter 4: Linear Equations in Two Variables (Do Char Wale Rekhik Samikaran)

## 🌟 Core Concepts (Mukhya Avdharnayein) 📊

1.  **Linear Equation in One Variable (Ek Char Wala Rekhik Samikaran) ka Revision:**
    *   Jaise `x + 5 = 0` ya `2y - 3 = 0`.
    *   Inka *unique* (sirf ek) solution hota hai. Example: `2x + 5 = 0` ka solution hai `x = -5/2`.
    *   Solution ko number line par represent kar sakte hain.

2.  **Introduction to Linear Equations in Two Variables (Do Char Wale Rekhik Samikaran ka Parichay):**
    *   Jab kisi situation mein do unknown quantities hon, tab humein in equations ki zaroorat padti hai.
    *   Example: Do batsmen ne milkar 176 runs banaye. Agar ek ne x runs aur dusre ne y runs banaye, toh equation hogi `x + y = 176`.

3.  **Definition and Standard Form (Paribhasha aur Manak Roop):**
    *   Koi bhi equation jise `ax + by + c = 0` ke form mein likha ja sakta hai, use linear equation in two variables kehte hain.
    *   Yahan `a`, `b`, aur `c` *real numbers* (vastavik sankhyayein) hain.
    *   Ek important condition: `a` aur `b` dono ek saath zero nahin ho sakte (`a` and `b` are not both zero).
    *   `x` aur `y` *variables* (char) hain.
    *   `a` ko `x` ka *coefficient* (gunank) kehte hain, `b` ko `y` ka coefficient, aur `c` ko *constant term* (acharang) kehte hain.

4.  **Converting to Standard Form (Manak Roop mein Badalna):**
    *   Kisi bhi di gayi linear equation ko `ax + by + c = 0` form mein rearrange karna.
    *   Example: `2x + 3y = 4.37` ko `2x + 3y - 4.37 = 0` likh sakte hain. Yahan `a = 2`, `b = 3`, `c = -4.37`.
    *   Example: `x = 3y` ko `x - 3y + 0 = 0` likh sakte hain. Yahan `a = 1`, `b = -3`, `c = 0`.
    *   Ek variable wali equation ko bhi do variable mein likh sakte hain. Example: `x = -5` ko `1x + 0y + 5 = 0` likh sakte hain. Yahan `a = 1`, `b = 0`, `c = 5`.

## 📘 Key Learnings (Mukhya Baatein) 📈

1.  **Solution of a Linear Equation in Two Variables (Do Char Wale Rekhik Samikaran ka Hal):**
    *   Ek variable wali equation ka *unique* solution hota hai.
    *   Lekin, do variable wali equation ka solution ek *pair of values* (x aur y ke maano ka yugm) hota hai jo equation ko *satisfy* kare (santusht kare).
    *   Solution ko hamesha ek *ordered pair* `(x, y)` ke roop mein likhte hain. Pehle x ki value, phir y ki value.
    *   Example: Equation `2x + 3y = 12` ke liye:
        *   Agar `x = 3`, `y = 2` rakhein: `2(3) + 3(2) = 6 + 6 = 12`. Toh `(3, 2)` ek solution hai. ✅
        *   Agar `x = 0`, `y = 4` rakhein: `2(0) + 3(4) = 0 + 12 = 12`. Toh `(0, 4)` bhi ek solution hai. ✅
        *   Agar `x = 1`, `y = 4` rakhein: `2(1) + 3(4) = 2 + 12 = 14`, jo 12 ke barabar nahin hai. Toh `(1, 4)` solution nahin hai. ❌

2.  **Infinitely Many Solutions (Anant Hal):**
    *   Ek linear equation in two variables ke *infinitely many solutions* (anant hal) hote hain.
    *   Hum `x` ki koi bhi value choose karke corresponding `y` ki value nikal sakte hain, ya `y` ki koi value choose karke corresponding `x` ki value nikal sakte hain.
    *   Example: `x + 2y = 6` ke solutions dhundhna:
        *   Agar `x = 0` rakhein: `0 + 2y = 6` => `2y = 6` => `y = 3`. Solution: `(0, 3)`.
        *   Agar `y = 0` rakhein: `x + 2(0) = 6` => `x = 6`. Solution: `(6, 0)`.
        *   Agar `x = 2` rakhein: `2 + 2y = 6` => `2y = 4` => `y = 2`. Solution: `(2, 2)`.
        *   Agar `y = 1` rakhein: `x + 2(1) = 6` => `x + 2 = 6` => `x = 4`. Solution: `(4, 1)`.
    *   Aasan tareeka solutions nikalne ka: Ek baar `x = 0` rakho aur `y` nikalo, phir `y = 0` rakho aur `x` nikalo. Isse kam se kam do solutions mil jaate hain.

Diagram/Graph ka Idea (Abhi sirf concept): Har solution `(x, y)` Cartesian plane par ek point ko represent karta hai. Jab hum in sabhi points ko join karte hain, toh ek straight line banti hai. Isliye in equations ko 'linear' kehte hain. (Yeh agle section mein detail mein aayega).

📈 Example Visualization (Man mein): Imagine karo `x + y = 10`. Solutions ho sakte hain (0, 10), (1, 9), (2, 8), (5, 5), (10, 0), (-1, 11), (11, -1), (4.5, 5.5) ... endless possibilities!

## 🧩 Active Learning (Sakriya Adhigam)

1.  **Activity: Real-World Equations 🔍**
    *   **Research Karo:** Apne aas paas 3 aisi situations dhundo jinhe linear equations in two variables se represent kiya ja sakta hai.
    *   **Example Ideas:**
        *   Ek dukaan se kuch pens (`x`) aur kuch notebooks (`y`) khareedne ka total cost. (Jaise NCERT example: Notebook ka cost pen se double hai: `x = 2y`)
        *   Auto rickshaw ka किराया: Fixed charge (`c`) plus per kilometer charge (`a`). Total किराया (`y`) for `x` kilometers: `y = ax + c`. (Yahan `a` aur `c` fixed numbers honge, `x` aur `y` variables).
        *   Do alag-alag mobile recharge plans ka comparison based on call duration (`x`) and total cost (`y`).
    *   **Task:** Har situation ke liye equation likho aur kam se kam 2 possible solutions (values for variables) batao.

2.  **Discussion: Why Infinite Solutions? 🌍**
    *   Class mein discuss karo: Ek linear equation in *one* variable ka sirf ek hi solution kyun hota hai, jabki *two* variables wali equation ke anant solutions kyun hote hain?
    *   **Socho:** Real-world example (jaise batsmen ka score `x + y = 176`) mein infinite solutions ka kya matlab hai? Kya saare solutions practical hain? (Kya `x = -10`, `y = 186` cricket score ke liye valid hai? Nahin. Toh real-world context mein solutions par constraints ho sakte hain).
    *   **Critical Analysis:** Kya `ax + by + c = 0` mein agar `a=0` ho jaye (jaise `3y + 4 = 0`), tab bhi infinite solutions honge? (Haan, `y = -4/3` hoga for *any* value of `x`. Solutions honge `(0, -4/3)`, `(1, -4/3)`, `(-5, -4/3)` etc.)

## 📝 Assessment Prep (Mulyankan Taiyari) 📝

**Case Study / Practice Problems:**

1.  **Cricket Match Scenario:** India aur Australia ke match mein, Virat (`x` runs) aur Rohit (`y` runs) ne milkar 210 runs ki partnership ki.
    *   Is situation ko linear equation in two variables mein express karo. (`x + y = 210`)
    *   Is equation ko standard form `ax + by + c = 0` mein likho aur `a`, `b`, `c` ki values batao. (`1x + 1y - 210 = 0`, so `a=1, b=1, c=-210`)
    *   Is equation ke 4 alag-alag solutions find karo. (e.g., (100, 110), (50, 160), (210, 0), (0, 210))
    *   Kya `(120, 80)` iska solution hai? Check karo. (`120 + 80 = 200`, jo 210 nahin hai. So, No.)

2.  **Standard Form Practice:** Neeche di gayi equations ko `ax + by + c = 0` form mein likho aur `a`, `b`, `c` identify karo:
    *   `3x = 2y - 5`   (Answer: `3x - 2y + 5 = 0`; `a=3, b=-2, c=5`)
    *   `y/2 - x/3 = 1` (Hint: Pehle LCM lo) (Answer: `3y - 2x = 6` => `-2x + 3y - 6 = 0` or `2x - 3y + 6 = 0`; `a=-2, b=3, c=-6` or `a=2, b=-3, c=6`)
    *   `5 = 2x`       (Answer: `-2x + 0y + 5 = 0` or `2x + 0y - 5 = 0`; `a=-2, b=0, c=5` or `a=2, b=0, c=-5`)
    *   `y = 7`         (Answer: `0x + 1y - 7 = 0`; `a=0, b=1, c=-7`)

3.  **Finding Solutions:** Equation `πx + y = 9` ke 3 solutions nikalo.
    *   (Hint: `x=0` rakho, `y=9` milega -> `(0, 9)`. `y=0` rakho, `πx=9` => `x=9/π` -> `(9/π, 0)`. `x=1` rakho, `π(1) + y = 9` => `y = 9-π` -> `(1, 9-π)`)

4.  **Checking Solutions:** Check karo ki `(4, 0)` aur `(√2, 4√2)` equation `x - 2y = 4` ke solutions hain ya nahin.
    *   For `(4, 0)`: `4 - 2(0) = 4 - 0 = 4`. Yes, it is a solution.
    *   For `(√2, 4√2)`: `√2 - 2(4√2) = √2 - 8√2 = -7√2`. No, it is not a solution.

5.  **Finding 'k':** Agar `x = 2`, `y = 1` equation `2x + 3y = k` ka ek solution hai, toh `k` ki value find karo.
    *   (Solution: Equation mein `x=2` aur `y=1` substitute karo: `2(2) + 3(1) = k` => `4 + 3 = k` => `k = 7`)
