# [Class 9] Maths - Chapter 2: Polynomials (Bahupad)

## 🌟 Core Concepts (Mukhya Avdharnayein)

Ek detailed hierarchy jo Polynomials ke important concepts ko samajhne mein madad karegi 📊:

1.  **Algebraic Expressions (Beejganitiya Vyanjak)**: Foundation concept.
2.  **Polynomials (Bahupad)**
    *   **Definition**: Aise algebraic expressions jinme variable ki power (exponent) hamesha ek **whole number** (poorn sankhya) ho.
        *   Example: `2x² + 5x - 3` (Polynomial hai)
        *   Non-Example: `x + 1/x` (yaani `x + x⁻¹`), `√t + 2` (yaani `t^(1/2) + 2`) (Polynomials *nahi* hain kyunki power whole number nahi hai).
    *   **Polynomials in One Variable (Ek Char Wale Bahupad)**: Expressions jisme sirf ek hi variable (jaise sirf x, ya sirf y) use hota hai.
    *   **Terms (Pad)**: Polynomial ke parts jo '+' ya '-' se separate hote hain.
        *   Example: `3y² + 5y + 7` mein terms hain `3y²`, `5y`, aur `7`.
    *   **Coefficients (Gunank)**: Har term mein variable ke saath multiply hone wala constant number.
        *   Example: `-x³ + 4x² + 7x - 2` mein `x³` ka coefficient `-1`, `x²` ka `4`, `x` ka `7`, aur constant term `-2` (jo `x⁰` ka coefficient hai).
    *   **Constant Polynomial (Achar Bahupad)**: Sirf ek constant number wala polynomial (e.g., 2, -5, 7). Inki degree 0 hoti hai.
    *   **Zero Polynomial (Shunya Bahupad)**: The constant polynomial 0. Iski degree **defined nahi** hoti hai.
3.  **Types of Polynomials based on Number of Terms (Padon ki Sankhya ke Aadhar par Prakar)**
    *   **Monomial (Ekpadi)**: Ek term wala polynomial (e.g., `2x`, `5x³`, `y`).
    *   **Binomial (Dwipadi)**: Do terms wala polynomial (e.g., `x + 1`, `u¹⁵ – u²`).
    *   **Trinomial (Tripadi)**: Teen terms wala polynomial (e.g., `x + x² + π`, `y⁴ + y + 5`).
4.  **Degree of a Polynomial (Bahupad ki Ghaat)**
    *   **Definition**: Polynomial mein variable ki **highest power** (sabse badi ghaat).
    *   Example: `3x⁷ – 4x⁶ + x + 9` ki degree 7 hai. `5y⁶ – 4y² – 6` ki degree 6 hai.
    *   Degree of a non-zero constant polynomial is **0**.
5.  **Types of Polynomials based on Degree (Ghaat ke Aadhar par Prakar)**
    *   **Linear Polynomial (Raikhik Bahupad)**: Degree 1 wala polynomial (e.g., `4x + 5`, `2y`, `3 - u`). General form: `ax + b`, where `a ≠ 0`.
    *   **Quadratic Polynomial (Dwighati Bahupad)**: Degree 2 wala polynomial (e.g., `2x² + 5`, `x²`, `6 – y – y²`). General form: `ax² + bx + c`, where `a ≠ 0`.
    *   **Cubic Polynomial (Trighati Bahupad)**: Degree 3 wala polynomial (e.g., `4x³`, `6 - x³`, `2x³ + 4x² + 6x + 7`). General form: `ax³ + bx² + cx + d`, where `a ≠ 0`.
6.  **Zeroes of a Polynomial (Bahupad ke Shunyank)**
    *   **Definition**: Variable ki woh value (real number 'c') jiske liye polynomial `p(x)` ki value zero (`p(c) = 0`) ho jaye.
    *   Zero ko polynomial equation `p(x) = 0` ka **root** (mool) bhi kehte hain.
    *   **Finding Zeroes**: Linear polynomial `ax + b` ka zero `-b/a` hota hai. Quadratic aur cubic ke liye methods (Factorization, etc.) use karte hain.
    *   Ek non-zero constant polynomial ka koi zero nahi hota.
    *   Zero polynomial ke liye har real number ek zero hota hai.
    *   Ek polynomial ke ek se zyada zeroes ho sakte hain.
7.  **Factor Theorem (Gunankhand Pramey)**
    *   Agar `p(x)` ek polynomial hai jiski degree `n ≥ 1` hai aur 'a' koi real number hai, toh:
        *   (i) `(x – a)` polynomial `p(x)` ka ek factor (gunankhand) hoga **agar** `p(a) = 0`.
        *   (ii) `p(a) = 0` hoga **agar** `(x – a)` polynomial `p(x)` ka ek factor hai.
    *   Yeh theorem polynomial ko factorize karne mein bahut useful hai.
8.  **Factorisation of Polynomials (Bahupadon ka Gunankhandan)**
    *   **Splitting the Middle Term**: Quadratic polynomial `ax² + bx + c` ko factorize karne ka method. Humein `b` ko aise do numbers `p` aur `q` mein split karna hota hai ki `p + q = b` aur `pq = ac`.
    *   **Using Factor Theorem**: Especially useful for cubic polynomials. Pehle trial-and-error se ek zero 'a' find karte hain (jiske liye `p(a) = 0`), isse `(x-a)` ek factor mil jata hai. Phir `p(x)` ko `(x-a)` se divide karke remaining quadratic factor nikalte hain aur usse factorize karte hain.
9.  **Algebraic Identities (Beejganitiya Sarvasamikayein)**
    *   Equations jo variables ki sabhi values ke liye true hoti hain.
    *   **Important Identities**:
        *   I: `(x + y)² = x² + 2xy + y²`
        *   II: `(x – y)² = x² – 2xy + y²`
        *   III: `x² – y² = (x + y)(x – y)`
        *   IV: `(x + a)(x + b) = x² + (a + b)x + ab`
        *   V: `(x + y + z)² = x² + y² + z² + 2xy + 2yz + 2zx`
        *   VI: `(x + y)³ = x³ + y³ + 3xy(x + y) = x³ + 3x²y + 3xy² + y³`
        *   VII: `(x – y)³ = x³ – y³ – 3xy(x – y) = x³ – 3x²y + 3xy² – y³`
        *   VIII: `x³ + y³ + z³ – 3xyz = (x + y + z)(x² + y² + z² – xy – yz – zx)`
        *   Special Case: Agar `x + y + z = 0`, toh `x³ + y³ + z³ = 3xyz`.

## 📘 Key Learnings (Mukhya Baatein)

Yahan hum core concepts ko examples aur diagrams ke saath detail mein samjhenge 📈:

1.  **Polynomial Pehchanna**: Sabse pehle yeh check karna ki expression mein variable ki power **whole number** hai ya nahi.
    *   `4x² - 3x + 7`: Yahan x ki powers 2, 1, aur 0 (7 = 7x⁰) hain. Sab whole numbers hain. Toh yeh **polynomial hai**. ✅
    *   `y + 2/y`: Yeh `y + 2y⁻¹` hai. Power -1 whole number nahi hai. Toh yeh **polynomial nahi hai**. ❌
    *   `3√t + t√2`: Yeh `3t^(1/2) + √2 * t¹` hai. Power 1/2 whole number nahi hai. Toh yeh **polynomial nahi hai**. ❌

2.  **Degree Samajhna**: Polynomial mein variable ki sabse badi power.
    *   `p(x) = 5x³ + 4x² + 7x`: Highest power 3 hai. Degree = 3. (Cubic Polynomial)
    *   `q(y) = 4 - y²`: Highest power 2 hai. Degree = 2. (Quadratic Polynomial)
    *   `r(t) = 5t - √7`: Highest power 1 hai. Degree = 1. (Linear Polynomial)
    *   `s(u) = 3`: Isse `3u⁰` likh sakte hain. Highest power 0 hai. Degree = 0. (Constant Polynomial)
    *   `0`: Zero polynomial ki degree **not defined** hoti hai.

    ```
    Polynomial Example   | Variable | Highest Power | Degree | Type (by Degree)
    ---------------------|----------|---------------|--------|-------------------
    5x³ + 4x² + 7x       | x        | 3             | 3      | Cubic
    4 - y²               | y        | 2             | 2      | Quadratic
    5t - √7              | t        | 1             | 1      | Linear
    3                    | (any)    | 0             | 0      | Constant
    ```
    *(Conceptual representation 📊)*

3.  **Zeroes Find Karna**: Woh value jo polynomial ko zero bana de.
    *   `p(x) = x - 1`. Agar `x = 1` rakhein, toh `p(1) = 1 - 1 = 0`. Toh `1` is polynomial ka zero hai.
    *   `q(x) = x + 2`. Agar `x = -2` rakhein, toh `q(-2) = -2 + 2 = 0`. Toh `-2` is polynomial ka zero hai.
    *   `r(x) = x² - 2x`.
        *   `r(2) = 2² - 2(2) = 4 - 4 = 0`. Toh `2` ek zero hai.
        *   `r(0) = 0² - 2(0) = 0 - 0 = 0`. Toh `0` bhi ek zero hai.
    *   Linear polynomial `ax + b` ka zero hamesha `x = -b/a` hota hai. Example: `p(x) = 2x + 1` ka zero `x = -1/2`.

4.  **Factor Theorem ka Use**: Check karna ki `(x-a)` factor hai ya nahi, ya factorize karna.
    *   Kya `x + 2` polynomial `p(x) = x³ + 3x² + 5x + 6` ka factor hai?
        *   `x + 2` ka zero hai `x = -2`.
        *   `p(-2) = (-2)³ + 3(-2)² + 5(-2) + 6 = -8 + 3(4) - 10 + 6 = -8 + 12 - 10 + 6 = 0`.
        *   Kyunki `p(-2) = 0`, isliye Factor Theorem ke according, `(x + 2)` **factor hai**. ✅
    *   Find `k` agar `x - 1` polynomial `p(x) = 4x³ + 3x² - 4x + k` ka factor hai.
        *   Agar `x - 1` factor hai, toh `p(1) = 0` hona chahiye.
        *   `p(1) = 4(1)³ + 3(1)² - 4(1) + k = 4 + 3 - 4 + k = 3 + k`.
        *   So, `3 + k = 0`, yaani `k = -3`.

5.  **Factorisation Techniques**:
    *   **Splitting Middle Term**: `6x² + 17x + 5`.
        *   Humein do numbers chahiye jinka sum `17` ho aur product `6 * 5 = 30` ho. Woh numbers hain `15` aur `2`.
        *   `6x² + 17x + 5 = 6x² + 2x + 15x + 5`
        *   `= 2x(3x + 1) + 5(3x + 1)`
        *   `= (3x + 1)(2x + 5)`
    *   **Factor Theorem (Cubic)**: `p(x) = x³ - 2x² - x + 2`.
        *   Factors of constant term `2` hain `±1, ±2`.
        *   Try `x = 1`: `p(1) = 1³ - 2(1)² - 1 + 2 = 1 - 2 - 1 + 2 = 0`. Toh `(x - 1)` ek factor hai.
        *   Ab `p(x)` ko `(x - 1)` se divide karo (long division ya synthetic division se) ya terms adjust karo:
            *   `x³ - 2x² - x + 2 = x²(x - 1) - x(x - 1) - 2(x - 1)` (Adjusting terms carefully)
            *   `= (x - 1)(x² - x - 2)`
        *   Ab quadratic `x² - x - 2` ko factorize karo (splitting middle term: -2x + x):
            *   `x² - x - 2 = x² - 2x + x - 2 = x(x - 2) + 1(x - 2) = (x - 2)(x + 1)`
        *   Final factors: `(x - 1)(x + 1)(x - 2)`.

6.  **Algebraic Identities ka Application**: Calculations aur factorisation ko aasan banane ke liye.
    *   Expand `(3a + 4b + 5c)²`: Using `(x+y+z)² = x²+y²+z²+2xy+2yz+2zx` with `x=3a, y=4b, z=5c`.
        *   `= (3a)² + (4b)² + (5c)² + 2(3a)(4b) + 2(4b)(5c) + 2(5c)(3a)`
        *   `= 9a² + 16b² + 25c² + 24ab + 40bc + 30ac`
    *   Factorise `49a² + 70ab + 25b²`: Yeh `(7a)² + 2(7a)(5b) + (5b)²` jaisa dikh raha hai.
        *   Using `x² + 2xy + y² = (x + y)²` with `x=7a, y=5b`.
        *   `= (7a + 5b)² = (7a + 5b)(7a + 5b)`
    *   Evaluate `105 × 106`: Isse `(100 + 5)(100 + 6)` likh sakte hain.
        *   Using `(x + a)(x + b) = x² + (a + b)x + ab` with `x=100, a=5, b=6`.
        *   `= (100)² + (5 + 6)100 + (5)(6)`
        *   `= 10000 + 11(100) + 30 = 10000 + 1100 + 30 = 11130`
    *   Factorise `8x³ + y³ + 27z³ - 18xyz`: Yeh `(2x)³ + (y)³ + (3z)³ - 3(2x)(y)(3z)` hai.
        *   Using `a³+b³+c³-3abc = (a+b+c)(a²+b²+c²-ab-bc-ca)` with `a=2x, b=y, c=3z`.
        *   `= (2x + y + 3z)((2x)² + y² + (3z)² - (2x)(y) - (y)(3z) - (3z)(2x))`
        *   `= (2x + y + 3z)(4x² + y² + 9z² - 2xy - 3yz - 6zx)`
