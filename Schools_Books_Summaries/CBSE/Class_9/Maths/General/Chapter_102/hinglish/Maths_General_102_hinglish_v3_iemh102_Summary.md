# [Class 9] Maths - Chapter 2: Polynomials (Bahupad)

## 🌟 Core Concepts (Mukhya Avdharnayein)

**Polynomials ka Parichay (Introduction)** 📊
*   **Algebraic Expressions (Beejganitiya Vyanjak):** Puraane concepts yaad karein - addition, subtraction, multiplication, division.
*   **Polynomial Definition:** Ek special type ka algebraic expression jisme variable ki power (exponent) hamesha **whole number** (poorn sankhya) hoti hai.
    *   Example: `3x² + 2x - 1` (Yeh polynomial hai)
    *   Non-Example: `x + 1/x` (yaani `x + x⁻¹`), `√t + 5` (yaani `t^(1/2) + 5`) (Yeh polynomials nahi hain kyunki power whole number nahi hai).
*   **Polynomials in One Variable (Ek Char Wale Bahupad):** Expressions jaise `p(x)`, `q(y)`, `r(t)` jisme sirf ek hi variable (x, y, ya t) use hota hai.

**Polynomial ki Terminology**
*   **Terms (Pad):** Polynomial ke parts jo '+' ya '-' se alag hote hain.
    *   Example: `3y² + 5y + 7` mein terms hain `3y²`, `5y`, aur `7`.
*   **Coefficients (Gunank):** Har term mein variable ke saath multiply hone wala number.
    *   Example: `–x³ + 4x² + 7x – 2` mein, `x³` ka coefficient `-1`, `x²` ka `4`, `x` ka `7`, aur constant term `-2` (jo `x⁰` ka coefficient hai).
*   **Constant Polynomial (Achar Bahupad):** Sirf number wale polynomial, jaise `2`, `–5`, `7`. Inki degree 0 hoti hai (kyunki `2 = 2x⁰`).
*   **Zero Polynomial (Shunya Bahupad):** Number `0`. Iski degree **defined nahi** hoti hai.

**Types of Polynomials (Bahupad ke Prakar)**
*   **Based on Number of Terms (Padon ki Sankhya ke Aadhar Par):**
    *   **Monomial (Ekpadi):** Ek term wala polynomial (e.g., `2x`, `5x³`, `y`).
    *   **Binomial (Dwipadi):** Do terms wala polynomial (e.g., `x + 1`, `y⁹ + 1`).
    *   **Trinomial (Tripadi):** Teen terms wala polynomial (e.g., `x + x² + π`, `2 + x – x²`).
*   **Based on Degree (Ghaat ke Aadhar Par):**
    *   **Degree (Ghaat):** Polynomial mein variable ki sabse **highest power** (uchchatam ghaat).
        *   Example: `3x⁷ – 4x⁶ + x + 9` ki degree 7 hai.
        *   Example: `5y⁶ – 4y² – 6` ki degree 6 hai.
        *   Non-zero constant polynomial ki degree 0 hoti hai.
    *   **Linear Polynomial (Raikhik Bahupad):** Degree 1 wala polynomial (e.g., `4x + 5`, `2y`, `3 – u`). General form: `ax + b`, jahan `a ≠ 0`.
    *   **Quadratic Polynomial (Dwighati Bahupad):** Degree 2 wala polynomial (e.g., `2x² + 5`, `5x² + 3x + π`, `y²`). General form: `ax² + bx + c`, jahan `a ≠ 0`.
    *   **Cubic Polynomial (Trighati Bahupad):** Degree 3 wala polynomial (e.g., `4x³`, `2x³ + 1`, `6 – x³`). General form: `ax³ + bx² + cx + d`, jahan `a ≠ 0`.

**Zeroes of a Polynomial (Bahupad ke Shunyank)**
*   **Value of a Polynomial:** `p(x)` mein `x` ki jagah koi number `c` rakhne par jo value milti hai, use `p(c)` kehte hain.
*   **Zero (Shunyank):** Ek real number `c` polynomial `p(x)` ka zero kehlata hai agar `p(c) = 0`.
    *   Example: Agar `p(x) = x - 1`, toh `p(1) = 1 - 1 = 0`. Isliye, `1` polynomial `p(x)` ka zero hai.
    *   Linear polynomial `ax + b` ka zero hamesha `x = -b/a` hota hai.
    *   Ek polynomial ke ek se zyada zeroes ho sakte hain.
    *   Zero polynomial (`0`) ka har real number ek zero hota hai. Non-zero constant polynomial ka koi zero nahi hota.

**Factorisation (Gunankhandan)**
*   **Factor Theorem (Gunankhand Pramey):** Agar `p(x)` ek polynomial hai jiski degree `n ≥ 1` hai aur `a` koi real number hai, toh:
    1.  `(x – a)` polynomial `p(x)` ka factor hoga **agar** `p(a) = 0`.
    2.  `p(a) = 0` hoga **agar** `(x – a)` polynomial `p(x)` ka factor hai.
    *   Yeh theorem check karne mein help karta hai ki `(x-a)` factor hai ya nahi, aur factorisation mein bhi use hota hai.
*   **Splitting the Middle Term (Madhya Pad Vibhajan):** Quadratic polynomial `ax² + bx + c` ko factorise karne ka method. Humein `b` ko do numbers `p` aur `q` mein aise todna hota hai ki `p + q = b` aur `pq = ac`.
*   **Factorising Cubic Polynomials:** Pehle Factor Theorem use karke kam se kam ek factor `(x-a)` dhoondhte hain (trial method se, `a` constant term ka factor hota hai). Phir `p(x)` ko `(x-a)` se divide karke ya terms adjust karke remaining quadratic factor nikalte hain, jise phir split karke factorise karte hain.

**Algebraic Identities (Beejganitiya Sarvasamikayein)**
*   Equations jo variables ki sabhi values ke liye true hoti hain.
*   **Standard Identities:**
    1.  `(x + y)² = x² + 2xy + y²`
    2.  `(x – y)² = x² – 2xy + y²`
    3.  `x² – y² = (x + y)(x – y)`
    4.  `(x + a)(x + b) = x² + (a + b)x + ab`
    5.  `(x + y + z)² = x² + y² + z² + 2xy + 2yz + 2zx`
    6.  `(x + y)³ = x³ + y³ + 3xy(x + y) = x³ + 3x²y + 3xy² + y³`
    7.  `(x – y)³ = x³ – y³ – 3xy(x – y) = x³ – 3x²y + 3xy² – y³`
    8.  `x³ + y³ + z³ – 3xyz = (x + y + z)(x² + y² + z² – xy – yz – zx)`
    *   **Special Case:** Agar `x + y + z = 0`, toh `x³ + y³ + z³ = 3xyz`.

## 📘 Key Learnings (Mukhya Baatein)

**1. Polynomials ko Pehchanna aur Classify Karna:** 📈
*   **Pehchan:** Check karein ki variable ki sabhi powers whole numbers hain ya nahi. Agar `1/x`, `√x`, `x⁻²` jaise terms hain, toh woh polynomial nahi hai.
*   **Classification:**
    *   Terms ginkar (Monomial, Binomial, Trinomial).
    *   Highest power dekhkar (Linear, Quadratic, Cubic).
    *   Diagrammatically, linear polynomials ka graph straight line hota hai, quadratic ka parabola (aap aage ki classes mein padhenge).

**2. Degree, Coefficients, aur Terms Samajhna:**
*   **Degree:** Polynomial ki "complexity" batati hai. `7x³` mein degree 3 hai. `4 - y²` mein degree 2 hai. `3` (constant polynomial) mein degree 0 hai.
*   **Coefficients:** Har term ka numerical part. `2 - x² + x³` mein `x²` ka coefficient `-1` hai. `√2x - 1` mein `x` ka coefficient `√2` hai.
*   **Terms:** Polynomial ke building blocks. `5x³ + 4x² + 7x` mein 3 terms hain.

**3. Zeroes Nikalna aur Verify Karna:**
*   Kisi number `c` ko polynomial `p(x)` mein substitute karke dekhein. Agar `p(c) = 0` aata hai, toh `c` us polynomial ka zero hai.
    *   Example: `p(x) = x² - 2x`. Check karna hai ki 2 aur 0 zeroes hain ya nahi.
        *   `p(2) = 2² - 2(2) = 4 - 4 = 0`. Haan, 2 zero hai.
        *   `p(0) = 0² - 2(0) = 0 - 0 = 0`. Haan, 0 bhi zero hai.
*   Linear polynomial `p(x) = cx + d` ka zero nikalne ke liye `cx + d = 0` solve karein, `x = -d/c`.

**4. Factor Theorem ka Upyog:** 🛠️
*   **Check karna ki factor hai ya nahi:** `g(x) = x - a` ko `p(x)` ka factor check karne ke liye, `p(a)` calculate karein. Agar `p(a) = 0`, toh factor hai.
    *   Example: Kya `x + 2` polynomial `x³ + 3x² + 5x + 6` ka factor hai?
        *   `x + 2` ka zero hai `-2`.
        *   `p(-2) = (-2)³ + 3(-2)² + 5(-2) + 6 = -8 + 12 - 10 + 6 = 0`.
        *   Haan, `x + 2` factor hai.
*   **Unknown constant (k) nikalna:** Agar diya hai ki `x - a` factor hai, toh `p(a) = 0` use karke `k` ki value nikalein.
    *   Example: Agar `x - 1`, polynomial `4x³ + 3x² - 4x + k` ka factor hai, toh `k` kya hai?
        *   `p(1) = 0` hona chahiye.
        *   `p(1) = 4(1)³ + 3(1)² - 4(1) + k = 4 + 3 - 4 + k = 3 + k`.
        *   `3 + k = 0` => `k = -3`.

**5. Polynomials ko Factorise Karna:**
*   **Quadratic (Splitting Middle Term):** `ax² + bx + c` mein `b` ko aise `p, q` mein todein ki `p+q=b` aur `pq=ac`.
    *   Example: `6x² + 17x + 5`. Yahan `a=6, b=17, c=5`. `ac = 30`. Humein `p+q=17` aur `pq=30` chahiye. Numbers hain 15 aur 2.
    *   `6x² + 2x + 15x + 5 = 2x(3x + 1) + 5(3x + 1) = (3x + 1)(2x + 5)`.
*   **Quadratic (Factor Theorem):** Agar `p(y) = y² - 5y + 6`, constant term 6 ke factors (1, 2, 3) try karein. `p(2)=0` aur `p(3)=0`. Toh factors `(y-2)` aur `(y-3)` hain. `y² - 5y + 6 = (y-2)(y-3)`.
*   **Cubic:** Pehle constant term ke factors try karke ek zero `a` nikalein (`p(a)=0`), jisse ek factor `(x-a)` mil jayega. Phir `p(x)` ko `(x-a)` se divide karein (ya terms adjust karein) to get a quadratic quotient. Us quadratic ko factorise karein.
    *   Example: `x³ – 2x² – x + 2`. Constant term 2 ke factors ±1, ±2.
        *   `p(1) = 1-2-1+2 = 0`. Toh `(x-1)` factor hai.
        *   `x³ – 2x² – x + 2 = x²(x-1) - x(x-1) - 2(x-1) = (x-1)(x² - x - 2)`
        *   `x² - x - 2` ko factorise karein: `x² - 2x + x - 2 = x(x-2) + 1(x-2) = (x-2)(x+1)`.
        *   Final factors: `(x-1)(x+1)(x-2)`.

**6. Algebraic Identities ka Sahi Istemaal:** ✨
*   **Expansion (Vistar):** Identities use karke expressions ko expand karna.
    *   Example: `(3a + 4b + 5c)²` ko expand karne ke liye Identity V use karein (`x=3a, y=4b, z=5c`).
    *   `(3a)² + (4b)² + (5c)² + 2(3a)(4b) + 2(4b)(5c) + 2(5c)(3a) = 9a² + 16b² + 25c² + 24ab + 40bc + 30ac`.
    *   Example: `(104)³` ko evaluate karne ke liye `(100+4)³` likhkar Identity VI use karein.
*   **Factorisation (Gunankhandan):** Expressions ko identities ke pattern mein pehchan kar factorise karna.
    *   Example: `49a² + 70ab + 25b²`. Yeh `(7a)² + 2(7a)(5b) + (5b)²` hai, jo `(7a + 5b)²` (Identity I) hai. Factors: `(7a + 5b)(7a + 5b)`.
    *   Example: `8x³ + y³ + 27z³ – 18xyz`. Yeh `(2x)³ + y³ + (3z)³ - 3(2x)(y)(3z)` hai. Identity VIII use karke factors: `(2x + y + 3z)( (2x)² + y² + (3z)² - (2x)y - y(3z) - (3z)(2x) ) = (2x + y + 3z)(4x² + y² + 9z² - 2xy - 3yz - 6zx)`.

        *   Agar `x=5` cm hai toh volume kya hoga? `V(5)` calculate karein.
