# [Class 9] Statistics - Chapter 12

## 🌟 Core Concepts

This chapter focuses on the **Graphical Representation of Data**, moving beyond tabular formats to visual interpretations. Understanding how to represent data graphically helps in easier comprehension and comparison.

1.  **Introduction to Graphical Representation:**
    *   Why use graphs? (Easier understanding, comparison, "one picture is better than a thousand words")
2.  **Types of Graphical Representations:**
    *   **Bar Graphs:**
        *   Representation of categorical data or discrete variables.
        *   Uses bars of uniform width with equal spacing.
        *   Height of bars represents the value (frequency) of the variable.
    *   **Histograms:**
        *   Representation of grouped frequency distributions with **continuous** class intervals.
        *   Uses adjacent rectangular bars (no gaps).
        *   Width of bars represents the class size.
        *   **Area** of rectangles is proportional to the corresponding frequencies.
        *   **Histograms with Uniform Width:** Height of rectangles is proportional to the frequency.
        *   **Histograms with Varying Widths:**
            *   Requires adjustment of rectangle lengths.
            *   Adjusted Length = (Frequency / Width of the class) × Minimum Class Width.
            *   Ensures area remains proportional to frequency.
            *   Use of kink (break) on the axis if the first interval doesn't start from zero.
    *   **Frequency Polygons:**
        *   Line graph formed by joining the mid-points (class marks) of the tops of the rectangles in a histogram.
        *   Can be drawn independently using class marks and frequencies.
        *   **Class Mark = (Upper Limit + Lower Limit) / 2**.
        *   Polygon is completed by joining the first/last points to hypothetical class marks with zero frequency before the first class interval and after the last class interval.
        *   Area of the frequency polygon is equal to the area of the corresponding histogram.
        *   Useful for comparing two datasets on the same graph.

## 📘 Key Learnings

**1. Bar Graphs:**
*   **Purpose:** To compare discrete categories or items visually.
*   **Construction:**
    *   Represent categories (variable) on one axis (usually horizontal).
    *   Represent values (frequency) on the other axis (usually vertical).
    *   Draw rectangular bars of uniform width for each category, maintaining equal gaps between them.
    *   The height of each bar corresponds to the value of the category.
*   **Example:** Representing monthly household expenditure under different heads (Fig 12.2) or the number of students born in different months (Fig 12.1).

**2. Histograms (Uniform Width):**
*   **Purpose:** To represent the distribution of continuous data.
*   **Construction:**
    *   Represent continuous class intervals on the horizontal axis. Use a kink if the scale doesn't start at 0.
    *   Represent frequencies on the vertical axis.
    *   Draw rectangular bars with widths equal to the class size and heights corresponding to the frequency of that class interval.
    *   Bars are adjacent (no gaps).
*   **Example:** Representing the distribution of weights of students (Fig 12.3).

**3. Histograms (Varying Widths):**
*   **Purpose:** To represent continuous data grouped into class intervals of different sizes.
*   **Challenge:** Direct plotting of frequencies against varying widths gives a misleading visual representation because the area, not just height, should be proportional to frequency.
*   **Solution:** Adjust the lengths (heights) of the rectangles.
    *   Identify the minimum class size.
    *   Calculate the adjusted frequency (length) for each class: `Adjusted Length = (Frequency / Class Width) * Minimum Class Width`.
    *   Draw rectangles with the original class widths but using these adjusted lengths.
*   **Example:** Representing student marks grouped into intervals like 0-20, 20-30, ..., 70-100 (Fig 12.5, corrected from Fig 12.4).

**4. Frequency Polygons:**
*   **Purpose:** To represent the shape of a distribution, especially useful for comparing multiple distributions.
*   **Construction (Method 1: Using Histogram):**
    *   Draw a histogram.
    *   Mark the mid-point of the top side of each rectangle.
    *   Join these mid-points consecutively using line segments.
    *   Join the mid-point of the first bar to the mid-point of a hypothetical preceding class interval (with frequency 0) on the horizontal axis.
    *   Join the mid-point of the last bar to the mid-point of a hypothetical succeeding class interval (with frequency 0) on the horizontal axis.
*   **Construction (Method 2: Without Histogram):**
    *   Calculate the class mark for each class interval.
    *   Plot points with coordinates (Class Mark, Frequency).
    *   Include points representing hypothetical preceding and succeeding class intervals with frequency 0. Their class marks would be `(First Class Mark - Class Size)` and `(Last Class Mark + Class Size)` respectively (assuming uniform class size for neighbours).
    *   Join the plotted points consecutively using line segments.
*   **Example:** Representing weekly cost of living index data (Fig 12.8) or comparing marks of two sections (Exercise 12.1, Q6).
