## 📘 Key Learnings

**1. Introduction to Word Processors:**
*   Word processors (like LibreOffice Writer) are digital tools used to create, edit, format, store, retrieve, and print textual documents.
*   They allow for organised, systematic, effective, and presentable communication compared to simple text entry.
*   **Document:** Any piece of information created using a text editor.
*   **Cursor:** A blinking vertical line indicating the typing position.

**2. Creating and Managing Documents:**
*   **New Document:** Open the application (e.g., double-click Writer icon) or use `File -> New` (Shortcut: `Ctrl + N`). The initial document often has a default name like 'Untitled 1'.
*   **Typing:** Use the keyboard to enter text. Familiarity with keys like `Enter`, `Tab`, `Insert`, `Delete`, `Backspace`, `Caps Lock`, and `Shift` is essential.
*   **Saving:** Crucial to save work regularly (`File -> Save` or `Ctrl + S`). Use `File -> Save As` for the first save or to save with a new name. Choose meaningful filenames (e.g., `bookFairReportRishi.odt`).
*   **Opening:** Retrieve saved documents using `File -> Open` (`Ctrl + O`).
*   **Closing:** Close the document (`File -> Close`) or the entire application (Close button).

**3. Page Setup:**
*   Before typing extensively, set up the page layout via formatting options.
*   **Page Size:** Standard sizes like A4.
*   **Orientation:** `Portrait` (vertical) or `Landscape` (horizontal).
*   **Margins:** Blank space around the text area (Top, Bottom, Left, Right).
*   **Background Colour:** Apply colour to the page background.
*   *Purpose:* Ensures consistency and desired appearance for the final document.

**4. Text Formatting:**
*   Enhances readability and visual appeal. Tools are typically found on a Formatting Toolbar.
*   **Font:** Select Font Name (e.g., Times New Roman, Arial, Calibri), Font Size.
*   **Style:** Apply **Bold** (`Ctrl + B`), *Italic* (`Ctrl + I`), <u>Underline</u> (`Ctrl + U`).
*   **Colour:** Change the colour of the selected text.

**Conceptual Diagram: Formatting Toolbar (Partial)**

**5. Paragraph Formatting:**
*   Controls the layout and appearance of paragraphs.
*   **Alignment:**
    *   `Align Left`: Text aligns with the left margin.
    *   `Center Horizontally`: Text is centered between margins.
    *   `Align Right`: Text aligns with the right margin.
    *   `Justified`: Text aligns with both left and right margins (common in newspapers, books).
*   **Spacing:**
    *   `Line Spacing`: Adjusts vertical space between lines within a paragraph.
    *   `Paragraph Spacing`: Adjusts vertical space before or after a paragraph.
*   **Indentation:** Adds space at the beginning of the first line of a paragraph.

**6. Editing Text:**
*   **Cut, Copy, Paste:**
    *   `Cut` (`Ctrl + X`): Removes selected text and places it on the clipboard.
    *   `Copy` (`Ctrl + C`): Copies selected text to the clipboard, leaving the original intact.
    *   `Paste` (`Ctrl + V`): Inserts the clipboard content at the cursor position.
*   **Find and Replace (`Ctrl + H`):** Locates specific text and optionally replaces it with other text. Useful for correcting recurring errors (e.g., replacing 'fare' with 'fair').

**7. Spelling and Grammar Check:**
*   Word processors often highlight potential errors:
    *   Red wavy line: Possible spelling mistake.
    *   Green wavy line: Possible grammatical error.
*   Use the Spelling & Grammar tool (`F7`) to review suggestions and correct errors.
*   **Add to Dictionary:** Add correctly spelled proper nouns (like 'Pragati Maidan') or technical terms to the custom dictionary to prevent them from being flagged as errors.

**8. Lists:**
*   Organise items using:
    *   **Bulleted Lists:** Uses symbols (●, ■, ✓) for unordered items (order doesn't matter).
    *   **Numbered/Alphabetical Lists:** Uses numbers (1, 2, 3) or letters (a, b, c) for ordered items (sequence is important, like steps in a process).

**9. Tables:**
*   Present data in a structured row-and-column format.
*   **Insert Table:** Specify the initial number of rows and columns.
*   **Add Rows/Columns:** Modify the table structure as needed.
*   **Formatting:** Apply borders, shading, and text formatting within cells.
*   **Merge Cells:** Combine multiple adjacent cells into a single cell (useful for headings spanning multiple columns or categories spanning multiple rows).

**Conceptual Diagram: Table Operations**

**10. Inserting Objects:**
*   **Pictures/Images:** Insert images from files stored on the computer to illustrate the document.

**11. Headers and Footers:**
*   **Header:** Text or graphics appearing at the *top* of every page (e.g., report title, author name).
*   **Footer:** Text or graphics appearing at the *bottom* of every page (e.g., page number, date).
*   Accessed via Insert menu options.

**12. Finalizing the Document:**
*   **Print Preview:** (`File -> Print Preview`) Shows how the document will look when printed. Allows checking layout, page breaks, etc., before actual printing. Helps save paper.
*   **Printing:** (`File -> Print` or `Ctrl + P`) Sends the document to a connected printer. Options include selecting the printer, number of copies, and page range.
*   **Exporting to PDF:** (`File -> Export As -> Export as PDF`) Creates a Portable Document Format file. PDFs are generally non-editable, preserving the formatting and layout across different devices and operating systems. Useful for sharing final versions.

**13. Soft Copy vs. Hard Copy:**
*   **Soft Copy:** The digital version of the document (e.g., saved file on a computer, viewed on screen).
*   **Hard Copy:** The printed version of the document on paper.

**14. Ethical Considerations:**
*   It is unethical to view or modify someone else's digital documents without their permission.
