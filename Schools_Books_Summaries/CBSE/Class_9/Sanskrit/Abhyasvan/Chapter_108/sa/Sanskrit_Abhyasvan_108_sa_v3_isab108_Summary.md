# Class 9 Sanskrit - Abhyasvan Chapter 108
**Language:** संस्कृतम्

```markdown
# [नवमी कक्षा] अभ्यासवान् - पाठः १०८ (उपसर्गाः, अव्ययाः, प्रत्ययाः च)

## 🌟 प्रमुख-अवधारणाः (Core Concepts)

अस्मिन् पाठे वयं संस्कृतव्याकरणस्य त्रीणि महत्त्वपूर्णानि अङ्गानि पठामः - उपसर्गाः, अव्ययाः, प्रत्ययाः च। एतेषां ज्ञानेन शब्दनिर्माणं, वाक्येषु अर्थभेदं च अवगन्तुं साहाय्यं भवति।

1.  **उपसर्गाः (Prefixes):**
    *   **परिभाषा:** ये शब्दांशाः धातोः वा शब्दात् पूर्वं युज्यन्ते, अर्थे परिवर्तनम् अथवा वैशिष्ट्यम् आनयन्ति च।
    *   **श्लोकः:** "उपसर्गेण धात्वर्थो बलादन्यत्र नीयते। प्रहाराहार-संहार-विहार-परिहारवत्॥"
    *   **लक्षणानि:**
        *   धातोः/शब्दात् पूर्वं भवन्ति।
        *   अर्थं परिवर्तयन्ति (उदा. हारः -> प्रहारः) वा पोषयन्ति (उदा. शोभते -> परिशोभते)।
        *   एकस्मिन् पदे एकाधिकाः उपसर्गाः अपि भवितुम् अर्हन्ति।
    *   **उदाहरणानि:** वि + हारः = विहारः, प्र + हारः = प्रहारः, सम् + हारः = संहारः, उप + हारः = उपहारः, वि + शेषः = विशेषः, सु + गन्धः = सुगन्धः, अप + मानः = अपमानः, दुर् + जनः = दुर्जनः।

2.  **अव्ययानि (Indeclinables):**
    *   **परिभाषा:** यानि पदानि त्रिषु लिङ्गेषु, सर्वासु विभक्तिषु, त्रिषु वचनेषु च समानरूपेण तिष्ठन्ति, तेषु कोऽपि विकारः (रूपपरिवर्तनम्) न भवति, तानि अव्ययानि कथ्यन्ते।
    *   **श्लोकः:** "सदृशं त्रिषु लिङ्गेषु सर्वासु च विभक्तिषु। वचनेषु च सर्वेषु यन्न व्येति तदव्ययम्॥"
    *   **उदाहरणानि (अर्थैः सह):**
        *   स्थानवाचकानि: अत्र, तत्र, यत्र, कुत्र, सर्वत्र, एकत्र, अन्यत्र, परितः, अभितः, उभयतः, सर्वतः, उपरि, अधः, निकषा, समया।
        *   कालवाचकानि: अद्य, श्वः, ह्यः, यदा, तदा, कदा, सदा, अधुना, सम्प्रति, इदानीम्, पुरा, एकदा, अचिरम्, सद्यः।
        *   रीतिवाचकानि: शनैः, उच्चैः, नीचैः, कथम्, यथा, तथा, सहसा, अकस्मात्, वृथा, तूष्णीम्।
        *   प्रश्नवाचकानि: किम्, कुतः, कथम्, कदा, कुत्र।
        *   निश्चयवाचकानि: नूनम्, खलु, किल, ध्रुवम्।
        *   अन्य: च, अपि, एव, मा, न, वा, अथ, इति, विना, सह।

3.  **प्रत्ययाः (Suffixes):**
    *   **परिभाषा:** ये शब्दांशाः धातोः वा शब्दस्य पश्चात् युज्यन्ते, अर्थे विस्तारं वा परिवर्तनं कुर्वन्ति।
    *   **प्रकाराः:**
        *   **कृत्प्रत्ययाः (Krit Pratyayas - धातुभिः सह):**
            *   **क्त्वा (त्वा):** पूर्वकालिकक्रियार्थे ('करके')। उदा. गम् + क्त्वा = गत्वा, पठ् + क्त्वा = पठित्वा।
            *   **ल्यप् (य):** उपसर्गयुक्तेषु धातुषु क्त्वा-स्थाने ('करके')। उदा. प्र + नम् + ल्यप् = प्रणम्य, आ + गम् + ल्यप् = आगत्य।
            *   **तुमुन् (तुम्):** प्रयोजनार्थे ('के लिए')। उदा. पठ् + तुमुन् = पठितुम्, गम् + तुमुन् = गन्तुम्।
            *   **शतृ (अत्/अन्):** वर्तमानकालिकक्रिया (परस्मैपद - 'करता हुआ')। विशेषणरूपेण प्रयुज्यते। उदा. गम् + शतृ = गच्छन् (पु.), गच्छन्ती (स्त्री.), गच्छत् (नपुं.)।
            *   **शानच् (आन/मान):** वर्तमानकालिकक्रिया (आत्मनेपद - 'करता हुआ')। विशेषणरूपेण प्रयुज्यते। उदा. सेव् + शानच् = सेवमानः (पु.), सेवमाना (स्त्री.), सेवमानम् (नपुं.)।
            *   **क्तिन् (ति):** भाववाचकसंज्ञानिर्माणार्थम् ('करना')। उदा. कृ + क्तिन् = कृतिः, मन् + क्तिन् = मतिः।
        *   **तद्धितप्रत्ययाः (Taddhita Pratyayas - शब्दैः सह):**
            *   **मतुप्/वतुप् (मत्/वत्):** 'वाला'/'युक्त' अर्थे। उदा. धन + वतुप् = धनवान्, शक्ति + मतुप् = शक्तिमान्। (अकारान्तेषु आकारान्तेषु च शब्देषु 'वत्' भवति, अन्यत्र 'मत्')।
            *   **इनि (इन्):** 'वाला'/'युक्त' अर्थे। उदा. धन + इनि = धनी, बल + इनि = बली।
            *   **तरप् (तर):** द्वयोः मध्ये तुलनायाम् ('अधिक अच्छा/लघु' इत्यादि)। उदा. लघु + तरप् = लघुतरः।
            *   **तमप् (तम):** बहुषु मध्ये तुलनायाम् ('सबसे अच्छा/लघु' इत्यादि)। उदा. लघु + तमप् = लघुतमः।
            *   **मयट् (मय):** प्रचुरता ('भरपूर') वा विकार ('से बना हुआ') अर्थे। उदा. आनन्द + मयट् = आनन्दमयः, स्वर्ण + मयट् = स्वर्णमयः।
        *   **स्त्रीप्रत्ययाः (Stri Pratyayas - पुंल्लिङ्गशब्देभ्यः स्त्रीलिङ्गनिर्माणार्थम्):**
            *   **टाप् (आ):** प्रायः अकारान्तशब्देभ्यः। उदा. अज + टाप् = अजा, बालक + टाप् = बालिका।
            *   **ङीप् (ई):** ऋकारान्तेभ्यः, नकारान्तेभ्यः, शतृप्रत्ययान्तेभ्यः, अन्येभ्यः च। उदा. नद + ङीप् = नदी, कर्तृ + ङीप् = कर्त्री, गच्छत् + ङीप् = गच्छन्ती।

## 📘 मुख्य-शिक्षणांशाः (Key Learnings)

*   **उपसर्गाणां प्रभावः:** उपसर्गैः कथं धातोः मूलार्थः परिवर्तते इति ज्ञातव्यम्। यथा 'हृ' (हरणे) धातोः विभिन्नैः उपसर्गैः सह अर्थभेदाः - प्रहारः (मारना), आहारः (भोजन), संहारः (नाश), विहारः (भ्रमण), परिहारः (त्याग), उपहारः (भेंट)।
    ```mermaid
    graph LR
        A[धातुः: हृ] --> B(हारः);
        B --> C(वि + हारः = विहारः);
        B --> D(प्र + हारः = प्रहारः);
        B --> E(सम् + हारः = संहारः);
        B --> F(उप + हारः = उपहारः);
        B --> G(परि + हारः = परिहारः);
    ```
*   **अव्ययानाम् अपरिवर्तनीयता:** अव्ययपदानि वाक्येषु कथं लिङ्ग-वचन-विभक्तिभिः अप्रभावितानि तिष्ठन्ति इति अवगन्तव्यम्। तेषां प्रयोगः वाक्ये स्थानं, कालं, रीतिं वा सूचयति।
*   **प्रत्ययानां वर्गीकरणम् उपयोगश्च:**
    *   **कृत्प्रत्ययाः:** धातुभिः सह युज्यन्ते, क्रियासम्बद्धान् अर्थान् (यथा पूर्वकालः, प्रयोजनम्, वर्तमानकालः) अथवा भाववाचकसंज्ञां निर्मान्ति।
        *   **क्त्वा/ल्यप्:** एकस्याः क्रियायाः अनन्तरं जायमानां द्वितीयां क्रियां सूचयतः। `रामः पठित्वा (पठ्+क्त्वा) क्रीडति।` `सः गुरुं प्रणम्य (प्र+नम्+ल्यप्) पृच्छति।`
        *   **तुमुन्:** क्रियायाः उद्देश्यं दर्शयति। `सः पठितुम् (पठ्+तुमुन्) विद्यालयं गच्छति।`
        *   **शतृ/शानच्:** क्रियां कुर्वन्तं कर्तारं विशेषणरूपेण वर्णयतः। `पठन् (पठ्+शतृ) बालकः।` `कम्पमाना (कम्प्+शानच्) लता।`
        *   **क्तिन्:** क्रियायाः भावं संज्ञा रूपेण प्रकटयति। `तस्य कृतिः (कृ+क्तिन्) श्लाघनीया।`
    *   **तद्धितप्रत्ययाः:** संज्ञा-सर्वनाम-विशेषणशब्दैः सह युज्यन्ते, 'तत् अस्य अस्ति' (मतुप्/इनि), 'तुलना' (तरप्/तमप्), 'विकारः/प्राचुर्यम्' (मयट्) इत्यादि अर्थान् बोधयन्ति। `धनवान् (धन+वतुप्) जनः।` `लघुतरः (लघु+तरप्) वृक्षः।` `स्वर्णमयः (स्वर्ण+मयट्) मुकुटः।`
    *   **स्त्रीप्रत्ययाः:** पुंल्लिङ्गशब्दान् स्त्रीलिङ्गे परिवर्तयन्ति। `अश्व -> अश्वा (टाप्)।` `देव -> देवी (ङीप्)।`

## 🧩 सक्रिय-अधिगमः (Active Learning)

*   **गतिविधिः (Activity): शोध-आधारित-विश्लेषणम् 🔍**
    *   पाठ्यपुस्तके दत्तानाम् अभ्यासानां (यथा - पृ. ९४, अभ्यासः २; पृ. १००, अभ्यासः १; पृ. १०४, अभ्यासः २) वाक्यानि चित्वा तेषु प्रयुक्तान् उपसर्गान्, अव्ययान्, प्रत्ययान् च अन्विष्यत।
    *   प्रत्येकस्य उपसर्गस्य/प्रत्ययस्य/अव्ययस्य प्रकारं लिखत, मूळधातुं/शब्दं च दर्शयत।
    *   तेन पदेन वाक्यस्य अर्थे कः प्रभावः जातः इति लिखत।
    *   स्वयं नूतनानि वाक्यानि रचयत येषु विशिष्टाः उपसर्गाः (उदा. 'अनु', 'प्रति', 'अधि') वा प्रत्ययाः (उदा. 'तुमुन्', 'शतृ', 'मतुप्') प्रयुक्ताः स्युः।
*   **चर्चा (Discussion): वास्तविक-जगति प्रभावस्य आलोचनात्मकं विश्लेषणम् 🌍**
    *   समानधातुना सह विभिन्नोपसर्गाणां संयोगात् उत्पद्यमानानां सूक्ष्म-अर्थभेदानां विषये चर्चां कुरुत (उदा. गम् धातोः - आगच्छति, निर्गच्छति, अवगच्छति, संगच्छते)।
    *   क्त्वा-ल्यप्, शतृ-शानच्, मतुप्-इनि इत्यादिषु प्रत्ययेषु कः भेदः? कदा कस्य प्रयोगः उचितः? उदाहरणैः सह स्पष्टीकुरुत।
    *   अव्ययानां प्रयोगेण वाक्यस्य संरचनायां अर्थे च कथं परिवर्तनं भवति? (उदा. 'सः गच्छति' इत्यस्य 'सः अद्य शनैः तत्र गच्छति' इति वाक्येन सह तुलना)।

## 📝 मूल्याङ्कन-सिद्धता (Assessment Prep)

परीक्षायां सफलतायै अधोनिर्दिष्टेषु विषयेषु ध्यानं दातव्यम्:

1.  **उपसर्ग-प्रत्यय-संयोजनं/विभाजनम्:** दत्तैः उपसर्गैः/प्रत्ययैः सह शब्दान्/धातून् योजयित्वा नूतनपदनिर्माणम् अथवा दत्तेषु पदेषु प्रकृति-प्रत्यय-उपसर्गान् पृथक्करणम्।
    *   उदा. `वि + ज्ञा + ल्यप् = ?` (विज्ञाय); `पठित्वा = ? + ?` (पठ् + क्त्वा)
2.  **रिक्तस्थानपूर्तिः:** कोष्ठके दत्तैः सङ्केतैः (धातु+प्रत्यय/उपसर्ग+धातु+प्रत्यय/अव्यय) उचितं पदं निर्माय रिक्तस्थानानि पूरयत।
    *   उदा. `बालकः पठितुम् (पठ्+तुमुन्) विद्यालयं गच्छति।` `......... (सहसा) निर्णयः न करणीयः।`
3.  **पदचयनम्:** वाक्येषु प्रयुक्तान् उपसर्गान्, अव्ययान्, प्रत्ययान् च चित्वा लिखत।
    *   उदा. `पुरा दशरथः नाम राजा आसीत्।` (अव्ययम् - पुरा)
4.  **लिङ्गपरिवर्तनम्:** स्त्रीप्रत्ययानां प्रयोगं कृत्वा शब्दानां लिङ्गपरिवर्तनम्।
    *   उदा. `बालकः -> बालिका`, `विद्वान् -> विदुषी`, `श्रीमान् -> श्रीमती`
5.  **वाक्यनिर्माणम्:** दत्तैः उपसर्गैः/अव्ययैः/प्रत्ययान्तपदैः सार्थकानि वाक्यानि रचयत।
    *   उदा. ('प्रति' उपसर्गः) `सः प्रतिदिनं पठति।` ('विना' अव्ययम्) `जलेन विना जीवनं नास्ति।` ('गत्वा' पदम्) `अहं गृहं गत्वा भोजनं करिष्यामि।`

## 🌏 भारतीय-सन्दर्भः (Bharatiya Context)

*   **भाषासु प्रभावः:** उपसर्गाः, प्रत्ययाः, अव्ययाः च संस्कृतस्य आधारभूताः घटकाः सन्ति। एतेषां प्रभावः अनेकासु आधुनिक-भारतीय-भाषासु (यथा - हिन्दी, मराठी, ગુજરાતી, বাংলা, कन्नड, तेलुगु इत्यादिषु) स्पष्टतया दृश्यते। अनेके तत्सम-तद्भवशब्दाः एतेषां व्याकरणिक-तत्त्वानां साहाय्येन एव निर्मिताः सन्ति।
    *   **हिन्दी:** विज्ञान (वि+ज्ञान), प्रगति (प्र+गति), अधिकार (अधि+कार), सुन्दरता (सुन्दर+ता), बलवान् (बल+वान्)।
    *   **मराठी:** उपस्थित (उप+स्थित), निर्धन (निर्+धन), पठनीय (पठ्+अनीयर्)।
    *   **বাংলা:** আগমন (आ+गमन), প্রতিদিন (प्रति+दिन), দর্শনীয় (दृश्+अनीयर्)।
*   **सांस्कृतिक-उदाहरणानि:** पाठे आगतानि उदाहरणानि यथा वाल्मीकेः कृतिः रामायणम्, अशोकः राजा च भारतीय-इतिहासस्य संस्कृतेश्च अभिन्नम् अङ्गम्। व्याकरणस्य नियमाः एतेषां ग्रन्थानां, चरित्राणां च अध्ययने साहाय्यं कुर्वन्ति।
*   **दैनन्दिन-प्रयोगः:** पाठे उल्लिखितानि अनेकानि अव्ययानि (यथा - अद्य, श्वः, तत्र, सर्वदा, शनैः, च, अपि) अस्माकं दैनन्दिन-सम्भाषणेषु अपि प्रयुज्यन्ते।
