# Class 9 Sanskrit - Abhyasvan Chapter 107
**Language:** संस्कृतम्

```markdown
# [कक्षा ९] अभ्यासवान् - अध्यायः १०७ (सन्धिः)

## 🌟 मुख्याः अवधारणाः (Core Concepts)

**सन्धिः** नाम वर्णानां मेलनेन जायमानं परिवर्तनम्। यदा द्वौ वर्णौ परस्परं मिलतः, तदा तयोः स्थाने यत् रूपान्तरं भवति, सः सन्धिः इति कथ्यते। वर्णानां संयोगेन शब्दरचनायां परिवर्तनं दृश्यते।

**सन्धि-विच्छेदः** नाम सन्धियुक्तस्य पदस्य वर्णान् पृथक् कृत्वा मूलरूपेण पुनः आनयनम्।

**सन्धेः प्रकाराः (अस्मिन् पाठे चर्चिताः):**

1.  **स्वर-सन्धिः** (Vowel Sandhi): यदा स्वरवर्णयोः मेलनं भवति।
    *   **दीर्घ-सन्धिः** (`अकः सवर्णे दीर्घः`) - समानयोः स्वरयोः मेलनेन दीर्घस्वरः भवति।
    *   **गुण-सन्धिः** (`आद् गुणः`) - अ/आ वर्णयोः पश्चात् इ/ई, उ/ऊ, ऋ/ॠ आगच्छति चेत् क्रमेण ए, ओ, अर् भवति।
    *   **वृद्धि-सन्धिः** (`वृद्धिरेचि`) - अ/आ वर्णयोः पश्चात् ए/ऐ, ओ/औ आगच्छति चेत् क्रमेण ऐ, औ भवति।
    *   **यण्-सन्धिः** (`इको यणचि`) - इ/ई, उ/ऊ, ऋ/ॠ वर्णयोः पश्चात् असमानः स्वरः आगच्छति चेत् क्रमेण य्, व्, र् भवति।
2.  **व्यञ्जन-सन्धिः** (Consonant Sandhi) - (अस्मिन् पाठे केवलं 'मोऽनुस्वारः' नियमस्य चर्चा अस्ति)
    *   **अनुस्वार-सन्धिः** (`मोऽनुस्वारः`) - पदान्ते 'म्' वर्णस्य पश्चात् व्यञ्जनवर्णः आगच्छति चेत् 'म्' स्थाने अनुस्वारः (ं) भवति। स्वरः आगच्छति चेत् संयोगः भवति।
3.  **विसर्ग-सन्धिः** (Visarga Sandhi) - (पाठ्यपुस्तके अस्य उल्लेखः अस्ति, परन्तु अस्मिन् अभ्यासे विस्तरेण न चर्चितः।)

## 📘 प्रमुख-शिक्षणबिन्दवः (Key Learnings)

अत्र पाठे वर्णिताः सन्धयः विस्तरेण दीयन्ते:

**1. दीर्घ-सन्धिः (`अकः सवर्णे दीर्घः`)**
   - **नियमः:** यदि ह्रस्व-दीर्घयोः (अ, इ, उ, ऋ) वर्णानां पश्चात् सः एव समानः ह्रस्वः वा दीर्घः वा वर्णः आगच्छति, तर्हि उभयोः स्थाने सः एव दीर्घः वर्णः भवति।
   - **उदाहरणानि:**
     *   अ/आ + अ/आ = आ (सूर्य + आतपे = सूर्यात्पे; लोभ + आकृष्टा = लोभाकृष्टा)
     *   इ/ई + इ/ई = ई (अति + इव = अतीव; कपि + इन्द्रः = कपीन्द्रः)
     *   उ/ऊ + उ/ऊ = ऊ (गुरु + उपदेशः = गुरूपदेशः; भानु + उदयः = भानूदयः)
     *   ऋ/ॠ + ऋ/ॠ = ॠॄ (पितृ + ऋणम् = पितॄणम्; मातृ + ऋद्धिः = मातॄद्धिः)

**2. गुण-सन्धिः (`आद् गुणः`)**
   - **नियमः:** यदि 'अ' वा 'आ' वर्णस्य पश्चात् 'इ' वा 'ई' आगच्छति, तर्हि उभयोः स्थाने 'ए' भवति। यदि 'उ' वा 'ऊ' आगच्छति, तर्हि उभयोः स्थाने 'ओ' भवति। यदि 'ऋ' वा 'ॠ' आगच्छति, तर्हि उभयोः स्थाने 'अर्' भवति।
   - **उदाहरणानि:**
     *   अ/आ + इ/ई = ए (अनेन + इति = अनेनेति; यथा + इच्छा = यथेच्छा; माता + इव = मातेव)
     *   अ/आ + उ/ऊ = ओ (वृक्षस्य + उपरि = वृक्षस्योपरि; सूर्य + उदयात् = सूर्योदयात्; गृह + उद्यानम् = गृहोद्यानम्)
     *   अ/आ + ऋ/ॠ = अर् (महा + ऋषिः = महर्षिः; देव + ऋषिः = देवर्षिः; वसन्त + ऋतुः = वसन्तर्तुः)

**3. वृद्धि-सन्धिः (`वृद्धिरेचि`)**
   - **नियमः:** यदि 'अ' वा 'आ' वर्णस्य पश्चात् 'ए' वा 'ऐ' आगच्छति, तर्हि उभयोः स्थाने 'ऐ' भवति। यदि 'ओ' वा 'औ' आगच्छति, तर्हि उभयोः स्थाने 'औ' भवति।
   - **उदाहरणानि:**
     *   अ/आ + ए/ऐ = ऐ (गत्वा + एव = गत्वैव; क्षणेन + एव = क्षणेनैव; न + एतादृशः = नैतादृशः; महा + ऐरावतः = महैरावतः)
     *   अ/आ + ओ/औ = औ (जल + ओघः = जलौघः; तव + औदार्यम् = तवौदार्यम्; वन + औषधिः = वनौषधिः; महा + औत्सुक्येन = महौत्सुक्येन)

**4. यण्-सन्धिः (`इको यणचि`)**
   - **नियमः:** यदि 'इ/ई', 'उ/ऊ', 'ऋ/ॠ' वर्णानां पश्चात् कोऽपि असमानः (भिन्नः) स्वरवर्णः आगच्छति, तर्हि 'इ/ई' स्थाने 'य्', 'उ/ऊ' स्थाने 'व्', 'ऋ/ॠ' स्थाने 'र्' भवति। परवर्ती स्वरः य्/व्/र् इत्येतैः सह मात्रा रूपेण युज्यते।
   - **उदाहरणानि:**
     *   इ/ई + असमानस्वरः = य् + स्वरः (प्रति + अवदत् = प्रत्यवदत्; यदि + अहम् = यद्यहम्; तानि + एव = तान्येव; परि + आवरणम् = पर्यावरणम्)
     *   उ/ऊ + असमानस्वरः = व् + स्वरः (खलु + अयम् = खल्वयम्; मधु + अरिः = मध्वरिः; सु + आगतम् = स्वागतम्)
     *   ऋ/ॠ + असमानस्वरः = र् + स्वरः (पितृ + आदेशः = पित्रादेशः; मातृ + आज्ञा = मात्राज्ञा; भ्रातृ + इच्छा = भ्रात्रिच्छा)

**5. अनुस्वार-सन्धिः (`मोऽनुस्वारः`)**
   - **नियमः:** यदि पदस्य अन्ते स्थितस्य 'म्' वर्णस्य पश्चात् कोऽपि व्यञ्जनवर्णः आगच्छति, तर्हि 'म्' वर्णस्य स्थाने अनुस्वारः (ं) भवति। यदि 'म्' पश्चात् स्वरवर्णः आगच्छति, तर्हि सः स्वरः 'म्' इत्यनेन सह मिलति (संयोगः भवति)।
   - **उदाहरणानि:**
     *   म् + व्यञ्जनम् = ं (त्वम् + यासि = त्वं यासि; किम् + कथयति = किं कथयति)
     *   म् + स्वरः = म् + स्वरः (संयोगः) (अहम् + इच्छामि = अहमिच्छामि; हृदयम् + इच्छति = हृदयमिच्छति)

## 🌏 भारतीयः सन्दर्भः (Bharatiya Context)

*   **पाणिनीय-व्याकरणम्:** सन्धेः नियमाः महर्षिणा **पाणिनिना** विरचिते विश्वप्रसिद्धे व्याकरण-ग्रन्थे **'अष्टाध्यायी'** मध्ये सूत्ररूपेण निबद्धाः सन्ति। इयं सहस्राधिकवर्षेभ्यः प्राचीना भारतीय-ज्ञान-परम्परायाः अद्भुतः निधिः अस्ति। (`अकः सवर्णे दीर्घः`, `आद् गुणः`, `वृद्धिरेचि`, `इको यणचि`, `मोऽनुस्वारः` इत्यादयः सूत्राणि पाणिनिना एव प्रणीतानि)।
*   **भाषा-सौष्ठवम्:** सन्धिः संस्कृतभाषायाः प्रवाहमयतां, सङ्क्षिप्ततां, श्रुतिमधुरतां च वर्धयति। शब्दानां मेलनेन नूतनाः अर्थाः अपि कदाचित् व्यज्यन्ते।
*   **ग्रन्थ-पठनम्:** वेद-उपनिषद्-पुराण-रामायण-महाभारतादीनां सर्वेषां शास्त्रीय-ग्रन्थानां सम्यक् अवगमनाय सन्धिज्ञानम् अनिवार्यम् अस्ति। अनेन एव शब्दानां मूलरूपं, तेषां सम्बन्धं च ज्ञातुं शक्यते।
```
