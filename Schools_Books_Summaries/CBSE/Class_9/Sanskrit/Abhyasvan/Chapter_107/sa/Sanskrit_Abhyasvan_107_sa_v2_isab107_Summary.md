## 🌟 आधारभूताः संकल्पनाः (Core Concepts)

**सन्धिः** इत्युक्ते वर्णानां मेलनम्। यदा द्वौ वर्णौ अत्यन्तं समीपं भवतः, तदा तयोः मेलनेन यत् परिवर्तनं जायते, सः **सन्धिः** कथ्यते। सन्धियुक्तानां शब्दानां पूर्व-उत्तरपदयोः पृथक्करणं **सन्धिविच्छेदः** इति कथ्यते।

## 📘 मुख्याः शिक्षणबिन्दवः (Key Learnings)

अत्र वयं स्वरसन्धेः प्रमुखान् भेदान्, अनुस्वारसन्धिं च विस्तरेण पठामः।

**1. दीर्घसन्धिः (Dirgha Sandhi)**
*   **सूत्रम्:** अकः सवर्णे दीर्घः।
*   **नियमः:** यदि ह्रस्वस्य (अ, इ, उ, ऋ) अथवा दीर्घस्य (आ, ई, ऊ, ॠ) स्वरस्य पश्चात् सः एव ह्रस्वः वा दीर्घः स्वरः आगच्छति, तर्हि उभयोः स्थाने एकः **दीर्घः स्वरः** (आ, ई, ऊ, ॠ) भवति।
    *   अ/आ + अ/आ = **आ** (यथा - सूर्य + आतपे = सूर्यातपे)
    *   इ/ई + इ/ई = **ई** (यथा - अति + इव = अतीव)
    *   उ/ऊ + उ/ऊ = **ऊ** (यथा - गुरु + उपदेशः = गुरूपदेशः)
    *   ऋ/ॠ + ऋ/ॠ = **ॠ** (यथा - पितृ + ऋणम् = पितॄणम्)
*   **उदाहरणानि:**
    *   लोभ + आकृष्टा = लोभाकृष्टा
    *   नदी + इयम् = नदीयम्
    *   भानु + उदयः = भानूदयः
    *   मातृ + ऋद्धिः = मातॄद्धिः

**2. गुणसन्धिः (Guna Sandhi)**
*   **सूत्रम्:** आद् गुणः।
*   **नियमः:** यदि 'अ' अथवा 'आ' वर्णस्य पश्चात् इ/ई, उ/ऊ, ऋ/ॠ वर्णाः आगच्छन्ति, तर्हि क्रमेण **ए, ओ, अर्** आदेशाः भवन्ति।
    *   अ/आ + इ/ई = **ए** (यथा - अनेन + इति = अनेनेति)
    *   अ/आ + उ/ऊ = **ओ** (यथा - वृक्षस्य + उपरि = वृक्षस्योपरि)
    *   अ/आ + ऋ/ॠ = **अर्** (यथा - महा + ऋषिः = महर्षिः)
*   **उदाहरणानि:**
    *   यथा + इच्छया = यथेच्छया
    *   सूर्य + उदयात् = सूर्योदयात्
    *   देव + ऋषिः = देवर्षिः
    *   वसन्त + ऋतुः = वसन्तर्तुः

**3. वृद्धिसन्धिः (Vriddhi Sandhi)**
*   **सूत्रम्:** वृद्धिरेचि।
*   **नियमः:** यदि 'अ' अथवा 'आ' वर्णस्य पश्चात् ए/ऐ अथवा ओ/औ वर्णाः आगच्छन्ति, तर्हि क्रमेण **ऐ, औ** आदेशौ भवतः।
    *   अ/आ + ए/ऐ = **ऐ** (यथा - गत्वा + एव = गत्वैव)
    *   अ/आ + ओ/औ = **औ** (यथा - जल + ओघः = जलौघः)
*   **उदाहरणानि:**
    *   क्षणेन + एव = क्षणेनैव
    *   न + एतादृशः = नैतादृशः
    *   तव + औदार्यम् = तवौदार्यम्
    *   महा + औषधिः = महौषधिः

**4. यण्सन्धिः (Yan Sandhi)**
*   **सूत्रम्:** इको यणचि।
*   **नियमः:** यदि इ/ई, उ/ऊ, ऋ/ॠ वर्णानां पश्चात् कोऽपि **असमानः** (भिन्नः) स्वरः आगच्छति, तर्हि इ/ई स्थाने **य्**, उ/ऊ स्थाने **व्**, ऋ/ॠ स्थाने **र्** आदेशाः भवन्ति। परवर्ती स्वरः मात्रा रूपेण तैः सह युज्यते।
    *   इ/ई + असमानस्वरः = **य्** + असमानस्वरः (यथा - प्रति + अवदत् = प्रत्यवदत्)
    *   उ/ऊ + असमानस्वरः = **व्** + असमानस्वरः (यथा - खलु + अयम् = खल्वयम्)
    *   ऋ/ॠ + असमानस्वरः = **र्** + असमानस्वरः (यथा - पितृ + आदेशः = पित्रादेशः)
*   **उदाहरणानि:**
    *   यदि + अहम् = यद्यहम्
    *   मधु + अरिः = मध्वरिः
    *   स्वागतम् = सु + आगतम्
    *   मातृ + आज्ञा = मात्राज्ञा

**5. अनुस्वारसन्धिः (Anusvara Sandhi)**
*   **सूत्रम्:** मोऽनुस्वारः।
*   **नियमः:** यदि पदस्य अन्ते स्थितस्य 'म्' वर्णस्य पश्चात् कोऽपि **व्यञ्जनवर्णः** आगच्छति, तर्हि 'म्' वर्णस्य स्थाने **अनुस्वारः (ं)** भवति। यदि 'म्' पश्चात् **स्वरवर्णः** आगच्छति, तर्हि 'म्' परवर्तिना स्वरेण सह मिलति।
    *   म् + व्यञ्जनम् = **ं** + व्यञ्जनम् (यथा - त्वम् + यासि = त्वं यासि)
    *   म् + स्वरः = म् + स्वरः (संयोगः) (यथा - अहम् + इच्छामि = अहमिच्छामि)
*   **उदाहरणानि:**
    *   किम् + कथयति = किं कथयति
    *   अयम् + राजा = अयं राजा
    *   हृदयम् + इच्छति = हृदयमिच्छति

## 🌏 भारतीयः सन्दर्भः (Bharatiya Context)

*   **भाषासु प्रभावः:** सन्धिप्रक्रिया न केवलं संस्कृतस्य अपितु अनेकासां आधुनिक-भारतीय-भाषाणाम् (यथा - हिन्दी, मराठी, बङ्गला, ગુજરાતી इत्यादयः) व्याकरणस्य अभिन्नम् अङ्गम् अस्ति। 'विद्यालयः' (विद्या+आलयः), 'सूर्योदयः' (सूर्य+उदयः), 'महोत्सवः' (महा+उत्सवः) इत्यादयः सन्धियुक्ताः शब्दाः अनेकासु भाषासु समानाः अथवा समानान्तररूपेण प्रयुज्यन्ते।
*   **पाणिनेः योगदानम्:** महर्षिणा पाणिनिना स्वस्य 'अष्टाध्यायी' नामके विश्वप्रसिद्धे व्याकरणग्रन्थे सन्धि-नियमानां वैज्ञानिकरीत्या, सूत्रबद्धरूपेण च विश्लेषणं कृतम्। एतत् भारतस्य प्राचीनं भाषावैज्ञानिकं गौरवं, विश्लेषणक्षमतां च प्रदर्शयति।
*   **साहित्ये प्रयोगः:** वेदाः, उपनिषदः, रामायणम्, महाभारतम्, पुराणानि, काव्यानि इत्यादिषु सर्वेषु संस्कृतवाङ्मयेषु सन्धेः व्यापकः प्रयोगः दृश्यते। सन्धिज्ञानं विना एतेषां ग्रन्थानां सम्यक् अर्थावबोधः कठिनः भवति।
