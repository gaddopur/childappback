# Class 9 Sanskrit - Abhyasvan Chapter 107
**Language:** संस्कृतम्

```markdown
# [कक्षा ९] अभ्यासवान् - अध्यायः १०७ (सन्धिः)

## 🌟 मुख्याः अवधारणाः (Core Concepts)

अस्मिन् पाठे वयं सन्धेः विषये पठामः। सन्धिः अर्थात् वर्णानां मेलनेन यत् परिवर्तनं भवति।

1.  **सन्धिः**
    *   परिभाषा: द्वयोः वर्णयोः मेलनेन यः विकारः (परिवर्तनम्) जायते, सः सन्धिः इति कथ्यते। (यथा - सूर्य + आतपे = सूर्यात्)
    *   प्रयोजनम्: शब्दानां संक्षेपणम्, उच्चारणसौकर्यम्, भाषायां प्रवाहः च।
2.  **सन्धिविच्छेदः**
    *   परिभाषा: सन्धियुक्तस्य पदस्य वर्णान् पृथक् कृत्वा पूर्वपदरूपेण उत्तरपदरूपेण च दर्शनं सन्धिविच्छेदः कथ्यते। (यथा - नृपोऽवदत् = नृपः + अवदत्)
3.  **सन्धेः प्रकाराः**
    *   **स्वरसन्धिः**: यदा स्वरवर्णेन सह स्वरवर्णस्य मेलनं भवति।
        *   **दीर्घसन्धिः**: (सूत्रम् - अकः सवर्णे दीर्घः) - समानयोः स्वरयोः मेलनेन दीर्घस्वरः भवति (अ/आ + अ/आ = आ; इ/ई + इ/ई = ई; उ/ऊ + उ/ऊ = ऊ; ऋ/ॠ + ऋ/ॠ = ॠॄ)।
        *   **गुणसन्धिः**: (सूत्रम् - आद् गुणः) - अ/आ इत्यस्मात् परम् इ/ई, उ/ऊ, ऋ/ॠ आगच्छति चेत् क्रमशः ए, ओ, अर् भवति।
        *   **वृद्धिसन्धिः**: (सूत्रम् - वृद्धिरेचि) - अ/आ इत्यस्मात् परम् ए/ऐ, ओ/औ आगच्छति चेत् क्रमशः ऐ, औ भवति।
        *   **यण्सन्धिः**: (सूत्रम् - इको यणचि) - इ/ई, उ/ऊ, ऋ/ॠ इत्येतेभ्यः परम् असमानः स्वरः आगच्छति चेत् क्रमशः य्, व्, र् भवति।
    *   **व्यञ्जनसन्धिः**: यदा व्यञ्जनवर्णेन सह स्वरस्य अथवा व्यञ्जनस्य मेलनं भवति। (अस्मिन् पाठे 'मोऽनुस्वारः' इति नियमः चर्चितः)।
        *   **अनुस्वारसन्धिः**: (सूत्रम् - मोऽनुस्वारः) - पदान्ते स्थितस्य 'म्' वर्णस्य पश्चात् यदि कोऽपि व्यञ्जनवर्णः आगच्छति, तर्हि 'म्' स्थाने अनुस्वारः (ं) भवति। यदि स्वरवर्णः आगच्छति, तर्हि 'म्' वर्णः तेन स्वरेण सह युज्यते।
    *   **विसर्गसन्धिः**: यदा विसर्गेण सह स्वरस्य अथवा व्यञ्जनस्य मेलनं भवति। (अस्मिन् पाठे अस्य विस्तरः नास्ति, परन्तु उदाहरणम् अस्ति - नृपः + अवदत् = नृपोऽवदत्)।

## 📘 प्रमुखाः शिक्षणबिन्दवः (Key Learnings)

अत्र स्वरसन्धेः केचन भेदाः, एकः व्यञ्जनसन्धिभेदः च सोदाहरणं स्पष्टीक्रियन्ते।

1.  **दीर्घसन्धिः (अकः सवर्णे दीर्घः)**
    *   **नियमः**: यदि ह्रस्वस्वरात् (अ, इ, उ, ऋ) अथवा दीर्घस्वरात् (आ, ई, ऊ, ॠ) परं सः एव ह्रस्वः वा दीर्घः स्वरः आगच्छति, तर्हि द्वयोः स्थाने सः एव दीर्घस्वरः (आ, ई, ऊ, ॠॄ) भवति।
    *   **उदाहरणानि**:
        *   (अ+आ=आ) लोभ + आकृष्टा = लोभाकृष्टा
        *   (इ+ई=ई) कपि + ईशः = कपीशः
        *   (उ+उ=ऊ) गुरु + उपदेशः = गुरूपदेशः
        *   (ऋ+ऋ=ॠॄ) पितृ + ऋणम् = पितॄणम्

2.  **गुणसन्धिः (आद् गुणः)**
    *   **नियमः**: यदि 'अ' अथवा 'आ' वर्णयोः पश्चात् 'इ'/'ई', 'उ'/'ऊ', 'ऋ'/'ॠ' वर्णाः आगच्छन्ति, तर्हि क्रमेण 'ए', 'ओ', 'अर्' आदेशाः भवन्ति।
    *   **उदाहरणानि**:
        *   (अ+इ=ए) अनेन + इति = अनेनेति
        *   (आ+इ=ए) यथा + इच्छा = यथेच्छा
        *   (अ+उ=ओ) वृक्षस्य + उपरि = वृक्षस्योपरि
        *   (आ+ऋ=अर्) महा + ऋषिः = महर्षिः

3.  **वृद्धिसन्धिः (वृद्धिरेचि)**
    *   **नियमः**: यदि 'अ' अथवा 'आ' वर्णयोः पश्चात् 'ए'/'ऐ' अथवा 'ओ'/'औ' वर्णाः आगच्छन्ति, तर्हि क्रमेण 'ऐ' तथा 'औ' आदेशौ भवतः।
    *   **उदाहरणानि**:
        *   (अ+ए=ऐ) गत्वा + एव = गत्वैव
        *   (आ+ऐ=ऐ) महा + ऐरावतः = महैरावतः
        *   (अ+ओ=औ) जल + ओघः = जलौघः
        *   (आ+औ=औ) महा + औषधम् = महौषधम्

4.  **यण्सन्धिः (इको यणचि)**
    *   **नियमः**: यदि 'इ'/'ई', 'उ'/'ऊ', 'ऋ'/'ॠ' वर्णानन्तरम् कोऽपि असमानः (भिन्नः) स्वरवर्णः आगच्छति, तर्हि 'इ'/'ई' स्थाने 'य्', 'उ'/'ऊ' स्थाने 'व्', 'ऋ'/'ॠ' स्थाने 'र्' आदेशाः भवन्ति। परवर्ती स्वरः मात्रा रूपेण य्/व्/र् इत्येतैः सह युज्यते।
    *   **उदाहरणानि**:
        *   (इ+अ=य्) प्रति + अवदत् = प्रत्यवदत्
        *   (उ+अ=व्) खलु + अयम् = खल्वयम्
        *   (ऋ+आ=रा) पितृ + आदेशः = पित्रादेशः
        *   (ई+अ=य्) यदि + अपि = यद्यपि
        *   (ऊ+अ=व्) वधू + आगमनम् = वध्वागमनम्

5.  **अनुस्वारसन्धिः (मोऽनुस्वारः)**
    *   **नियमः**: पदस्य अन्ते वर्तमानस्य 'म्' वर्णस्य पश्चात् यदि कोऽपि व्यञ्जनवर्णः भवति, तर्हि 'म्' स्थाने अनुस्वारः (ं) भवति।
    *   **नियमः (संयोगः)**: यदि 'म्' वर्णस्य पश्चात् कोऽपि स्वरवर्णः भवति, तर्हि सः स्वरः 'म्' वर्णेन सह मिलति (संयोगः भवति)।
    *   **उदाहरणानि**:
        *   (म् + व्यञ्जनम् = ं) त्वम् + यासि = त्वं यासि
        *   (म् + व्यञ्जनम् = ं) किम् + कथयति = किं कथयति
        *   (म् + स्वरः = संयोगः) अहम् + इच्छामि = अहमिच्छामि
        *   (म् + स्वरः = संयोगः) हृदयम् + इच्छति = हृदयमिच्छति

## 🧩 सक्रिय-अधिगमः (Active Learning)

*   **गतिविधिः (Activity):** 🔍 स्वपाठ्यपुस्तकात् कस्याश्चित् कथायाः अथवा संवादस्य भागं पठित्वा तत्र आगतानि न्यूनातिन्यूनं दश सन्धिपदानि चिनुत। तेषां सन्धिविच्छेदं कृत्वा सन्धेः नाम अपि लिखत। (उदाहरणार्थम् - पञ्चतन्त्रकथाः, हितोपदेशकथाः वा)। अनेन वास्तविक-सन्दर्भेषु सन्धि-प्रयोगस्य अवगमनं दृढं भविष्यति।
*   **विमर्शः (Discussion):** 🌍 कक्षायां चर्चां कुरुत - "संस्कृतभाषायाः पठने, श्रवणे, भाषणे, लेखने च सन्धेः किं महत्त्वम् अस्ति? यदि सन्धिः न स्यात् तर्हि भाषायां किं परिवर्तनं भवेत्?" अस्मिन् विषये स्वविचारान् प्रकटयन्तु। सन्धेः प्रयोगेण भाषायां किं सौन्दर्यं, का सुगमता च आगच्छति इति विश्लेषयन्तु।

## 📝 मूल्याङ्कन-सिद्धता (Assessment Prep)

परीक्षायां सन्धि-सम्बद्धाः प्रश्नाः एवं भवितुम् अर्हन्ति:

1.  **सन्धिं कुरुत:** पदद्वयं दत्तं भविष्यति, तयोः मेलनेन सन्धियुक्तं पदं रचयितव्यम्।
    *   यथा - विद्या + अर्थी = ? ; सदा + एव = ? ; सु + आगतम् = ? ; अहम् + पठामि = ?
2.  **सन्धिविच्छेदं कुरुत:** सन्धियुक्तं पदं दत्तं भविष्यति, तस्य विच्छेदः करणीयः।
    *   यथा - देवालयः = ? + ? ; यद्यपि = ? + ? ; पवनः = ? + ? ; तवैव = ? + ?
3.  **सन्धेः नाम लिखत:** सन्धिं कृत्वा अथवा विच्छेदं कृत्वा तस्य सन्धेः नाम अपि लेखनीयम्।
    *   यथा - नर + इन्द्रः = नरेन्द्रः (अत्र कः सन्धिः?) ; इत्यादि = इति + आदि (अत्र कः सन्धिः?)

*   **अभ्यासार्थं पदानि:** (उत्तराणि अन्ते दत्तानि)
    *   सन्धिं कुरुत: १. महा + उत्सवः २. इति + अलम् ३. तत् + मात्रम् ४. किम् + चित्
    *   विच्छेदं कुरुत: १. गायकः २. प्रत्येकम ३. महर्षिः ४. रामोऽवदत्
*   **सूत्राणां स्मरणम्:** 'अकः सवर्णे दीर्घः', 'आद् गुणः', 'वृद्धिरेचि', 'इको यणचि', 'मोऽनुस्वारः' इत्यादीनि सूत्राणि तेषां नियमाः च अवधेयाः।

*(उत्तराणि: सन्धिं कुरुत - १. महोत्सवः (गुणसन्धिः) २. इत्यलम् (यण्सन्धिः) ३. तन्मात्रम् (व्यञ्जनसन्धिः - अनुनासिकः) ४. किञ्चित् (व्यञ्जनसन्धिः - अनुस्वारः/परसवर्णः)। विच्छेदं कुरुत - १. गै + अकः (अयादिसन्धिः) २. प्रति + एकम् (यण्सन्धिः) ३. महा + ऋषिः (गुणसन्धिः) ४. रामः + अवदत् (विसर्गसन्धिः - उत्वम्, पूर्वरूपम् च))*

## 🌏 भारतीयः सन्दर्भः (Bharatiya Context)

*   **भाषायाः वैज्ञानिकता:** संस्कृतं भारतस्य एका प्राचीना, शास्त्रीया च भाषा अस्ति। सन्धिप्रक्रिया अस्याः भाषायाः वैज्ञानिक्याः संरचनायाः एकं महत्त्वपूर्णम् अङ्गम् अस्ति। 📊 वर्णानां मेलनेन ध्वनिषु परिवर्तनस्य नियमाः (सन्धिः) भाषां अधिकं तर्कसङ्गतां प्रवाहयुक्तां च कुर्वन्ति।
*   **साहित्ये उपयोगः:** वेद-उपनिषद्-पुराण-रामायण-महाभारतादिषु ग्रन्थेषु, तथैव कालिदास-भास-भवभूति-प्रभृतीनां कवीनां काव्येषु नाटकषु च सन्धेः विपुलः प्रयोगः दृश्यते। 📜 सन्धिज्ञानं विना एतेषां ग्रन्थानां सम्यक् अर्थावबोधः कठिनः भवति।
*   **उच्चारणसौष्ठवम्:** सन्धिः शब्दानां निरन्तरम् उच्चारणं सुकरं करोति, येन मन्त्राणाम्, श्लोकानां च पाठे लयः सौष्ठवं च आयाति। 🎶 उदाहरणार्थम्, 'नमः शिवाय' इत्यस्य स्थाने 'नमश्शिवाय' इति सन्धिना उच्चारणं सहजं भवति।
*   **शब्दनिर्माणम्:** सन्धिप्रक्रिया नूतनशब्दानां निर्माणे अपि सहायिका भवति, यथा उपसर्गैः धातुभिः प्रत्ययैः च सह शब्दानां मेलनेन। एषा प्रक्रिया भाषायाः शब्दभण्डारं समृद्धं करोति।

सन्धिज्ञानं न केवलं परीक्षादृष्ट्या महत्त्वपूर्णम्, अपितु संस्कृतभाषायाः गहन-अवगमनाय, भारतीय-वाङ्मयस्य आस्वादनाय च अत्यावश्यकम् अस्ति।
```
