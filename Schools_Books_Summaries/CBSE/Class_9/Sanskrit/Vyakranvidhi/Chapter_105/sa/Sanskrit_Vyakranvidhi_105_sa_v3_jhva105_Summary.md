# Class 9 Sanskrit - Vyakranvidhi Chapter 105

# [कक्षा ९] व्याकरणवीथिः - अध्यायः १०५ (धातुरूप-सामान्यपरिचयः)

## 🌟 मूल-अवधारणाः (Core Concepts)

अस्मिन् पाठे वयं क्रियापदानां मूलरूपं 'धातुः' इति विषये पठामः। धातुरूपाणां संरचना तथा प्रयोगः अधः प्रदत्त-सोपानक्रमेण ज्ञायते 📊:

1.  **क्रियापदम्**: येन शब्देन कस्यापि कार्यस्य करणं वा होणं वा ज्ञायते, सः क्रियापदम्।
    *   **उदाहरणम्**: रामः पुस्तकं **पठति**। अत्र 'पठति' क्रियापदम् अस्ति।
2.  **धातुः**: क्रियापदस्य मूलरूपं धातुः कथ्यते।
    *   **उदाहरणम्**: 'पठति' इत्यस्य मूलरूपं '**पठ्**' धातुः अस्ति।
3.  **धातूनां गणाः**: संस्कृते अर्थानुसारं धातवः **दशसु (१०) गणेषु** विभक्ताः सन्ति।
    *   भ्वादिगणः (आधारः - भू धातुः)
    *   अदादिगणः (अद्)
    *   जुहोत्यादिगणः (हु)
    *   दिवादिगणः (दिव्)
    *   स्वादिगणः (सु)
    *   रुधादिगणः (रुध्)
    *   तुदादिगणः (तुद्)
    *   तनादिगणः (तन्)
    *   क्र्यादिगणः (क्री)
    *   चुरादिगणः (चुर्)
4.  **पदभेदेन धातवः**: प्रयोगानुसारं धातवः त्रिविधाः भवन्ति -
    *   **परस्मैपदिनः**: येषां क्रियाफलं परगामि भवति (प्रायः)। प्रत्ययाः - ति, तः, अन्ति इत्यादयः। (यथा - पठ्, गम्, लिख्)
    *   **आत्मनेपदिनः**: येषां क्रियाफलं कर्तृगामि भवति (प्रायः)। प्रत्ययाः - ते, इते, अन्ते इत्यादयः। (यथा - सेव्, लभ्, मुद्)
    *   **उभयपदिनः**: ये परस्मैपदे आत्मनेपदे च प्रयुज्यन्ते। (यथा - कृ [करोति/कुरुते], पच् [पचति/पचते])
        *   *विशेषः*: उभयपदिषु यदि क्रियाफलं कर्तारं गच्छति तर्हि आत्मनेपदम्, यदि अन्यं गच्छति तर्हि परस्मैपदं प्रयुज्यते।
5.  **लकाराः**: कालान् तथा अर्थान् (moods) बोधयितुं संस्कृते **दश (१०) लकाराः** सन्ति।
    *   लट् (वर्तमानकालः)
    *   लिट् (परोक्षभूतकालः - ऐतिहासिकः)
    *   लुट् (अनद्यतनभविष्यत्कालः)
    *   लृट् (सामान्यभविष्यत्कालः)
    *   लेट् (वेदेषु प्रयुक्तः)
    *   लोट् (आज्ञा/अनुज्ञा अर्थः)
    *   लङ् (अनद्यतनभूतकालः)
    *   विधिलिङ् (विधिः/सम्भावना - 'चाहिए' अर्थः)
    *   आशीर्लिङ् (आशीर्वादार्थः - लिङः भेदः)
    *   लुङ् (सामान्यभूतकालः)
    *   लृङ् (क्रियातिपत्तिः - हेतुहेतुमद्भावः/Conditional)
6.  **पाठ्यक्रम-निर्धारिताः पञ्च लकाराः**: माध्यमिकस्तरे मुख्यतया पञ्च लकाराः पठ्यन्ते -
    *   **लट्** (वर्तमानकालः)
    *   **लङ्** (भूतकालः - अनद्यतन)
    *   **लृट्** (भविष्यत्कालः - सामान्य)
    *   **लोट्** (आज्ञार्थकः)
    *   **विधिलिङ्** ('चाहिए' योगे)
7.  **प्रत्ययाः**: धातुभिः सह संयोज्य रूपाणि निर्मातुं प्रत्ययाः प्रयुज्यन्ते। परस्मैपदे आत्मनेपदे च नव-नव (९+९) प्रत्ययाः भवन्ति, ये त्रिषु पुरुषेषु (प्रथमः, मध्यमः, उत्तमः) त्रिषु वचनेषु (एकवचनम्, द्विवचनम्, बहुवचनम्) च विभक्ताः सन्ति।

## 📘 मुख्य-शिक्षणांशाः (Key Learnings)

अस्मिन् अध्याये वयं धातुरूपाणां महत्त्वपूर्णान् पक्षान् सरलतया अवगच्छामः 📈:

1.  **धातुपरिचयः**: क्रियायाः मूलं धातुः। यथा - 'गच्छति' इत्यत्र 'गम्' धातुः।
2.  **गणव्यवस्था**: दश गणाः धातुषु विकरणप्रत्ययान् (गणानुसारं मध्ये आगच्छन्तः प्रत्ययाः) निर्धारयन्ति, येन रूपनिर्माणं भिद्यते। (यथा - भ्वादिगणे 'शप्' विकरणः - भू+अ+ति = भवति)।
3.  **पदव्यवस्था**: परस्मैपदी (यथा - सः पठति), आत्मनेपदी (यथा - छात्रः लभते), उभयपदी (यथा - सः कार्यं करोति/कुरुते) इति भेदः प्रत्ययेषु परिवर्तनम् आनयति।
4.  **लकारज्ञानम्**: प्रत्येकं लकारः विशिष्टं कालं वा अर्थं वा सूचयति।
    *   **लट्**: अहं पठामि। (वर्तमानः)
    *   **लङ्**: सः अगच्छत्। (ह्यः गतः)
    *   **लृट्**: त्वं लेखिष्यसि। (श्वः वा कदाचित्)
    *   **लोट्**: यूयं पठत। (आज्ञा)
    *   **विधिलिङ्**: वयं पठेम। (अस्माभिः पठनीयम्)
5.  **पञ्चलकारेषु प्रत्ययाः**: छात्राणां सौकर्याय पञ्चसु प्रमुखलकारेषु परस्मैपदस्य आत्मनेपदस्य च प्रत्ययाः तालिका रूपेण प्रदत्ताः, येषां स्मरणेन रूपनिर्माणं सुकरं भवति।

    **उदाहरणम् - लट् लकारः (वर्तमानकालः)**
    | पुरुषः    | एकवचनम् | द्विवचनम् | बहुवचनम् | | एकवचनम् | द्विवचनम् | बहुवचनम् |
    | :-------- | :------: | :-------: | :-------: |---| :------: | :-------: | :-------: |
    |           | **परस्मैपदम्** |           |           | | **आत्मनेपदम्** |           |           |
    | प्रथमपुरुषः |   -ति    |    -तः   |   -अन्ति  | |   -ते    |    -इते   |   -अन्ते  |
    | मध्यमपुरुषः |   -सि    |    -थः   |    -थ    | |   -से    |    -इथे   |   -ध्वे   |
    | उत्तमपुरुषः |   -मि    |    -वः   |    -मः   | |   -इ     |    -वहे   |   -महे   |

    *(एवमेव लङ्, लृट्, लोट्, विधिलिङ् लकाराणाम् अपि प्रत्ययाः पुस्तके प्रदत्ताः)*

6.  **रूपसिद्धिः (उदाहरणम्)**: 'पठ्' (परस्मैपदी) तथा 'सेव्' (आत्मनेपदी) धातोः पञ्चसु लकारेषु रूपाणि उदाहरणरूपेण दर्शितानि।
    *   **पठ् - लट्**: पठति, पठतः, पठन्ति...
    *   **सेव् - लट्**: सेवते, सेवेते, सेवन्ते...
    *   **पठ् - लङ्**: अपठत्, अपठताम्, अपठन्...
    *   **सेव् - लङ्**: असेवत, असेवेताम्, असेवन्त... (इत्यादि)

    *   सरलानि संस्कृतवाक्यानि (यथा - पञ्चतन्त्रकथाभ्यः, हितोपदेशात्) चित्वा तेषु प्रयुक्तानि क्रियापदानि अधोरेखितानि कुर्वन्तु।
    *   तेषां क्रियापदानां मूलधातुम्, लकारम्, पुरुषम्, वचनं च लिखन्तु। (उदा. - 'एकः काकः **आसीत्**।' -> आसीत् - अस् धातुः, लङ् लकारः, प्रथमपुरुषः, एकवचनम्)।
2.  **चर्चा (Discussion) 🌍**:
    *   "संस्कृतसम्भाषणे लेखने च शुद्धधातुरूपाणां प्रयोगः कथं महत्त्वपूर्णः?" इति विषये कक्षायां चर्चां कुर्वन्तु।
    *   विभिन्नलकाराणां प्रयोगेण वाक्यस्य अर्थः कथं परिवर्तते? उदाहरणसहितं स्वविचारान् प्रकटयन्तु। (यथा - 'सः गच्छति' vs 'सः गच्छेत्' vs 'सः गमिष्यति')।

## 🌏 भारतीय-सन्दर्भः (Bharatiya Context)

*   **भाषायाः आधारः**: संस्कृतं बह्वीनां भारतीयानां भाषाणां जननी अस्ति तथा भारतीयसंस्कृतेः, ज्ञानपरम्परायाः च वाहिका अस्ति। धातुरूपाणां सम्यक् ज्ञानं संस्कृतवाङ्मयस्य (वेदाः, उपनिषदः, रामायणम्, महाभारतम्, पुराणानि, काव्यानि) अवगमने सहायकं भवति। 📊
*   **वैदिक-प्रयोगः**: दशसु लकारेषु 'लेट्' लकारस्य प्रयोगः मुख्यतया वेदेषु एव प्राप्यते, यत् संस्कृतभाषायाः प्राचीनतां वैविध्यं च दर्शयति।
*   **नैतिक-शिक्षा**: विधिलिङ् लकारस्य प्रयोगः ('चाहिए' अर्थे) नैतिकोपदेशेषु बहुधा दृश्यते। यथा - "सत्यं ब्रूयात्, प्रियं ब्रूयात्।" (मनुस्मृतिः)। अत्र 'ब्रूयात्' (ब्रू धातोः विधिलिङ्) उपदेशं सूचयति।
*   **ऐतिहासिक-सन्दर्भः**: लिट् (परोक्षभूत) तथा लुङ् (सामान्यभूत) लकारयोः प्रयोगः ऐतिहासिकघटनानां वर्णने (यथा - पुरा राजा नलः अभूत् - लुङ्) अथवा परोक्षघटनानां वर्णने (रामः रावणं जघान - लिट्) भवति, येन भारतस्य समृद्धः इतिहासः ज्ञायते।

*(अध्यायस्य अन्ते प्रदत्ताः अभ्यासप्रश्नाः छात्राणां ज्ञानपरीक्षणाय अवबोधदृढीकरणाय च सहायकाः भविष्यन्ति।)*
