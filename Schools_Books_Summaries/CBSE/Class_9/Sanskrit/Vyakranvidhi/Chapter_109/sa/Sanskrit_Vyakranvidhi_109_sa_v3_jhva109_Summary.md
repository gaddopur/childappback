# Class 9 Sanskrit - Vyakranvidhi Chapter 109
**Language:** संस्कृतम्

```markdown
# [कक्षा ९] व्याकरणवीथिः - अध्यायः ९ (समास परिचयः)

(पाठ्यपुस्तके अयं नवमः (९) अध्यायः अस्ति, न तु १०९)

## 🌟 मुख्याः अवधारणाः (Core Concepts)

समासस्य परिचयः एवं प्रकाराः 📊

1.  **समासः किम्?**
    *   'समसनम्' इति समासः। अर्थः - **संक्षेपणम्**।
    *   द्वयोः वा अधिकयोः पदयोः विभक्ति-समुच्चयबोधकादीनां लोपं कृत्वा एकपदनिर्माणम्।
    *   **उदाहरणम्:** राज्ञः पुरुषः → राजपुरुषः (विभक्तिलोपः), सीता च रामश्च → सीतारामौ ('च' लोपः)।

2.  **समासस्य भेदाः (पदप्रधानतायाः आधारेण):**
    *   **अव्ययीभावः** (पूर्वपदप्रधानः)
    *   **तत्पुरुषः** (उत्तरपदप्रधानः)
        *   *उपभेदौ:*
            *   **कर्मधारयः** (समानाधिकरणतत्पुरुषः)
            *   **द्विगुः** (संख्यापूर्वपदः कर्मधारयः)
    *   **द्वन्द्वः** (उभयपदप्रधानः)
    *   **बहुव्रीहिः** (अन्यपदप्रधानः)
    *   *(सामान्यतः षड्भेदाः परिगणिताः)*

3.  **अलुक्समासः:** यत्र पदयोः मध्ये विभक्तेः लोपः न भवति (यथा - खेचरः, युधिष्ठिरः)। (अस्मिन् पाठे केवलं परिचयः)

4.  **एकशेषः:** यत्र अनेकपदेषु केवलम् एकं पदम् अवशिष्यते (यथा - माता च पिता च → पितरौ)। (समासात् भिन्ना वृत्तिः)

## 📘 प्रमुखाः शिक्षणबिन्दवः (Key Learnings)

प्रत्येकस्य समासस्य विस्तृता व्याख्या उदाहरणैः सह 📈

1.  **अव्ययीभावसमासः:**
    *   **लक्षणम्:** पूर्वपदम् अव्ययं प्रधानं च भवति। समस्तपदम् अव्ययं भूत्वा नपुंसकलिङ्गे प्रयुज्यते।
    *   **उदाहरणानि:**
        *   शक्तिम् अनतिक्रम्य = **यथाशक्ति** (अनतिक्रम्य अर्थे)
        *   विघ्नानाम् अभावः = **निर्विघ्नम्** (अभावार्थे)
        *   गङ्गायाः समीपम् = **उपगङ्गम्** (समीपार्थे)
        *   रूपस्य योग्यम् = **अनुरूपम्** (योग्यतार्थे)
        *   एकम् एकम् इति = **प्रत्येकम्** (वीप्सार्थे)
        *   गृहं गृहम् इति = **प्रतिगृहम्** (वीप्सार्थे)
        *   मक्षिकाणाम् अभावः = **निर्मक्षिकम्** (अभावार्थे)

2.  **तत्पुरुषसमासः:**
    *   **लक्षणम्:** प्रायः उत्तरपदस्य प्रधानता भवति। पूर्वपदस्य विभक्तेः लोपः भवति (द्वितीया तः सप्तमी पर्यन्तम्)।
    *   **उदाहरणानि:**
        *   **द्वितीया तत्पुरुषः:** शरणम् आगतः = शरणागतः, सुखं प्राप्तः = सुखप्राप्तः।
        *   **तृतीया तत्पुरुषः:** पित्रा युक्तः = पितृयुक्तः, सर्पेण दष्टः = सर्पदष्टः, धनेन हीनः = धनहीनः।
        *   **चतुर्थी तत्पुरुषः:** भूताय बलिः = भूतबलिः, दानाय पात्रम् = दानपात्रम्, स्नानाय इदम् = स्नानार्थम्।
        *   **पञ्चमी तत्पुरुषः:** चौरात् भयम् = चोरभयम्, रोगात् मुक्तः = रोगमुक्तः, अश्वात् पतितः = अश्वपतितः।
        *   **षष्ठी तत्पुरुषः:** राज्ञः पुरुषः = राजपुरुषः, देवानां पतिः = देवपतिः, देवस्य पूजा = देवपूजा।
        *   **सप्तमी तत्पुरुषः:** युद्धे निपुणः = युद्धनिपुणः, कार्ये कुशलः = कार्यकुशलः, जले मग्नः = जलमग्नः।
        *   **नञ् तत्पुरुषः:** न धार्मिकः = अधार्मिकः, न सत्यम् = असत्यम्, न आदिः = अनादिः।

3.  **कर्मधारयसमासः (समानाधिकरणतत्पुरुषः):**
    *   **लक्षणम्:** उभयोः पदयोः समाना विभक्तिः भवति।
    *   **स्वरूपाणि:**
        *   **विशेषण-विशेष्य:** नीलम् उत्पलम् = नीलोत्पलम्, विशालः वृक्षः = विशालवृक्षः, मधुरं फलम् = मधुरफलम्।
        *   **उपमान-उपमेय:** घन इव श्यामः = घनश्यामः, कमलम् इव मुखम् = कमलमुखम्, नरः सिंह इव = नरसिंहः।
        *   **उभयपद-विशेषण:** शीतं च उष्णम् = शीतोष्णम्, रक्तश्च पीतः = रक्तपीतः।

4.  **द्विगुसमासः:**
    *   **लक्षणम्:** कर्मधारयस्य पूर्वपदं यदा संख्यावाची भवति। प्रायः समूहार्थे भवति। समस्तपदं सामान्यतः नपुंसकलिङ्गैकवचने भवति। विग्रहे षष्ठी विभक्तिः प्रयुज्यते।
    *   **उदाहरणानि:**
        *   सप्तानां दिनानां समाहारः = सप्तदिनम्।
        *   पञ्चानां पात्राणां समाहारः = पञ्चपात्रम्।
        *   त्रयाणां भुवनानां समाहारः = त्रिभुवनम्।
        *   चतुर्णां युगानां समाहारः = चतुर्युगम्।
    *   **विशेषः:** कदाचित् ईकारान्तः स्त्रीलिङ्गोऽपि भवति।
        *   त्रयाणां लोकानां समाहारः = त्रिलोकी।
        *   पञ्चानां वटानां समाहारः = पञ्चवटी।
        *   सप्तानां शतानां समाहारः = सप्तशती।
        *   अष्टानाम् अध्यायानां समाहारः = अष्टाध्यायी।

5.  **द्वन्द्वसमासः:**
    *   **लक्षणम्:** यत्र उभयोः पदयोः प्रधानता भवति। विग्रहे 'च' इत्यस्य प्रयोगः।
    *   **भेदाः:**
        *   **इतरेतर द्वन्द्वः:** यत्र पदानाम् अर्थः पृथक्-पृथक् भवति। समस्तपदस्य वचनं पदानुसारं (द्विवचनं/बहुवचनं) भवति, लिङ्गं च उत्तरपदवत्।
            *   उदाहरणानि: लवश्च कुशश्च = लवकुशौ, रामश्च कृष्णश्च = रामकृष्णौ, धर्मश्च अर्थश्च कामश्च मोक्षश्च = धर्मार्थकाममोक्षाः, माता च पिता च = मातापितरौ।
        *   **समाहार द्वन्द्वः:** यत्र समूहस्य प्रधानता भवति। समस्तपदं नपुंसकलिङ्गैकवचने भवति।
            *   उदाहरणानि: आहारश्च निद्रा च भयं च, एतेषां समाहारः = आहारनिद्राभयम्, पाणी च पादौ च = पाणिपादम्, यवाश्च चणकाश्च = यवचणकम्।
    *   **पदक्रमनियमाः (संक्षेपेण):** ह्रस्व इ/उकारान्तपदं पूर्वम् (वायुसूर्यौ), स्वरादि/अकारान्तपदं पूर्वम् (ईशकृष्णौ), अल्पस्वरवर्णपदं पूर्वम् (रामकेशवौ), ह्रस्वस्वरपदं पूर्वम् (कुशकाशम्), पूज्यपदं पूर्वम् (मातापितरौ)।

6.  **बहुव्रीहिसमासः:**
    *   **लक्षणम्:** यत्र पूर्वपदम् उत्तरपदं वा प्रधानं न भूत्वा अन्यपदस्य प्रधानता भवति। विग्रहे 'यस्य सः / यस्याः सा' इत्यादीनां प्रयोगः।
    *   **उदाहरणानि:**
        *   महान्तौ बाहू यस्य सः = महाबाहुः (विष्णुः)।
        *   दश आननानि यस्य सः = दशाननः (रावणः)।
        *   पीतम् अम्बरम् यस्य सः = पीताम्बरः (कृष्णः)।
        *   चत्वारि मुखानि यस्य सः = चतुर्मुखः (ब्रह्मा)।
        *   चक्रं पाणौ यस्य सः = चक्रपाणिः (विष्णुः)।
        *   चन्द्रः शेखरे यस्य सः = चन्द्रशेखरः (शिवः)।
        *   चन्द्र इव मुखं यस्याः सा = चन्द्रमुखी (नारी)।

7.  **एकशेषः:**
    *   **लक्षणम्:** अनेकपदेषु केवलम् एकस्य पदस्य शेषः भवति। पुंस्त्रीलिङ्गयोः पदेषु पुंलिङ्गपदम् एव शिष्यते।
    *   **उदाहरणानि:**
        *   बालकश्च बालकश्च बालकश्च = बालकाः।
        *   माता च पिता च = पितरौ।
        *   दुहिता च पुत्रश्च = पुत्रौ।

## 🌏 भारतीयः सन्दर्भः (Bharatiya Context)

संस्कृतवाङ्मये समासस्य प्रयोगः 📊

*   समासः संस्कृतभाषायाः महत्त्वपूर्णम् अङ्गम् अस्ति। अनेन भाषा संक्षिप्ता, सुन्दरा, प्रभावपूर्णा च भवति।
*   प्राचीनभारतीयेषु शास्त्रेषु, काव्येषु, पुराणेषु च समासानां बहुलः प्रयोगः दृश्यते। यथा - **महाभारतम्**, **रामायणम्**, **पञ्चतन्त्रम्** इत्यादिषु ग्रन्थेषु।
*   बहवः देवतानां नामानि (यथा - **चन्द्रशेखरः**, **गजाननः**, **पीताम्बरः**, **चक्रपाणिः**), स्थानानां नामानि (यथा - **पञ्चवटी**, **त्रिलोकी**, **हस्तिनापुरम्**) च समासपदानि एव सन्ति।
*   सूत्रशैल्यां (यथा - पाणिनिमुनेः **अष्टाध्यायी**, दर्शनसूत्राणि) अर्थस्य संक्षेपणार्थं समासाः अतीव उपयोगिनः अभवन्।
*   समासानां ज्ञानेन संस्कृतसाहित्यस्य गहनः अर्थः सुलभतया अवगन्तुं शक्यते। उदाहरणानि यथा पाठे दत्तानि - **राजपुरुषः**, **घनश्यामः**, **दशाननः**, **धर्मार्थकाममोक्षाः** - एतानि पदानि भारतीयसंस्कृतेः विचाराणां च भागानि सन्ति।
```
