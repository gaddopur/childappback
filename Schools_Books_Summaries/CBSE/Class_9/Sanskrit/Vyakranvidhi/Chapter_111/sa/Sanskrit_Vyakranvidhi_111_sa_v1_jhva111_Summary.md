# Class 9 Sanskrit - Vyakranvidhi Chapter 111

# [कक्षा ९] व्याकरणविधिः - एकादशः अध्यायः (वाच्यपरिवर्तनम्)

## 🌟 मूलाधाराः अवधारणाः (Core Concepts)
अत्र वाच्यस्य अवधारणाः सोपानक्रमेण दर्शिताः सन्ति 📊:

1.  **वाच्यम्**
    *   **परिभाषा**: अभिव्यक्तिः वा कथनस्य प्रकटीकरणस्य विधा 'वाच्यम्' इति कथ्यते। (The mode of expressing a statement is called Voice).
    *   **प्रकाराः**: संस्कृते वाच्यं त्रिविधं भवति।
        *   **१. कर्तृवाच्यम् (Active Voice)**
            *   **लक्षणम्**:
                *   कर्ता प्रधानः भवति।
                *   क्रियापदं कर्तारम् अनुसरति (पुरुषे वचने च)।
                *   कर्तरि प्रथमा विभक्तिः।
                *   कर्मणि (यदि अस्ति) द्वितीया विभक्तिः।
            *   **उदाहरणम्**: रामः गृहं गच्छति। (अत्र 'रामः' कर्ता [प्रथमा], 'गृहम्' कर्म [द्वितीया], 'गच्छति' क्रिया कर्तारम् 'रामम्' अनुसरति)।
        *   **२. कर्मवाच्यम् (Passive Voice)**
            *   **लक्षणम्**:
                *   कर्म प्रधानं भवति।
                *   क्रियापदं कर्मपदम् अनुसरति (लिङ्गे, पुरुषे, वचने च)।
                *   कर्तरि तृतीया विभक्तिः।
                *   कर्मणि प्रथमा विभक्तिः।
            *   **उदाहरणम्**: रामेण गृहं गम्यते। (अत्र 'रामेण' कर्ता [तृतीया], 'गृहम्' कर्म [प्रथमा], 'गम्यते' क्रिया कर्मपदं 'गृहम्' अनुसरति)।
        *   **३. भाववाच्यम् (Impersonal Voice)**
            *   **लक्षणम्**:
                *   भावः (क्रियायाः अर्थः) प्रधानः भवति।
                *   प्रायः अकर्मकधातुभिः सह प्रयुज्यते।
                *   कर्तरि तृतीया विभक्तिः।
                *   क्रियापदं सदैव प्रथमपुरुष-एकवचने एव भवति (नपुंसकलिङ्गे)।
            *   **उदाहरणम्**: मया सुप्यते। / छात्रैः हस्यते। (अत्र कर्ता भिन्नवचनेषु अपि अस्ति चेत्, क्रिया 'सुप्यते', 'हस्यते' प्रथमपुरुष-एकवचने एव स्तः)।

2.  **वाच्यपरिवर्तनस्य नियमाः (Rules for Voice Change)**
    *   **कर्तृवाच्यतः कर्मवाच्ये/भाववाच्ये परिवर्तनम्**:
        *   कर्तुः प्रथमायाः स्थाने तृतीया विभक्तिः।
        *   कर्मणः द्वितीयायाः स्थाने प्रथमा विभक्तिः (कर्मवाच्ये)।
        *   क्रियापदस्य परिवर्तनम्:
            *   **वर्तमानकाले (लट्-लकारे)**: मूलधातुः + **य** + आत्मनेपद-प्रत्ययः (ते, येते, न्ते)। यथा - पठति → पठ्यते, लिखन्ति → लिख्यन्ते।
            *   **भूतकाले (क्तवतु/क्त प्रत्ययौ)**: कर्तृवाच्ये 'क्तवतु' प्रत्ययस्य स्थाने कर्मवाच्ये/भाववाच्ये 'क्त' प्रत्ययस्य प्रयोगः भवति। क्रिया कर्मानुसारं (कर्मवाच्ये) वा सदैव नपुंसकलिङ्ग-एकवचने (भाववाच्ये) भवति। यथा - सः पठितवान् → तेन पठितः (ग्रन्थः), तेन पठितम् (पुस्तकम्)।

## 📘 प्रमुख-शिक्षणबिन्दवः (Key Learnings)
अस्मिन् अध्याये वयं वाच्यस्य भेदान् तेषां परिवर्तनस्य नियमान् च जानीमः।

1.  **कर्तृवाच्यम्**: यत्र कर्ता मुख्यः, क्रिया च कर्तुः अनुसारं चलति।
    *   **संरचना**: कर्ता (प्रथमा) + कर्म (द्वितीया) + क्रिया (कर्त्रनुसारिणी)
    *   **उदाहरणानि**:
        *   बालिका पाठं पठितवती। ('बालिका' कर्ता, 'पाठम्' कर्म, 'पठितवती' क्रिया)
        *   सैनिकः देशं रक्षति। ('सैनिकः' कर्ता, 'देशम्' कर्म, 'रक्षति' क्रिया)

2.  **कर्मवाच्यम्**: यत्र कर्म मुख्यं भवति, क्रिया च कर्मणः अनुसारं चलति।
    *   **संरचना**: कर्ता (तृतीया) + कर्म (प्रथमा) + क्रिया (कर्मानुसारिणी)
    *   **उदाहरणानि**:
        *   विद्यार्थिना पाठः पठ्यते। ('विद्यार्थिना' कर्ता, 'पाठः' कर्म [पुंल्लिङ्ग-एकवचनम्], 'पठ्यते' क्रिया कर्मानुसारिणी)
        *   मया चित्रे दृश्येते। ('मया' कर्ता, 'चित्रे' कर्म [नपुंसकलिङ्ग-द्विवचनम्], 'दृश्येते' क्रिया कर्मानुसारिणी)

3.  **भाववाच्यम्**: यत्र क्रियायाः भावः एव प्रधानः, कर्तरि तृतीया, क्रिया च नित्यं प्रथमपुरुष-एकवचने।
    *   **संरचना**: कर्ता (तृतीया) + क्रिया (प्रथमपुरुष-एकवचनम्)
    *   **उदाहरणम्**: तैः सुप्यते। (कर्ता 'तैः' बहुवचने अपि अस्ति, परन्तु क्रिया 'सुप्यते' एकवचने एव)

4.  **क्रियापरिवर्तनम् (Verb Transformation)** 📈:
    *   **वर्तमानकाले**:
        | कर्तृवाच्यम् | कर्मवाच्यम् / भाववाच्यम् |
        | :---------- | :---------------------- |
        | पठति        | पठ्यते                  |
        | लिखति       | लिख्यते                 |
        | करोति       | क्रियते                 |
        | गच्छति       | गम्यते                  |
        | हसति        | हस्यते                  |
        | खादति       | खाद्यते                 |
        | नयति        | नीयते                  |
    *   **भूतकाले (क्तवतु → क्त)**:
        *   अहम् ग्रन्थान् पठितवान्। → मया ग्रन्थाः पठिताः।
        *   वयं गुरुम् पूजितवन्तः। → अस्माभिः गुरुः पूजितः।
        *   सः फलानि खादितवान्। → तेन फलानि खादितानि।

2.  **रिक्तस्थानपूर्तिः**: कर्तृपदस्य, कर्मपदस्य, क्रियापदस्य वा उचितरूपेण पूर्तिः।

    *   उदाहरणम्: कर्मवाच्यस्य कर्तरि का विभक्तिः भवति? (क) प्रथमा (ख) द्वितीया (ग) तृतीया [उत्तरम् - (ग)]

## 🌏 भारतीय-सन्दर्भः (Bharatiya Context)
वाच्यस्य अवधारणा संस्कृतव्याकरणस्य, তথা भारतीयभाषाचिन्तनस्य च महत्त्वपूर्णम् अङ्गम् अस्ति। 📊

1.  **उदाहरणानि**: अस्मिन् पाठे प्रयुक्तानि नामानि (यथा - रामः, राजेन्द्रः, शकुन्तला, दुष्यन्तः) स्थानानि च (यथा - पाटलिपुत्रम्) भारतीयसंस्कृतेः परिचायकानि सन्ति।
2.  **भाषागत-वैशिष्ट्यम्**: कर्तृ-कर्म-भाव-वाच्यानां प्रयोगेण संस्कृतभाषायां अर्थस्य सूक्ष्मता (nuance) वक्तुः आशयस्य च स्पष्टता वर्धते। वाक्ये कस्य पदस्य (कर्तुः, कर्मणः वा क्रियायाः) प्राधान्यम् अस्ति, इति वाच्येन ज्ञायते।
3.  **शास्त्रीय-परम्परा**: पाणिनेः अष्टाध्यायीतः आरभ्य अद्यपर्यन्तं वाच्यविचारः व्याकरणशास्त्रे प्रमुखस्थानं भजते। महाकाव्येषु, शास्त्रेषु, नाटकेषु च विविधवाच्यानां कलात्मकः प्रयोगः दृश्यते, येन भाषायाः सौन्दर्यं वर्धते।
