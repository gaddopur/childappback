# [Class 9] Vyakranvidhi - Chapter 103 - संधि

## 🌟 Core Concepts

संधि का अर्थ है 'मेल' या 'जुड़ना'। व्याकरण में, यह वर्णों का विकार (परिवर्तन) है। जब दो पद या एक ही पद में दो वर्ण बिना किसी रुकावट के अत्यंत पास आते हैं (संहिता), तो उनमें जो वर्ण-विकार होता है, उसे संधि कहते हैं।

**संधि के मुख्य भेद 📊:**

1.  **स्वर संधि (अच् संधि):** जब दो स्वर वर्ण अत्यंत पास आने पर उनमें परिवर्तन होता है।
    *   दीर्घ संधि
    *   गुण संधि
    *   वृद्धि संधि
    *   यण् संधि
    *   अयादि संधि
    *   पूर्वरूप संधि
    *   प्रकृतिभाव संधि
    *   पररूप संधि
2.  **व्यंजन संधि (हल् संधि):** जब व्यंजन के बाद स्वर या व्यंजन आने पर व्यंजन में परिवर्तन होता है।
    *   श्चुत्व संधि
    *   ष्टुत्व संधि
    *   जश्त्व संधि
    *   चर्त्व संधि
    *   अनुस्वार संधि
    *   परसवर्ण संधि
    *   लत्व संधि
    *   छत्व संधि
    *   'च्' का आगम
    *   'र्' का लोप और पूर्व स्वर का दीर्घ होना
    *   'न्' का 'ण्' होना
3.  **विसर्ग संधि:** जब विसर्ग (:) के बाद स्वर या व्यंजन आने पर विसर्ग में परिवर्तन होता है।
    *   सत्व (विसर्ग का 'स्', 'श्', 'ष्' होना)
    *   षत्व (विसर्ग का 'ष्' होना)
    *   रुत्व-उत्व, गुण, पूर्वरूप (विसर्ग का 'ओ' और अवग्रह 'ऽ' होना)
    *   रुत्व (विसर्ग का 'र्' होना)

## 📘 Key Learnings

**1. स्वर संधि (अच् संधि)**

दो स्वरों के अत्यंत पास आने पर होने वाला वर्ण-विकार।

*   **i) दीर्घ संधि (अकः सवर्णे दीर्घः):**
    *   **नियम:** यदि ह्रस्व या दीर्घ अ, इ, उ, ऋ के बाद समान ह्रस्व या दीर्घ स्वर आए, तो दोनों मिलकर क्रमशः आ, ई, ऊ, ॠ हो जाते हैं।
    *   **उदाहरण:**
        *   पुस्तक + आलयः = पुस्तकालयः (अ + आ = आ)
        *   गिरि + इन्द्रः = गिरीन्द्रः (इ + इ = ई)
        *   भानु + उदयः = भानूदयः (उ + उ = ऊ)
        *   पितृ + ऋणम् = पितॄणम् (ऋ + ऋ = ॠ)

*   **ii) गुण संधि (आद्गुणः):** ('अ', 'ए', 'ओ' गुण वर्ण हैं)
    *   **नियम:** यदि 'अ' या 'आ' के बाद 'इ/ई' आए तो 'ए'; 'उ/ऊ' आए तो 'ओ'; 'ऋ' आए तो 'अर्' हो जाता है।
    *   **उदाहरण:**
        *   उप + इन्द्रः = उपेन्द्रः (अ + इ = ए)
        *   महा + ईशः = महेशः (आ + ई = ए)
        *   सूर्य + उदयः = सूर्योदयः (अ + उ = ओ)
        *   गंगा + उदकम् = गंगोदकम् (आ + उ = ओ)
        *   देव + ऋषि = देवर्षिः (अ + ऋ = अर्)
        *   वर्षा + ऋतु = वर्षर्तुः (आ + ऋ = अर्)

*   **iii) वृद्धि संधि (वृद्धिरेचि):** ('आ', 'ऐ', 'औ' वृद्धि वर्ण हैं)
    *   **नियम:** यदि 'अ' या 'आ' के बाद 'ए/ऐ' आए तो 'ऐ'; 'ओ/औ' आए तो 'औ' हो जाता है।
    *   **उदाहरण:**
        *   मम + एव = ममैव (अ + ए = ऐ)
        *   सदा + एव = सदैव (आ + ए = ऐ)
        *   जल + ओघः = जलौघः (अ + ओ = औ)
        *   विद्या + औचित्यम् = विद्यौचित्यम् (आ + औ = औ)

*   **iv) यण् संधि (इको यणचि):**
    *   **नियम:** यदि इ/ई, उ/ऊ, ऋ/ॠ, लृ के बाद कोई असमान स्वर आए तो इ/ई को 'य्', उ/ऊ को 'व्', ऋ/ॠ को 'र्', और लृ को 'ल्' हो जाता है।
    *   **उदाहरण:**
        *   यदि + अपि = यद्यपि (इ + अ = य् + अ)
        *   सु + आगतम् = स्वागतम् (उ + आ = व् + आ)
        *   पितृ + आदेशः = पित्रादेशः (ऋ + आ = र् + आ)
        *   लृ + आकृतिः = लाकृतिः (लृ + आ = ल् + आ)

*   **v) अयादि संधि (एचोऽयवायावः):**
    *   **नियम:** यदि ए, ऐ, ओ, औ के बाद कोई स्वर आए तो ए को 'अय्', ऐ को 'आय्', ओ को 'अव्', औ को 'आव्' हो जाता है।
    *   **उदाहरण:**
        *   ने + अनम् = नयनम् (ए + अ = अय् + अ)
        *   नै + अकः = नायकः (ऐ + अ = आय् + अ)
        *   पो + अनम् = पवनम् (ओ + अ = अव् + अ)
        *   पौ + अकः = पावकः (औ + अ = आव् + अ)

*   **vi) पूर्वरूप संधि (एङः पदान्तादति):**
    *   **नियम:** यदि पद के अंत में 'ए' या 'ओ' हो और उसके बाद ह्रस्व 'अ' आए, तो 'अ' अपना रूप 'ए' या 'ओ' में विलीन कर देता है और उसके स्थान पर अवग्रह चिह्न (ऽ) लगाया जाता है।
    *   **उदाहरण:**
        *   हरे + अव = हरेऽव (ए + अ = एऽ)
        *   विष्णो + अव = विष्णोऽव (ओ + अ = ओऽ)
        *   वृक्षे + अपि = वृक्षेऽपि (ए + अ = एऽ)

*   **vii) प्रकृतिभाव संधि (प्लुतप्रगृह्या अचि नित्यम्):**
    *   **नियम:** संधि के नियम लागू होने की स्थिति में भी संधि कार्य न होना। यह प्लुत और प्रगृह्य संज्ञक वर्णों के बाद स्वर आने पर होता है।
    *   **प्रगृह्य संज्ञा:** द्विवचन के रूप जिनके अंत में ई, ऊ, या ए हो (ईदूदेद्द्विवचनं प्रगृह्यम्) तथा 'अदस्' शब्द के 'म्' के बाद ई या ऊ (अदसो मात्)।
    *   **उदाहरण:**
        *   कवी + इच्छतः = कवी इच्छतः (ई-कारांत द्विवचन, प्रगृह्य)
        *   विष्णू + इमौ = विष्णू इमौ (ऊ-कारांत द्विवचन, प्रगृह्य)
        *   बालिके + आगच्छतः = बालिके आगच्छतः (ए-कारांत द्विवचन, प्रगृह्य)
        *   अमी + ईशाः = अमी ईशाः ('अदस्' शब्द, प्रगृह्य)

*   **viii) पररूप संधि (एङि पररूपम्):** (वृद्धि संधि का अपवाद)
    *   **नियम:** यदि 'अ' वर्ण वाले उपसर्ग के बाद 'ए' या 'ओ' से शुरू होने वाली धातु आए, तो उपसर्ग का 'अ' बाद वाले 'ए' या 'ओ' में मिल जाता है (पररूप हो जाता है)।
    *   **उदाहरण:**
        *   प्र + एजते = प्रेजते (अ + ए = ए)
        *   उप + ओषति = उपोषति (अ + ओ = ओ)

**2. व्यंजन संधि (हल् संधि)**

व्यंजन के बाद स्वर या व्यंजन आने पर व्यंजन में होने वाला परिवर्तन।

*   **i) श्चुत्व संधि (स्तोः श्चुना श्चुः):**
    *   **नियम:** 'स्' या त-वर्ग (त्, थ्, द्, ध्, न्) का 'श्' या च-वर्ग (च्, छ्, ज्, झ्, ञ्) के साथ योग होने पर 'स्' को 'श्' और त-वर्ग को च-वर्ग हो जाता है।
    *   **उदाहरण:**
        *   मनस् + चलति = मनश्चलति (स् + च् = श्च्)
        *   सत् + चित् = सच्चित् (त् + च् = च्च्)
        *   सत् + जनः = सज्जनः (त्(द्) + ज् = ज्ज्)

*   **ii) ष्टुत्व संधि (ष्टुना ष्टुः):**
    *   **नियम:** 'स्' या त-वर्ग का 'ष्' या ट-वर्ग (ट्, ठ्, ड्, ढ्, ण्) के साथ योग होने पर 'स्' को 'ष्' और त-वर्ग को ट-वर्ग हो जाता है।
    *   **उदाहरण:**
        *   रामस् + षष्ठः = रामष्षष्ठः (स् + ष् = ष्ष्)
        *   तत् + टीका = तट्टीका (त् + ट् = ट्ट्)
        *   उत् + डयनम् = उड्डयनम् (त्(द्) + ड् = ड्ड्)

*   **iii) जश्त्व संधि (झलां जशोऽन्ते):**
    *   **नियम:** पद के अंत में स्थित झल् (वर्ग के 1, 2, 3, 4 वर्ण और श्, ष्, स्, ह्) के स्थान पर जश् (उसी वर्ग का तीसरा वर्ण - ज्, ब्, ग्, ड्, द्) हो जाता है।
    *   **उदाहरण:**
        *   वाक् + ईशः = वागीशः (क् को ग्)
        *   जगत् + ईशः = जगदीशः (त् को द्)
        *   सुप् + अन्तः = सुबन्तः (प् को ब्)

*   **iv) चर्त्व संधि (खरि च):**
    *   **नियम:** यदि वर्गों के दूसरे, तीसरे या चौथे वर्ण के बाद वर्ग का पहला या दूसरा वर्ण अथवा श्, ष्, स् आए, तो पहले आने वाला वर्ण अपने ही वर्ग का पहला वर्ण हो जाता है।
    *   **उदाहरण:**
        *   सद् + कारः = सत्कारः (द् को त्)
        *   दिग् + पालः = दिक्पालः (ग् को क्)

*   **v) अनुस्वार संधि (मोऽनुस्वारः):**
    *   **नियम:** यदि पद के अंत में 'म्' हो और उसके बाद कोई व्यंजन आए, तो 'म्' का अनुस्वार (ं) हो जाता है।
    *   **उदाहरण:**
        *   हरिम् + वन्दे = हरिं वन्दे
        *   अहम् + गच्छामि = अहं गच्छामि

*   **vi) परसवर्ण संधि (अनुस्वारस्य ययि परसवर्णः):**
    *   **नियम:** यदि अनुस्वार के बाद किसी वर्ग का व्यंजन आए, तो अनुस्वार के स्थान पर आगे वाले वर्ण के वर्ग का पाँचवाँ वर्ण (ङ्, ञ्, ण्, न्, म्) हो जाता है। (यह नियम पदान्त में प्रायः नहीं लगता)।
    *   **उदाहरण:**
        *   अं + कितः = अङ्कितः (ं + क् = ङ्क्)
        *   सं + कल्पः = सङ्कल्पः (ं + क् = ङ्क्)
        *   अं + चितः = अञ्चितः (ं + च् = ञ्च्)

*   **vii) लत्व संधि (तोर्लि):**
    *   **नियम:** यदि त-वर्ग के बाद 'ल्' आए, तो त-वर्ग के वर्णों का 'ल्' हो जाता है। 'न्' के बाद 'ल्' आने पर अनुनासिक 'लँ' होता है।
    *   **उदाहरण:**
        *   उत् + लङ्घनम् = उल्लङ्घनम् (त् + ल् = ल्ल)
        *   महान् + लाभः = महांल्लाभः (न् + ल् = ँल्ल्)

*   **viii) छत्व संधि (शश्छोऽटि):**
    *   **नियम:** यदि 'श्' से पहले पदान्त में वर्ग का 1, 2, 3, 4 वर्ण या र्, ल्, व्, ह् हो, तो 'श्' के स्थान पर 'छ्' हो जाता है। (पाठ्यपुस्तक के उदाहरण में त् + श् = च्छ् दिखाया गया है, जो श्चुत्व के बाद छत्व का परिणाम है)।
    *   **उदाहरण:**
        *   एतत् + शोभनम् = एतच्छोभनम् (त् + श् -> च् + श् -> च् + छ्)
        *   तत् + श्रुत्वा = तच्छ्रुत्वा (त् + श् -> च् + श् -> च् + छ्)

*   **ix) 'च्' का आगम (छे च):**
    *   **नियम:** यदि ह्रस्व स्वर के बाद 'छ्' आए, तो 'छ्' से पहले 'च्' का आगम (जुड़ना) होता है।
    *   **उदाहरण:**
        *   तरु + छाया = तरुच्छाया (उ + छ् = उ + च् + छ्)
        *   अनु + छेदः = अनुच्छेदः (उ + छ् = उ + च् + छ्)

*   **x) 'र्' का लोप और पूर्व स्वर का दीर्घ होना (रो रि):**
    *   **नियम:** यदि 'र्' के बाद 'र्' हो, तो पहले 'र्' का लोप हो जाता है और उसका पूर्ववर्ती स्वर दीर्घ हो जाता है।
    *   **उदाहरण:**
        *   निर् + रोगः = नीरोगः (र् का लोप, इ -> ई)
        *   निर् + रसः = नीरसः (र् का लोप, इ -> ई)

*   **xi) 'न्' का 'ण्' होना:**
    *   **नियम:** यदि एक ही पद में ऋ, र्, या ष् के बाद 'न्' आए, तो 'न्' का 'ण्' हो जाता है, भले ही बीच में स्वर, ह्, य्, व्, कवर्ग, पवर्ग, आङ् या नुम् का व्यवधान हो।
    *   **उदाहरण:**
        *   कृष्ण, विष्णु, वर्ण, नराणाम् (नरा + नाम्), ऋषीणाम् (ऋषी + नाम्)

**3. विसर्ग संधि**

विसर्ग (:) के बाद स्वर या व्यंजन आने पर विसर्ग में होने वाला परिवर्तन।

*   **i) सत्व (विसर्जनीयस्य सः):**
    *   **नियम:** यदि विसर्ग के बाद खर् प्रत्याहार (वर्ग के 1, 2 वर्ण और श्, ष्, स्) आए, तो विसर्ग का 'स्' हो जाता है। परन्तु, यदि विसर्ग के बाद 'श्' हो तो 'श्', और 'ट्' या 'ठ्' हो तो 'ष्' होता है।
    *   **उदाहरण:**
        *   नमः + ते = नमस्ते (: + त् = स्त्)
        *   बालकः + तरति = बालकस्तरति (: + त् = स्त्)
        *   निः + चलः = निश्चलः (: + च् = श्च्)
        *   धनुः + टङ्कारः = धनुष्टङ्कारः (: + ट् = ष्ट्)

*   **ii) षत्व:**
    *   **नियम:** यदि विसर्ग से पहले 'इ' या 'उ' हो और बाद में क्, ख्, प्, फ् में से कोई वर्ण हो, तो विसर्ग का 'ष्' हो जाता है। (अपवाद: नमः, पुरः के बाद क्, ख्, प्, फ् आने पर विसर्ग का 'स्' होता है)।
    *   **उदाहरण:**
        *   निः + कपटः = निष्कपटः (: + क् = ष्क्)
        *   दुः + कर्म = दुष्कर्म (: + क् = ष्क्)
        *   नमः + कारः = नमस्कारः (: + क् = स्क)
        *   पुरः + कारः = पुरस्कारः (: + क् = स्क)

*   **iii) रुत्व-उत्व, गुण, पूर्वरूप (अतो रोरप्लुतादप्लुते, हशि च):**
    *   **नियम 1 (अतो...):** यदि विसर्ग से पहले ह्रस्व 'अ' हो और बाद में भी ह्रस्व 'अ' हो, तो विसर्ग -> र् -> उ, फिर अ+उ=ओ (गुण), और फिर ओ+अ = ओऽ (पूर्वरूप) हो जाता है।
    *   **उदाहरण:**
        *   बालः + अयम् = बालोऽयम्
        *   सः + अवदत् = सोऽवदत्
    *   **नियम 2 (हशि च):** यदि विसर्ग से पहले ह्रस्व 'अ' हो और बाद में वर्ग का तीसरा, चौथा, पाँचवाँ वर्ण या य्, र्, ल्, व्, ह् हो, तो विसर्ग -> र् -> उ, फिर अ+उ=ओ (गुण) हो जाता है।
    *   **उदाहरण:**
        *   तपः + वनम् = तपोवनम्
        *   मनः + रथः = मनोरथः
        *   बालः + गच्छति = बालो गच्छति

*   **iv) रुत्व (: = र्):**
    *   **नियम:** यदि विसर्ग से पहले अ, आ को छोड़कर कोई अन्य स्वर हो और बाद में कोई स्वर या घोष व्यंजन (वर्ग के 3, 4, 5 वर्ण और य्, र्, ल्, व्, ह्) हो, तो विसर्ग का 'र्' हो जाता है।
    *   **उदाहरण:**
        *   मुनिः + अयम् = मुनिरयम् (इ + : + अ = इ + र् + अ)
        *   हरिः + आगच्छति = हरिरागच्छति (इ + : + आ = इ + र् + आ)
        *   गुरुः + जयति = गुरुर्जयति (उ + : + ज् = उ + र् + ज्)

संधि संस्कृत व्याकरण का आधार स्तंभ है। यह न केवल शब्दों के निर्माण को समझने में मदद करती है, बल्कि:

1.  **शास्त्रीय ग्रंथों की कुंजी:** वेद, उपनिषद्, रामायण, महाभारत, पुराण और अन्य संस्कृत साहित्य को उनके मूल रूप में समझने के लिए संधि का ज्ञान अनिवार्य है। उदाहरण: `जगदीशः` (जगत्+ईशः), `महर्षिः` (महा+ऋषिः)।
2.  **उच्चारण शुद्धि:** संधि के नियम शब्दों के सही और सहज उच्चारण में सहायक होते हैं।
3.  **भारतीय भाषाओं पर प्रभाव:** संस्कृत से उत्पन्न या प्रभावित कई आधुनिक भारतीय भाषाएँ (जैसे हिंदी, मराठी, बंगाली, गुजराती आदि) तत्सम शब्दों में संस्कृत के संधि नियमों का पालन करती हैं। उदाहरण: हिंदी में 'विद्यालय' (विद्या+आलय), 'महोत्सव' (महा+उत्सव)।
4.  **सांस्कृतिक निरंतरता:** संधि के माध्यम से प्राचीन ज्ञान और भाषा की संरचना आज भी जीवित है, जो भारत की भाषाई और सांस्कृतिक विरासत का अभिन्न अंग है। उदाहरण: `नमस्ते` (नमः+ते) जैसे शब्द दैनिक जीवन में प्रयुक्त होते हैं।
