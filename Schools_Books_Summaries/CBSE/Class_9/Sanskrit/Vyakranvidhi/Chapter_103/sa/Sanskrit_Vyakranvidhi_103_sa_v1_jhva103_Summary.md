# [कक्षा ९] व्याकरणवीथिः - अध्यायः ३ (सन्धिः)

## 🌟 मुख्याः अवधारणाः (Core Concepts)

अत्र सन्धेः विस्तृतं वर्गीकरणं प्रस्तुतम् अस्ति:

1.  **सन्धिः** - वर्णानां मेलनेन यः वर्णविकारः (परिवर्तनम्) भवति।
    *   **परिभाषा:** द्वयोः पदयोः वा एकस्मिन् पदे द्वयोः वर्णयोः अत्यन्तसमीपस्थितौ (संहितायाम्) यः वर्णविकारः भवति, सः सन्धिः कथ्यते। (यथा - विद्या + आलयः = विद्यालयः)
    *   **मुख्यभेदाः:**
        *   स्वरसन्धिः (अच्-सन्धिः)
        *   व्यञ्जनसन्धिः (हल्-सन्धिः)
        *   विसर्गसन्धिः

2.  **स्वरसन्धिः (अच्-सन्धिः)** - द्वयोः स्वरवर्णयोः मेलनेन यः विकारः भवति।
    *   **भेदाः:**
        *   **दीर्घसन्धिः (अकः सवर्णे दीर्घः):** (अ/आ + अ/आ = आ; इ/ई + इ/ई = ई; उ/ऊ + उ/ऊ = ऊ; ऋ/ॠ + ऋ/ॠ = ॠ)
        *   **गुणसन्धिः (आद्गुणः):** (अ/आ + इ/ई = ए; अ/आ + उ/ऊ = ओ; अ/आ + ऋ/ॠ = अर्)
        *   **वृद्धिसन्धिः (वृद्धिरेचि):** (अ/आ + ए/ऐ = ऐ; अ/आ + ओ/औ = औ)
        *   **यण्सन्धिः (इको यणचि):** (इ/ई → य्; उ/ऊ → व्; ऋ/ॠ → र्; लृ → ल्; यदि असवर्णः स्वरः परे)
        *   **अयादिसन्धिः (एचोऽयवायावः):** (ए → अय्; ऐ → आय्; ओ → अव्; औ → आव्; यदि कोऽपि स्वरः परे)
        *   **पूर्वरूपसन्धिः (एङः पदान्तादति):** (पदान्ते ए/ओ + अ → एऽ/ओऽ)
        *   **प्रकृतिभावसन्धिः (प्लुतप्रगृह्या अचि नित्यम्):** (सन्धेः अभावः - ईत्/ऊत्/एत् द्विवचने, अदसः 'म' अनन्तरम् ई/ऊ, प्लुतस्वरे च परे अचि)
        *   **पररूपसन्धिः (एङि पररूपम्):** (उपसर्गस्य 'अ' + ए/ओ → ए/ओ)

3.  **व्यञ्जनसन्धिः (हल्-सन्धिः)** - व्यञ्जनस्य पश्चात् स्वरस्य वा व्यञ्जनस्य मेलनेन यः व्यञ्जने विकारः भवति।
    *   **भेदाः:**
        *   **श्चुत्वम् (स्तोः श्चुना श्चुः):** (स्/तवर्गस्य → श्/चवर्गेण परिवर्तनम्, श्/चवर्गस्य योगे)
        *   **ष्टुत्वम् (ष्टुना ष्टुः):** (स्/तवर्गस्य → ष्/टवर्गेण परिवर्तनम्, ष्/टवर्गस्य योगे)
        *   **जश्त्वम् (झलां जशोऽन्ते):** (पदान्ते झल् (वर्गस्य १,२,३,४, श्,ष्,स्,ह्) → जश् (स्ववर्गस्य तृतीयवर्णः))
        *   **चर्त्वम् (खरि च):** (वर्गस्य २,३,४ वर्णस्य → स्ववर्गस्य प्रथमवर्णः, यदि परे वर्गस्य १,२ वर्णः वा श्,ष्,स्)
        *   **अनुस्वारः (मोऽनुस्वारः):** (पदान्ते 'म्' → (ं), यदि परे व्यञ्जनम्)
        *   **परसवर्णः (अनुस्वारस्य ययि परसवर्णः):** (अनुस्वारस्य → परवर्णस्य वर्गस्य पञ्चमवर्णः, यदि परे वर्गीयव्यञ्जनम् (अपदान्ते))
        *   **लत्वम् (तोर्लि):** (तवर्गस्य → 'ल्', यदि परे 'ल्') (न् + ल् → ँल्)
        *   **छत्वम् (शश्छोऽटि):** (पदान्ते वर्गस्य १,२,३,४/र्/ल्/व्/ह् + श् → छ्)
        *   **'च्'-आगमः (छे च):** (ह्रस्वस्वरः + छ् → च् + छ्)
        *   **'र्'-लोपः, पूर्वस्वरदीर्घीकरणञ्च (रो रि):** ('र्' + 'र्' → पूर्वस्वरः दीर्घः, प्रथमस्य 'र्' लोपः)
        *   **णत्वविधानम् (रषाभ्यां नो णः समानपदे...):** (ऋ/र्/ष् पश्चात् 'न्' → 'ण्', पदे व्यवधाने सत्यपि)

4.  **विसर्गसन्धिः** - विसर्गस्य (:) पश्चात् स्वरस्य वा व्यञ्जनस्य मेलनेन यः विसर्गे विकारः भवति।
    *   **भेदाः:**
        *   **सत्वम् (विसर्जनीयस्य सः):** (विसर्गः → स्, यदि परे खर् (वर्गस्य १,२, श्,ष्,स्)) (श् परे → श्; ट्/ठ् परे → ष्)
        *   **षत्वम्:** (इ/उ + विसर्गः + क्/ख्/प्/फ् → ष्) (अपवादः - नमः/पुरः + क्/ख्/प्/फ् → स्)
        *   **रुत्वम्-उत्वम्-गुणः-पूर्वरूपम् (अतो रोरप्लुतादप्लुते):** (अ + : + अ → ओऽ)
        *   **रुत्वम्-उत्वम्-गुणः (हशि च):** (अ + : + हश् (वर्गस्य ३,४,५, य्,र्,ल्,व्,ह्) → ओ)
        *   **रुत्वम् (र्):** (अ/आ भिन्नः स्वरः + : + स्वरः/घोषव्यञ्जनम् → र्)

## 📘 मुख्याः शिक्षणबिन्दवः (Key Learnings)

अस्मिन् अध्याये वयं सन्धेः नियमान् उदाहरणैः सह अवगच्छामः:

1.  **सन्धिः किम्?**
    *   वर्णयोः मेलनेन जायमानः वर्णविकारः सन्धिः। यथा - `नर + इन्द्रः = नरेन्द्रः` (अत्र अ+इ=ए इति गुणसन्धिः)।

2.  **स्वरसन्धेः प्रकाराः:**
    *   **दीर्घसन्धिः:** समानस्वराणां मेलनेन दीर्घस्वरः भवति।
        *   `पुस्तक + आलयः = पुस्तकालयः` (अ + आ = आ)
        *   `कपि + ईशः = कपीशः` (इ + ई = ई)
        *   `भानु + उदयः = भानूदयः` (उ + उ = ऊ)
    *   **गुणसन्धिः:** 'अ/आ' इत्यस्य पश्चात् 'इ/ई', 'उ/ऊ', 'ऋ' आगच्छति चेत् क्रमशः 'ए', 'ओ', 'अर्' भवति।
        *   `गण + ईशः = गणेशः` (अ + ई = ए)
        *   `महा + उत्सवः = महोत्सवः` (आ + उ = ओ)
        *   `देव + ऋषिः = देवर्षिः` (अ + ऋ = अर्)
    *   **वृद्धिसन्धिः:** 'अ/आ' इत्यस्य पश्चात् 'ए/ऐ', 'ओ/औ' आगच्छति चेत् क्रमशः 'ऐ', 'औ' भवति।
        *   `एक + एकम् = एकैकम्` (अ + ए = ऐ)
        *   `जल + ओघः = जलौघः` (अ + ओ = औ)
    *   **यण्सन्धिः:** 'इ/उ/ऋ/लृ' इत्यस्य स्थाने 'य्/व्/र्/ल्' भवति, यदि पश्चात् भिन्नः स्वरः आगच्छति।
        *   `इति + आदि = इत्यादि` (इ → य्)
        *   `सु + आगतम् = स्वागतम्` (उ → व्)
        *   `पितृ + आदेशः = पित्रादेशः` (ऋ → र्)
    *   **अयादिसन्धिः:** 'ए/ऐ/ओ/औ' इत्यस्य स्थाने 'अय्/आय्/अव्/आव्' भवति, यदि पश्चात् कोऽपि स्वरः आगच्छति।
        *   `ने + अनम् = नयनम्` (ए → अय्)
        *   `पौ + अकः = पावकः` (औ → आव्)
    *   **पूर्वरूपसन्धिः:** पदान्ते 'ए/ओ' इत्यस्य पश्चात् ह्रस्वः 'अ' आगच्छति चेत् 'अ' पूर्ववर्णे लीयते, तस्य स्थाने अवग्रहः (ऽ) लिख्यते।
        *   `हरे + अव = हरेऽव`
        *   `विष्णो + अव = विष्णोऽव`
    *   **प्रकृतिभावसन्धिः:** केषुचित् स्थलेषु सन्धिः न भवति, वर्णाः यथावत् तिष्ठन्ति। यथा - द्विवचने ईकारान्ते, ऊकारान्ते, एकारान्ते पदे परे स्वरे सति।
        *   `कवी + इच्छतः = कवी इच्छतः` (न तु कवीच्छतः)
        *   `बालिके + आगच्छतः = बालिके आगच्छतः`
    *   **पररूपसन्धिः:** उपसर्गस्य 'अ' इत्यस्य पश्चात् 'ए/ओ' आगच्छति चेत् 'अ' परवर्णे (ए/ओ) लीयते।
        *   `प्र + एजते = प्रेजते` (न तु प्रैजते)
        *   `उप + ओषति = उपोषति` (न तु उपौषति)

3.  **व्यञ्जनसन्धेः प्रकाराः:**
    *   **श्चुत्वम्:** स्/तवर्गः → श्/चवर्गः। `सत् + चित् = सच्चित्`; `मनस् + चलति = मनश्चलति`।
    *   **ष्टुत्वम्:** स्/तवर्गः → ष्/टवर्गः। `तत् + टीका = तट्टीका`; `रामस् + षष्ठः = रामष्षष्ठः`।
    *   **जश्त्वम्:** पदान्ते वर्गस्य १,२,३,४ वर्णः → स्ववर्गस्य तृतीयवर्णः। `वाक् + ईशः = वागीशः`; `जगत् + ईशः = जगदीशः`।
    *   **चर्त्वम्:** वर्गस्य २,३,४ वर्णः → स्ववर्गस्य प्रथमवर्णः। `सद् + कारः = सत्कारः`।
    *   **अनुस्वारः:** पदान्ते म् → (ं)। `हरिम् + वन्दे = हरिं वन्दे`।
    *   **परसवर्णः:** अनुस्वारः → परवर्णस्य पञ्चमवर्णः। `अं + कितः = अङ्कितः`; `सं + चयः = सञ्चयः`।
    *   **लत्वम्:** तवर्गः → ल्। `उत् + लेखः = उल्लेखः`; `महान् + लाभः = महांल्लाभः`।
    *   **छत्वम्:** श् → छ्। `तत् + श्रुत्वा = तच्छ्रुत्वा`।
    *   **'च्'-आगमः:** ह्रस्वस्वरः + छ् → च् + छ्। `तरु + छाया = तरुच्छाया`।
    *   **'र्'-लोपः:** र् + र् → पूर्वस्वरः दीर्घः, प्रथम 'र्' लोपः। `निर् + रोगः = नीरोगः`।
    *   **णत्वम्:** ऋ/र्/ष् पश्चात् न् → ण्। `नर् + आनाम् = नराणाम्`; `कृष् + नः = कृष्णः`।

4.  **विसर्गसन्धेः प्रकाराः:**
    *   **सत्वम्:** विसर्गः → स्/श्/ष्। `नमः + ते = नमस्ते`; `निः + चलः = निश्चलः`; `धनुः + टङ्कारः = धनुष्टङ्कारः`।
    *   **षत्वम्:** इ/उ + : + क्/ख्/प्/फ् → ष्। `निः + कपटः = निष्कपटः`। (अपवादः - `नमः + कारः = नमस्कारः`)
    *   **उत्वम् (ओ):**
        *   अ + : + अ → ओऽ। `सः + अवदत् = सोऽवदत्`।
        *   अ + : + घोषव्यञ्जनम् → ओ। `मनः + रथः = मनोरथः`; `बालः + गच्छति = बालो गच्छति`।
    *   **रुत्वम् (र्):** अ/आ भिन्नः स्वरः + : + स्वरः/घोषव्यञ्जनम् → र्। `मुनिः + अयम् = मुनिरयम्`; `गुरुः + जयति = गुरुर्जयति`।

## 🧩 सक्रिय-अधिगमः (Active Learning)

*   **क्रियाकलापः (Activity): श्लोकेषु सन्धि-विश्लेषणम् 🔍**
    *   अधः दत्तं श्लोकं पठित्वा तत्र आगतान् सन्धिपदान् चित्वा तेषां विच्छेदं कृत्वा सन्धेः नाम लिखत।
        *   `यदा यदा हि धर्मस्य ग्लानिर्भवति भारत।`
        *   `अभ्युत्थानमधर्मस्य तदात्मानं सृजाम्यहम्॥` (भगवद्गीता ४.७)
    *   *उदाहरणम्:* `ग्लानिर्भवति = ग्लानिः + भवति` (विसर्गसन्धिः - रुत्वम्)
    *   *विश्लेषणार्थं पदानि:* `यदा यदा`, `ग्लानिर्भवति`, `अभ्युत्थानमधर्मस्य` (`अभ्युत्थानम् + अधर्मस्य`), `तदात्मानम्` (`तदा + आत्मानम्`), `सृजाम्यहम्` (`सृजामि + अहम्`)।

*   **चर्चा (Discussion): सन्धेः उच्चारणार्थं अर्थज्ञानार्थं च महत्त्वम् 🌍**
    *   संस्कृतभाषायां सन्धेः किं महत्त्वम् अस्ति?
    *   यदि सन्धि-नियमाः न स्युः तर्हि भाषायाः पठने, उच्चारणे, अर्थावबोधने च काः समस्याः भवेयुः?
    *   वेदमन्त्रेषु, श्लोकेषु च सन्धेः प्रयोगः कथं सौन्दर्यं प्रवाहं च जनयति? उदाहरणैः सह चर्चां कुरुत।

    *   `नमस्ते = ? + ?`
    *   `सज्जनः = ? + ?`
    *   `दिगम्बरः = ? + ?`
    *   `मनोरथः = ? + ?`

3.  **रेखाङ्कितपदेषु सन्धिं/सन्धि-विच्छेदं कृत्वा वाक्यं पुनः लिखत:**
    *   `सूर्य + उदयः` भवति।
    *   `मम + एव` इदं पुस्तकम् अस्ति।
    *   `स्वागतम्` अत्र भवताम्।

    *   `तट्टीका` रमणीया अस्ति।

## 🌏 भारतीयः सन्दर्भः (Bharatiya Context)

सन्धिः केवलं व्याकरणस्य नियमः नास्ति, अपितु भारतीयभाषाणां, विशेषतः संस्कृतस्य, अभिन्नम् अङ्गम् अस्ति।

*   **प्राचीनग्रन्थेषु प्रयोगः:** वेदाः, उपनिषदः, रामायणम् (`राम + अयनम्`), महाभारतम्, पुराणानि, काव्यानि च सन्धिभिः युक्तानि सन्ति। सन्धिज्ञानं विना एतेषां ग्रन्थानां शुद्धम् उच्चारणं अर्थावबोधनं च कठिनं भवति।
    *   यथा - `ईशावास्यमिदं सर्वम्...` (`ईश + आवास्यम् + इदम्`)
*   **मन्त्रेषु नामसु च:** बहवः मन्त्राः (`ॐ नमः शिवाय`), देवतानां नामानि (`गणेशः = गण + ईशः`, `महेशः = महा + ईशः`), व्यक्तीनां नामानि (`रवीन्द्रः = रवि + इन्द्रः`, `सुरेशः = सुर + ईशः`) च सन्धि-नियमान् अनुसरन्ति।
*   **भाषायाः प्रवाहः सौन्दर्यं च:** सन्धिः शब्दान् योजयित्वा भाषायां प्रवाहं, सङ्गीतं, सङ्क्षिप्ततां च आनयति। अनेन उच्चारणं सुकरं भवति।
*   **अन्यभारतीयभाषासु प्रभावः:** संस्कृतस्य प्रभावः अनेकासु आधुनिकभारतीयभाषासु (हिन्दी, मराठी, बङ्गाली, कन्नड इत्यादि) दृश्यते, यत्र तत्समशब्देषु सन्धेः नियमाः प्रायः पाल्यन्ते।

अतः, सन्धि-ज्ञानं न केवलं परीक्षादृष्ट्या, अपितु भारतीयसंस्कृतेः, साहित्यस्य, भाषायाः च गभीर-अवबोधनार्थम् आवश्यकम् अस्ति।
