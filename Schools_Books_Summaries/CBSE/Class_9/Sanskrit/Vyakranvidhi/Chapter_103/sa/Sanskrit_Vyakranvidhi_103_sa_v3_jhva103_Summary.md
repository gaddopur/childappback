## 📘 प्रमुख-अधिगमबिन्दवः (Key Learnings)
(विस्तृताः व्याख्याः सरलसंस्कृतेन)

**१. सन्धिः कः?**
द्वयोः वर्णयोः अत्यन्तसमीपस्थितौ (संहितायाम्) यः वर्णविकारः (परिवर्तनम्) भवति, सः सन्धिः इति कथ्यते।
*   यथा - `विद्या + आलयः = विद्यालयः` (अत्र आ + आ = आ इति दीर्घः एकादेशः)

**२. सन्धेः मुख्यभेदाः**
*   **स्वरसन्धिः (अच्):** यदा स्वरवर्णेन सह स्वरवर्णस्य मेलनं भवति।
    *   **दीर्घः (अकः सवर्णे दीर्घः):** यदि अ/आ, इ/ई, उ/ऊ, ऋ/ॠ इत्येतेषां पश्चात् सवर्णः (समानः) ह्रस्वः दीर्घः वा स्वरः आगच्छति, तर्हि द्वयोः स्थाने सवर्णः दीर्घः स्वरः (आ, ई, ऊ, ॠ) भवति।
        *   `पुस्तक + आलयः ➡️ पुस्तकालयः`
        *   `गिरि + ईशः ➡️ गिरीशः`
        *   `भानु + उदयः ➡️ भानूदयः`
    *   **गुणः (आद्गुणः):** यदि अ/आ इत्यस्य पश्चात् इ/ई, उ/ऊ, ऋ/ॠ आगच्छति, तर्हि क्रमेण ए, ओ, अर् इति गुणादेशाः भवन्ति।
        *   `गण + ईशः ➡️ गणेशः`
        *   `महा + उत्सवः ➡️ महोत्सवः`
        *   `देव + ऋषिः ➡️ देवर्षिः`
    *   **वृद्धिः (वृद्धिरेचि):** यदि अ/आ इत्यस्य पश्चात् ए/ऐ, ओ/औ आगच्छति, तर्हि क्रमेण ऐ, औ इति वृद्ध्यादेशौ भवतः।
        *   `मम + एव ➡️ ममैव`
        *   `जल + ओघः ➡️ जलौघः`
    *   **यण् (इको यणचि):** यदि इ/ई, उ/ऊ, ऋ/ॠ, लृ इत्येतेषां पश्चात् असमानः स्वरः आगच्छति, तर्हि तेषां स्थाने क्रमेण य्, व्, र्, ल् इति आदेशाः भवन्ति।
        *   `इति + आदि ➡️ इत्यादि`
        *   `सु + आगतम् ➡️ स्वागतम्`
        *   `पितृ + आदेशः ➡️ पित्रादेशः`
    *   **अयादिः (एचोऽयवायावः):** यदि ए, ऐ, ओ, औ इत्येतेषां पश्चात् कोऽपि स्वरः आगच्छति, तर्हि तेषां स्थाने क्रमेण अय्, आय्, अव्, आव् इति आदेशाः भवन्ति।
        *   `ने + अनम् ➡️ नयनम्`
        *   `नै + अकः ➡️ नायकः`
        *   `पो + अनः ➡️ पवनः`
        *   `पौ + अकः ➡️ पावकः`
    *   **पूर्वरूपम् (एङः पदान्तादति):** यदि पदान्ते स्थितस्य ए/ओ इत्यस्य पश्चात् ह्रस्वः 'अ' आगच्छति, तर्हि 'अ'कारः पूर्वे ए/ओ रूपे लीनः भवति, तस्य स्थाने अवग्रहचिह्नं (ऽ) लिख्यते।
        *   `हरे + अव ➡️ हरेऽव`
        *   `विष्णो + अत्र ➡️ विष्णोऽत्र`
    *   **प्रकृतिभावः (प्लुतप्रगृह्या अचि नित्यम्):** यत्र सन्धिकार्यस्य प्राप्तिः अस्ति, परन्तु नियमविशेषेण सन्धिः न भवति, वर्णाः यथास्थितौ तिष्ठन्ति। ईकारान्ताः, ऊकारान्ताः, एकारान्ताः द्विवचनशब्दाः प्रगृह्यसंज्ञकाः भवन्ति, तेषां परतः स्वरे सति सन्धिः न भवति।
        *   `कवी + इच्छतः ➡️ कवी इच्छतः` (न तु कवीच्छतः)
        *   `विष्णू + इमौ ➡️ विष्णू इमौ`
        *   `बालिके + आगच्छतः ➡️ बालिके आगच्छतः`
    *   **पररूपम् (एङि पररूपम्):** यदि 'अ'कारान्तोपसर्गस्य पश्चात् ए/ओ इत्यारब्धा धातुः आगच्छति, तर्हि उपसर्गस्य 'अ'कारः परवर्तिनि ए/ओ रूपे लीनः भवति (पररूपमेकादेशः)।
        *   `प्र + एजते ➡️ प्रेजते`
        *   `उप + ओषति ➡️ उपोषति`

*   **व्यञ्जनसन्धिः (हल्):** यदा व्यञ्जनस्य स्वरेण अथवा व्यञ्जनेन सह मेलनं भवति।
    *   **श्चुत्वम् (स्तोः श्चुना श्चुः):** स्/तवर्गस्य (त्, थ्, द्, ध्, न्) श्/चवर्गेण (च्, छ्, ज्, झ्, ञ्) सह योगे स् स्थाने श्, तवर्गस्य स्थाने चवर्गः भवति।
        *   `मनस् + चलति ➡️ मनश्चलति`
        *   `सत् + चित् ➡️ सच्चित्`
    *   **ष्टुत्वम् (ष्टुना ष्टुः):** स्/तवर्गस्य ष्/टवर्गेण (ट्, ठ्, ड्, ढ्, ण्) सह योगे स् स्थाने ष्, तवर्गस्य स्थाने टवर्गः भवति।
        *   `रामस् + षष्ठः ➡️ रामष्षष्ठः`
        *   `तत् + टीका ➡️ तट्टीका`
    *   **जश्त्वम् (झलां जशोऽन्ते):** पदान्ते स्थितानां वर्गीय-प्रथम-द्वितीय-तृतीय-चतुर्थवर्णानां (झल्) स्थाने स्वस्य वर्गस्य तृतीयवर्णः (जश् - ज्, ब्, ग्, ड्, द्) भवति, यदि परतः स्वरः अथवा मृदुव्यञ्जनम् अस्ति।
        *   `वाक् + ईशः ➡️ वागीशः`
        *   `जगत् + अम्बा ➡️ जगदम्बा`
    *   **चर्त्वम् (खरि च):** यदि वर्गाणां द्वितीय-तृतीय-चतुर्थवर्णानां पश्चात् वर्गस्य प्रथमः/द्वितीयः वर्णः अथवा श्, ष्, स् आगच्छति, तर्हि पूर्ववर्णः स्ववर्गस्य प्रथमवर्णः (चर्) भवति।
        *   `सद् + कारः ➡️ सत्कारः`
    *   **अनुस्वारः (मोऽनुस्वारः):** पदान्ते स्थितस्य 'म्' इत्यस्य पश्चात् यदि व्यञ्जनम् आगच्छति, तर्हि 'म्' स्थाने अनुस्वारः (ं) भवति।
        *   `हरिम् + वन्दे ➡️ हरिं वन्दे`
    *   **परसवर्णः (अनुस्वारस्य ययि परसवर्णः):** अनुस्वारस्य पश्चात् यदि कोऽपि वर्गीयव्यञ्जनः (यय्) आगच्छति, तर्हि अनुस्वारस्य स्थाने परवर्णस्य वर्गस्य पञ्चमवर्णः भवति। (अपदान्ते प्रायः)
        *   `अं + कितः ➡️ अङ्कितः`
        *   `सं + चयः ➡️ सञ्चयः`
    *   **लत्वम् (तोर्लि):** तवर्गस्य पश्चात् 'ल्' आगच्छति चेत्, तवर्गस्य स्थाने 'ल्' भवति। 'न्' पश्चात् 'ल्' चेत् अनुनासिकः 'लँ' भवति।
        *   `उत् + लेखः ➡️ उल्लेखः`
        *   `महान् + लाभः ➡️ महाँल्लाभः`

*   **विसर्गसन्धिः:** यदा विसर्गस्य (:) पश्चात् स्वरः अथवा व्यञ्जनम् आगच्छति।
    *   **सत्वम् (विसर्जनीयस्य सः):** विसर्गस्य पश्चात् चर्-प्रत्याहारस्य वर्णेषु (वर्गीय प्रथम/द्वितीय, श्, ष्, स्) सत्सु विसर्गस्य 'स्' भवति। परन्तु श् परे चेत् श्, ट्/ठ् परे चेत् ष् भवति।
        *   `नमः + ते ➡️ नमस्ते`
        *   `निः + चलः ➡️ निश्चलः`
        *   `धनुः + टङ्कारः ➡️ धनुष्टङ्कारः`
    *   **षत्वम्:** यदि विसर्गस्य पूर्वम् इ/उ अस्ति, परतः च क्/ख्/प्/फ् अस्ति, तर्हि विसर्गस्य 'ष्' भवति।
        *   `निः + कपटः ➡️ निष्कपटः`
    *   **रुत्व-उत्व-गुण-पूर्वरूपम् (अतो रोरप्लुतादप्लुते, हशि च):**
        *   यदि विसर्गस्य पूर्वम् 'अ' अस्ति, परतः च 'अ' अस्ति, तर्हि विसर्गः -> रु -> उ -> (अ+उ=) ओ भवति, परस्य 'अ'कारस्य अवग्रहः (ऽ) भवति। `कः + अपि ➡️ कोऽपि`
        *   यदि विसर्गस्य पूर्वम् 'अ' अस्ति, परतः च मृदुव्यञ्जनम् (हश् - वर्गीय ३,४,५, य्, व्, र्, ल्, ह्) अस्ति, तर्हि विसर्गः -> रु -> उ -> (अ+उ=) ओ भवति। `मनः + हरः ➡️ मनोहरः`
    *   **रुत्वम्:** यदि विसर्गस्य पूर्वम् अ/आ भिन्नः स्वरः अस्ति, परतः च स्वरः अथवा मृदुव्यञ्जनम् अस्ति, तर्हि विसर्गस्य 'र्' भवति।
        *   `मुनिः + अयम् ➡️ मुनिरयम्`
        *   `गुरुः + जयति ➡️ गुरुर्जयति`

## 🧩 सक्रिय-अधिगमः (Active Learning)

*   **प्रवृत्तिः (Activity): शोध-आधारित-विश्लेषणम् 🔍**
    अधः दत्तस्य सुभाषितस्य सन्धिपदानि चित्वा तेषां विच्छेदं कुरुत, सन्धेः नाम च लिखत।
    *   **सुभाषितम्:** `विद्या ददाति विनयम्, विनयाद् याति पात्रताम्। पात्रत्वाद् धनमाप्नोति, धनाद् धर्मं ततः सुखम्॥`
    *   **विश्लेषणार्थं पदानि:** `विनयाद्याति` (विनयात् + याति - जश्त्व/व्यञ्जन), `पात्रत्वाद्धनम्` (पात्रत्वात् + धनम् - जश्त्व/व्यञ्जन), `धनमाप्नोति` (धनम् + आप्नोति - संयोगः/व्यञ्जन), `धनाद्धर्मम्` (धनात् + धर्मम् - जश्त्व/व्यञ्जन)। (एवं विश्लेषणं करणीयम्)

*   **चर्चा (Discussion): वास्तविक-जगति प्रभावस्य विश्लेषणम् 🌍**
    *   **विषयः:** संस्कृत-साहित्यस्य अवगमने सन्धेः महत्त्वम्।
    *   **चर्चाबिन्दवः:**
        *   सन्धिज्ञानं विना श्लोकानां पदानां च अर्थग्रहणे काः समस्याः भवन्ति?
        *   संहितापाठे (यथा वेदमन्त्रेषु) सन्धेः भूमिका का?
        *   उच्चारणे सन्धेः प्रभावः कः?
        *   आधुनिक-भारतीय-भाषासु अपि किं सन्धेः प्रभावः दृश्यते? उदाहरणानि ददत।

## 🌏 भारतीयः सन्दर्भः (Bharatiya Context)
📊 सन्धिप्रकरणं केवलं व्याकरणस्य नियमः नास्ति, अपितु **भारतस्य समृद्ध-भाषावैज्ञानिक-परम्परायाः** अभिन्नम् अङ्गम् अस्ति। संस्कृतभाषा भारतस्य एका शास्त्रीया भाषा अस्ति यस्यां विपुलं ज्ञानं निहितम् अस्ति।

*   **प्राचीन-ग्रन्थानाम् अवगमनम्:** वेद-उपनिषद्-पुराण-रामायण-महाभारतादिषु ग्रन्थेषु, तथैव आयुर्वेद-ज्यौतिष-गणित-दर्शनादिषु शास्त्रेषु सन्धेः प्रयोगः बहुलतया दृश्यते। सन्धिज्ञानं विना एतेषां ग्रन्थानां सम्यक् अध्ययनं, तेषां अर्थावगमनं च कठिनं भवति।
*   **भाषायाः प्रवाहः सौन्दर्यं च:** सन्धिः शब्दानां मेलनेन भाषायां प्रवाहं, सङ्क्षिप्ततां, श्रुतिमाधुर्यं च आनयति।
*   **भारतीय-ज्ञान-परम्परा:** सन्धिज्ञानम् अस्मान् **भारतीय-ज्ञान-परम्परायाः** (Indian Knowledge Systems) मूलाधारैः सह योजयति। यतः अस्माकं पूर्वजानां ज्ञानं, विज्ञानं, संस्कृतिः, इतिहासः च मुख्यतया संस्कृतभाषायामेव सङ्ग्रथितः अस्ति। अतः, सन्धि-नियमानाम् अध्ययनं भारतीय-विरासतः (heritage) अवगमनाय अत्यावश्यकम् अस्ति।
