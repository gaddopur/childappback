# [कक्षा ९] व्याकरणवीथिः - अध्यायः १०३ (सन्धिः)

## 🌟 मूलाधाराः (Core Concepts)
सन्धिप्रकरणस्य विस्तृतं सोपानक्रमम् 📊

**सन्धिः** (वर्णविकारः / परिवर्तनम्)
*   **परिभाषा:** द्वयोः वर्णयोः अत्यन्तसमीपस्थितौ (संहितायाम्) यः वर्णविकारः जायते, सः सन्धिः। (यथा - विद्या + आलयः = विद्यालयः)
*   **मुख्यभेदाः:**
    1.  **स्वरसन्धिः (अच्-सन्धिः):** स्वरवर्णयोः मेलनेन जातः विकारः।
        *   दीर्घसन्धिः (अकः सवर्णे दीर्घः) - (अ/आ + अ/आ = आ; इ/ई + इ/ई = ई; उ/ऊ + उ/ऊ = ऊ; ऋ/ॠ + ऋ/ॠ = ॠ)
        *   गुणसन्धिः (आद्गुणः) - (अ/आ + इ/ई = ए; अ/आ + उ/ऊ = ओ; अ/आ + ऋ/ॠ = अर्)
        *   वृद्धिसन्धिः (वृद्धिरेचि) - (अ/आ + ए/ऐ = ऐ; अ/आ + ओ/औ = औ)
        *   यण्सन्धिः (इको यणचि) - (इ/ई → य्; उ/ऊ → व्; ऋ/ॠ → र्; लृ → ल्; पश्चात् असमानः स्वरः चेत्)
        *   अयादिसन्धिः (एचोऽयवायावः) - (ए → अय्; ऐ → आय्; ओ → अव्; औ → आव्; पश्चात् कोऽपि स्वरः चेत्)
        *   पूर्वरूपसन्धिः (एङः पदान्तादति) - (पदान्ते ए/ओ + ह्रस्वः अ → एऽ/ओऽ)
        *   प्रकृतिभावः (प्लुतप्रगृह्या अचि नित्यम्) - (सन्धेः अभावः - ईत्/ऊत्/एत् द्विवचनम्, अदसः 'म' पश्चात् ई/ऊ, प्लुतस्वरः च)
        *   पररूपसन्धिः (एङि पररूपम्) - (अ-कारान्त-उपसर्गः + ए/ओ → ए/ओ)
    2.  **व्यञ्जनसन्धिः (हल्-सन्धिः):** व्यञ्जनस्य पश्चात् स्वरस्य व्यञ्जनस्य वा मेलनेन व्यञ्जने जातः विकारः।
        *   श्चुत्वम् (स्तोः श्चुना श्चुः) - (स्/तवर्गः + श्/चवर्गः → श्/चवर्गः)
        *   ष्टुत्वम् (ष्टुना ष्टुः) - (स्/तवर्गः + ष्/टवर्गः → ष्/टवर्गः)
        *   जश्त्वम् (झलां जशोऽन्ते) - (पदान्ते वर्गीय प्रथम/द्वितीय/तृतीय/चतुर्थवर्णः → स्ववर्गीय तृतीयवर्णः)
        *   चर्त्वम् (खरि च) - (वर्गीय द्वितीय/तृतीय/चतुर्थवर्णः + वर्गीय प्रथम/द्वितीय/श्/ष्/स् → स्ववर्गीय प्रथमवर्णः)
        *   अनुस्वारः (मोऽनुस्वारः) - (पदान्ते म् + व्यञ्जनम् → म् स्थाने अनुस्वारः ं)
        *   परसवर्णः (अनुस्वारस्य ययि परसवर्णः) - (अनुस्वारः + वर्गीयव्यञ्जनम् → अनुस्वारस्थाने अग्रिमवर्णस्य वर्गस्य पञ्चमवर्णः)
        *   लत्वम् (तोर्लि) - (तवर्गः + ल् → ल्; न् + ल् → ँल्)
        *   छत्वम् (शश्छोऽटि) - (वर्गीय प्रथम-चतुर्थवर्णः/र्/ल्/व्/ह् + श् → श् स्थाने छ्)
        *   च्-आगमः (छे च) - (ह्रस्वस्वरः + छ् → मध्ये च्-आगमः)
        *   र्-लोपः, पूर्वस्वरदीर्घीकरणञ्च (रो रि) - (र् + र् → पूर्वस्य र्-लोपः, तत्पूर्वस्वरस्य दीर्घः)
        *   णत्वविधानम् (रषाभ्यां नो णः समानपदे) - (ऋ/र्/ष् पश्चात् न् → ण्)
    3.  **विसर्गसन्धिः:** विसर्गस्य (:) पश्चात् स्वरस्य व्यञ्जनस्य वा मेलनेन विसर्गे जातः विकारः।
        *   सत्वम् (विसर्जनीयस्य सः) - (विसर्गः + चर्/श्/ट्/ठ् → स्/श्/ष्)
        *   षत्वम् (इणः षः - implied) - (इ/उ + विसर्गः + क्/ख्/प्/फ् → ष्) (नमः/पुरः + क्/ख्/प्/फ् → स्)
        *   रुत्वम्-उत्वम्-गुणः-पूर्वरूपम् (अतो रोरप्लुतादप्लुते, हशि च) - (अ + विसर्गः + अ → ओऽ; अ + विसर्गः + मृदुव्यञ्जनम् → ओ)
        *   रुत्वम् (विसर्गस्य रः - implied) - (अ/आ भिन्नः स्वरः + विसर्गः + स्वरः/मृदुव्यञ्जनम् → र्)

## 📘 मुख्याधिगमाः (Key Learnings)
विस्तृतविवरणानि रेखाचित्रैः सह 📈

*   **सन्धेः आवश्यकता:** संस्कृतभाषायां पदानि प्रायः सन्धिं कृत्वा एव लिख्यन्ते, उच्यन्ते च। अनेन भाषायां प्रवाहः, सङ्क्षिप्तता, श्रुतिमाधुर्यं च आयाति। सम्यक् सन्धिज्ञानेन एव शब्दानां मूलरूपं, तेषाम् अर्थं च ज्ञातुं शक्नुमः।
*   **स्वरसन्धि-नियमाः (उदाहरणसहिताः):**
    *   **दीर्घः:** पुस्तक + आलयः = पुस्तकालयः (अ+आ=आ) | गिरि + इन्द्रः = गिरीन्द्रः (इ+इ=ई) | भानु + उदयः = भानूदयः (उ+उ=ऊ) | पितृ + ऋणम् = पितॄणम् (ऋ+ऋ=ॠ)
    *   **गुणः:** नर + इन्द्रः = नरेन्द्रः (अ+इ=ए) | महा + उत्सवः = महोत्सवः (आ+उ=ओ) | ग्रीष्म + ऋतुः = ग्रीष्मर्तुः (अ+ऋ=अर्)
    *   **वृद्धिः:** मम + एव = ममैव (अ+ए=ऐ) | जल + ओघः = जलौघः (अ+ओ=औ)
    *   **यण्:** यदि + अपि = यद्यपि (इ→य्) | सु + आगतम् = स्वागतम् (उ→व्) | पितृ + आदेशः = पित्रादेशः (ऋ→र्) | लृ + आकृतिः = लाकृतिः (लृ→ल्)
    *   **अयादिः:** ने + अनम् = नयनम् (ए→अय्) | नै + अकः = नायकः (ऐ→आय्) | पो + अनम् = पवनम् (ओ→अव्) | पौ + अकः = पावकः (औ→आव्)
    *   **पूर्वरूपम्:** हरे + अव = हरेऽव (ए+अ=एऽ) | विष्णो + अव = विष्णोऽव (ओ+अ=ओऽ)
    *   **प्रकृतिभावः:** कवी + इच्छतः = कवी इच्छतः (ईकारान्तद्विवचनम्) | विष्णू + इमौ = विष्णू इमौ (ऊकारान्तद्विवचनम्) | बालिके + आगच्छतः = बालिके आगच्छतः (एकारान्तद्विवचनम्)
    *   **पररूपम्:** प्र + एजते = प्रेजते (अ+ए=ए) | उप + ओषति = उपोषति (अ+ओ=ओ)

*   **व्यञ्जनसन्धि-नियमाः (उदाहरणसहिताः):**
    *   **श्चुत्वम्:** सत् + चित् = सच्चित् (त्→च्) | रामस् + शेते = रामश्शेते (स्→श्)
    *   **ष्टुत्वम्:** तत् + टीका = तट्टीका (त्→ट्) | रामस् + षष्ठः = रामष्षष्ठः (स्→ष्)
    *   **जश्त्वम्:** वाक् + ईशः = वागीशः (क्→ग्) | जगत् + अम्बा = जगदम्बा (त्→द्)
    *   **चर्त्वम्:** सद् + कारः = सत्कारः (द्→त्)
    *   **अनुस्वारः:** हरिम् + वन्दे = हरिं वन्दे (म्→ं)
    *   **परसवर्णः:** अं + कितः = अङ्कितः (ं→ङ्) | सं + चयः = सञ्चयः (ं→ञ्)
    *   **लत्वम्:** उत् + लेखः = उल्लेखः (त्→ल्) | महान् + लाभः = महाँल्लाभः (न्→ँल्)
    *   **च्-आगमः:** तरु + छाया = तरुच्छाया (मध्ये च्)
    *   **र्-लोपः:** निर् + रसः = नीरसः (र्-लोपः, पूर्व-इ दीर्घः)

*   **विसर्गसन्धि-नियमाः (उदाहरणसहिताः):**
    *   **सत्वम्:** नमः + ते = नमस्ते (:→स्) | निः + चलः = निश्चलः (:→श्) | धनुः + टङ्कारः = धनुष्टङ्कारः (:→ष्)
    *   **षत्वम्:** निः + कपटः = निष्कपटः (:→ष्) | नमः + कारः = नमस्कारः (:→स्)
    *   **उत्वम्/पूर्वरूपम्:** बालः + अयम् = बालोऽयम् (अः+अ→ओऽ) | मनः + रथः = मनोरथः (अः+र्→ओ)
    *   **रुत्वम्:** मुनिः + अयम् = मुनिरयम् (इः+अ→र्) | गुरुः + जयति = गुरुर्जयति (उः+ज्→र्)

*   **सन्धि-नियम-सारणी (उदाहरणम् - गुणसन्धिः):** 📈
    | पूर्ववर्णः | परवर्णः (अग्रिमः) | सन्धि-परिणामः | उदाहरणम् |
    |---|---|---|---|
    | अ / आ | इ / ई | ए | गण + ईशः = गणेशः |
    | अ / आ | उ / ऊ | ओ | सूर्य + उदयः = सूर्योदयः |
    | अ / आ | ऋ / ॠ | अर् | देव + ऋषिः = देवर्षिः |

## 🧩 सक्रिय-अधिगमः (Active Learning)

*   **क्रियाकलापः (शोध-आधारित-विश्लेषणम्) 🔍:**
    *   **कार्यम्:** श्रीमद्भगवद्गीतायाः कञ्चित् श्लोकं चित्वा तस्मिन् प्रयुक्तान् न्यूनातिन्यूनं पञ्चविधान् सन्धीन् अन्विष्य लिखत। तेषां सन्धिच्छेदं कृत्वा सन्धेः नाम, प्रयुक्तं सूत्रं (यदि ज्ञातम्) च निर्दिशत।
    *   **उद्देश्यम्:** वास्तविक-संस्कृत-साहित्ये सन्धि-नियमानाम् अन्वेषणं, विश्लेषणं च। (Evaluating)

*   **चर्चा (विश्लेषणात्मिका) 🌍:**
    *   **विषयः:** "सन्धिः संस्कृतभाषायाः सौन्दर्यं वर्धयति, परन्तु नूतनानाम् अध्येतॄणां कृते काठिन्यम् अपि जनयति।" – एतस्य कथनस्य पक्षे विपक्षे च स्वमतानि तर्कसहितं प्रस्तुतं कुर्वन्तु। सन्धिज्ञानस्य किं व्यावहारिकं महत्त्वम् अस्ति?
    *   **उद्देश्यम्:** सन्धेः भाषायां प्रभावस्य, तस्य उपयोगितायाः च मूल्याङ्कनं, समालोचनात्मक-चिन्तनस्य विकासः। (Evaluating/Creating)

## 📝 मूल्याङ्कन-सिद्धता (Assessment Prep)
विशिष्ट-उदाहरणानि (Case Studies) एवं रेखाचित्राणि 📝

*   **विशिष्ट-उदाहरण-विश्लेषणम्:**
    *   `जगदीशः` पदस्य सन्धिच्छेदं कृत्वा नियमं स्पष्टीकुरुत। (जगत् + ईशः = जगदीशः - जश्त्वसन्धिः)
    *   `तच्छ्रुत्वा` पदस्य सन्धिच्छेदं कृत्वा नियमं स्पष्टीकुरुत। (तत् + श्रुत्वा = तच्छ्रुत्वा - श्चुत्वम्, छत्वम् च)
    *   `कवी इच्छतः` इत्यत्र सन्धिः किमर्थं न भवति? (प्रकृतिभावः - ईकारान्तद्विवचनम्)
    *   `बालोऽयम्` पदस्य सन्धिच्छेदं कृत्वा नियमं स्पष्टीकुरुत। (बालः + अयम् = बालोऽयम् - उत्वम्, पूर्वरूपम् च)
*   **अभ्यास-प्रश्नाः:**
    *   पाठ्यपुस्तके दत्तान् अभ्यासप्रश्नान् (विशेषतः प्रश्नसंख्या २, ४, ५) साधयन्तु।
    *   अधोदत्तेषु पदेषु सन्धिं/सन्धिच्छेदं कुरुत:
        *   महा + ऋषिः = ? (महर्षिः - गुणः)
        *   षट् + आननः = ? (षडाननः - जश्त्वम्)
        *   नमस्ते = ? + ? (नमः + ते - सत्वम्)
        *   स्वागतम् = ? + ? (सु + आगतम् - यण्)
        *   सज्जनः = ? + ? (सत् + जनः - श्चुत्वम्/जश्त्वम्)
*   **नियम-स्मारक-सारण्यः:** पूर्वं दर्शिताः सारण्यः (यथा - गुणसन्धिः, यण्सन्धिः) स्मृत्वा पुनरावृत्तिं कुर्वन्तु। एताः सारण्यः परीक्षाकाले शीघ्रस्मरणीयतायै सहायकाः भवन्ति।

## 🌏 भारतीय-सन्दर्भः (Bharatiya Context)
राष्ट्रिय-आर्थिक/सामाजिक-आकडाः 📊 (Note: Icon used as requested, but context is linguistic/cultural)

*   **भाषासु प्रभावः:** संस्कृतं भारतस्य अनेकासां प्रादेशिकभाषाणां (यथा - हिन्दी, मराठी, बाङ्गला, गुजराती, कन्नड, तेलुगु इत्यादयः) जननी अथवा प्रभावकभाषा अस्ति। संस्कृतस्य सन्धि-नियमाः एतासु भाषासु अपि तत्समशब्देषु (यथा - विद्यालय, सूर्योदय, गणेश, महोत्सव) साक्षात् अथवा किञ्चित्परिवर्तितरूपेण दृश्यन्ते। अनेन भारतीयभाषाणाम् एकसूत्रता ज्ञायते।
*   **ज्ञानपरम्परायां स्थानम्:** वेदाः, उपनिषदः, पुराणानि, दर्शनानि, आयुर्वेदग्रन्थाः, गणित-ज्योतिषग्रन्थाः इत्यादयः सर्वे ज्ञानग्रन्थाः प्रमुखतया संस्कृतभाषायामेव सन्ति। एतेषु ग्रन्थेषु पदानां संयोजनार्थं सन्धेः प्रयोगः अनिवार्यरूपेण कृतः अस्ति। अतः, भारतीयज्ञानपरम्परायाः सम्यक् अवगमनाय सन्धिज्ञानम् अत्यावश्यकम् अस्ति। उदाहरणार्थम्, `ईशावास्यमिदं सर्वम्` (ईश + आवास्यम् + इदम्), `तत्त्वमसि` (तत् + त्वम् + असि) इत्यादिषु वाक्येषु सन्धिज्ञानं विना अर्थावबोधः कठिनः भवति।
*   **सांस्कृतिक-महत्त्वम्:** स्तोत्रेषु, मन्त्रेषु, पूजाविधिषु च शुद्धोच्चारणस्य महत्त्वम् अस्ति। सन्धिज्ञानेन शब्दानां शुद्धम् उच्चारणं कर्तुं शक्यते, येन सांस्कृतिक-धार्मिक-क्रियाकलापानां निर्वहणं सम्यक्तया भवति। यथा - `गणेशाय नमः` (गणेश + आय), `गुरवे नमः` (गुरवे)।
