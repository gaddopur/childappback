## 📘 प्रमुखशिक्षणीयविषयाः (Key Learnings)
विस्तृता व्याख्या सचित्रम् 📈:

**१. प्रत्ययस्य परिभाषा:**
   - धातोः शब्दस्य वा पश्चात् ये विशिष्टाः शब्दांशाः अर्थविशेषं बोधयितुं युज्यन्ते, ते **प्रत्ययाः** इति कथ्यन्ते।

**२. प्रत्ययस्य प्रकाराः:**
   - **कृत्प्रत्ययाः:** एते धातुभिः सह युज्यन्ते। एतेषां योगेन संज्ञा, विशेषणम्, अव्ययं वा पदं निर्मियते।
     - **अव्ययार्थम्:**
       - **क्त्वा (त्वा):** पूर्वकालिकक्रियार्थे। *यथा:* पठ् + क्त्वा = पठित्वा (सः पठित्वा गच्छति)।
       - **ल्यप् (य):** यदि धातोः पूर्वम् उपसर्गः भवति तदा क्त्वा-प्रत्ययस्य स्थाने ल्यप्-प्रत्ययः भवति। *यथा:* प्र + नम् + ल्यप् = प्रणम्य (सः गुरुं प्रणम्य पठति)।
       - **तुमुन् (तुम्):** 'के लिए' (निमित्तार्थे) क्रियार्थे। *यथा:* पठ् + तुमुन् = पठितुम् (सः पठितुं विद्यालयं गच्छति)।
       ```mermaid
       graph LR
           A[धातुः] --> B{उपसर्गः अस्ति?};
           B -- आम् --> C[धातुः + ल्यप् (य)];
           B -- न --> D[धातुः + क्त्वा (त्वा)];
           A --> E[धातुः + तुमुन् (तुम्)];
           C --> F[अव्ययपदम् (प्रणम्य)];
           D --> G[अव्ययपदम् (गत्वा)];
           E --> H[अव्ययपदम् (गन्तुम्)];
       ```
     - **विशेषणार्थम्/वर्तमानकालार्थम्:**
       - **शतृ (अत्):** परस्मैपदीधातुभिः सह, 'करता हुआ' इति अर्थे। पुंल्लिङ्गे 'अन्', स्त्रीलिङ्गे 'अन्ती', नपुंसकलिङ्गे 'अत्' इति भवति। विशेषणरूपेण प्रयुज्यते। *यथा:* गम् + शतृ = गच्छन् (पुं.), गच्छन्ती (स्त्री.), गच्छत् (नपुं.)। (गच्छन् बालकः)।
       - **शानच् (आन/मान):** आत्मनेपदीधातुभिः सह, 'करता हुआ' इति अर्थे। विशेषणरूपेण प्रयुज्यते। *यथा:* सेव् + शानच् = सेवमानः (पुं.), सेवमाना (स्त्री.), सेवमानम् (नपुं.)। (सेवमानः भक्तः)।
     - **भूतकालार्थम्:**
       - **क्त (तः, ता, तम्):** कर्मणि/भावे प्रयुज्यते (प्रायः)। गत्यर्थक-अकर्मकधातुभिः कर्तरि अपि। *यथा:* गम् + क्त = गतः (रामः गतः), पठ् + क्त = पठितः (तेन ग्रन्थः पठितः)।
       - **क्तवतु (तवान्, तवती, तवत्):** कर्तरि भूतकालार्थे। *यथा:* गम् + क्तवतु = गतवान् (सः गतवान्), गतवती (सा गतवती)।
     - **विध्यर्थे/योग्यार्थे ('चाहिए'/'योग्य'):**
       - **तव्यत् (तव्यः, तव्या, तव्यम्):** *यथा:* पठ् + तव्यत् = पठितव्यम् (मया पुस्तकं पठितव्यम्)।
       - **अनीयर् (अनीयः, अनीया, अनीयम्):** *यथा:* कृ + अनीयर् = करणीयम् (मया कार्यं करणीयम्)।
     - **संज्ञानिर्माणार्थम्:**
       - **तृच् (ता):** कर्तृवाचकसंज्ञा। *यथा:* कृ + तृच् = कर्ता।
       - **ण्वुल् (अकः):** कर्तृवाचकसंज्ञा। *यथा:* पठ् + ण्वुल् = पाठकः।
       - **क्तिन् (तिः):** भाववाचकस्त्रीलिङ्गसंज्ञा। *यथा:* कृ + क्तिन् = कृतिः।
       - **ल्युट् (अनम्):** भाववाचकनपुंसकलिङ्गसंज्ञा। *यथा:* पठ् + ल्युट् = पठनम्।

   - **तद्धितप्रत्ययाः:** एते संज्ञा-सर्वनाम-विशेषणादि-प्रातिपदिकशब्देभ्यः परं युज्यन्ते।
     - **मतुप्/वतुप् (मान्/वान्):** 'वाला'/'युक्त' अर्थे। *यथा:* बुद्धि + मतुप् = बुद्धिमान्, धन + वतुप् = धनवान्।
     - **तरप्/तमप् (तरः/तमः):** द्वयोः/बहूनां मध्ये एकस्य श्रेष्ठत्वबोधनार्थम्। *यथा:* लघु + तरप् = लघुतरः, लघु + तमप् = लघुतमः।
     - **त्व/तल् (त्वम्/ता):** भाववाचकसंज्ञानिर्माणार्थम्। *यथा:* गुरु + त्व = गुरुत्वम्, गुरु + तल् = गुरुता।
     - **अण् (अः):** अपत्य (सन्तान), भाव, समूह, सम्बन्ध आदि अर्थेषु। आदिवृद्धिः भवति। *यथा:* वसुदेव + अण् = वासुदेवः, कुरु + अण् = कौरवः, कुशल + अण् = कौशलम्।
     - **तसिल् (तः):** पञ्चम्यर्थे (से)। अव्ययं भवति। *यथा:* ग्राम + तसिल् = ग्रामतः (ग्रामात्)।

   - **स्त्रीप्रत्ययाः:** पुंल्लिङ्गशब्दान् स्त्रीलिङ्गे परिवर्तयितुं प्रयुज्यन्ते।
     - **टाप् (आ):** अकारान्तपुंल्लिङ्गशब्देभ्यः। *यथा:* अज + टाप् = अजा, बालक + टाप् = बालिका (अन्ते 'अक' चेत् 'इक' भवति)।
     - **ङीप् (ई):** ऋकारान्त, नकारान्त, शतृ-प्रत्ययान्त, अकारान्त (क्वचित्) शब्देभ्यः। *यथा:* कर्तृ + ङीप् = कर्त्री, गुणिन् + ङीप् = गुणिनी, गच्छत् + ङीप् = गच्छन्ती, देव + ङीप् = देवी।

## 🧩 सक्रिय-अधिगमः (Active Learning)

- **गतिविधिः (Activity): शोध-आधारित-विश्लेषणम् (Research-based case study analysis) 🔍**
  - लघुसंस्कृत-कथां (यथा - पञ्चतन्त्रतः, हितोपदेशात् वा) पठित्वा तत्र आगतान् न्यूनातिन्यूनं पञ्चविधान् (क्त्वा, शतृ, क्त, तव्यत्, मतुप्/टाप् इत्यादि) प्रत्ययान् चिनुत। तेषां प्रकृतिं (धातुं/शब्दं) प्रत्ययं च पृथक् कृत्वा तेषां कार्यं (अर्थं) लिखत।
  *उदाहरणम्:* "अस्ति गोदावरीतीरे विशालः शाल्मलीतरुः। तत्र **निवसन्ति** स्म पक्षिणः।" (नि + वस् + शतृ + ङीप् = निवसन्त्यः -> निवसन्ति [प्रयोगाधारितम्]) - अत्र 'निवसन्ति' पदे शतृ-प्रत्ययस्य प्रयोगः वर्तमानकालिककर्तॄणां बोधनाय अस्ति।

- **चर्चा (Discussion): वास्तविक-जगति प्रभावस्य आलोचनात्मकं विश्लेषणम् (Critical analysis of real-world impacts) 🌍**
  - संस्कृतभाषायां प्रत्ययानां किं महत्त्वम् अस्ति? कथं प्रत्ययाः नूतनशब्दानां निर्माणे, अर्थस्य विस्तारे च साहाय्यं कुर्वन्ति? प्राचीनग्रन्थानाम् (यथा - गीता, उपनिषदः) अवगमने प्रत्ययज्ञानं कथम् आवश्यकम्? एतेषां भाषासमृद्धौ किं योगदानम्? इति विषये समूहेषु चर्चां कुरुत। स्वविचारान् तर्कैः सह उपस्थापयत।

     - **अजा** क्षेत्रे चरति। (प्रकृतिः: ______, प्रत्ययः: ______)
  2. कोष्ठके दत्तैः प्रकृति-प्रत्ययैः पदं निर्माय रिक्तस्थानानि पूरयत:
     - अहं जलं ______ (पा + तुमुन्) इच्छामि।
     - ______ (गम् + क्त) छात्रान् शिक्षकः अपृच्छत्।
     - सा ______ (बुद्धि + मतुप्) अस्ति।
     - एषा ______ (बालक + टाप्) अस्ति।
     - ______ (कृ + तव्यत्) कार्याणि शीघ्रं समापयेत्।

- **स्मरणीय-तालिकाः:** उपर्युक्ताः 'प्रमुखशिक्षणीयविषयाः' विभागे दत्ताः तालिकाः, वर्गीकरणवृक्षः च परीक्षासिद्धतार्थम् अवलोकनीयाः।

## 🌏 भारतीय-सन्दर्भः (Bharatiya Context)
राष्ट्रिय-भाषावैज्ञानिक-परम्परा 📊:

- **पाणिनीय-परम्परा:** संस्कृतव्याकरणस्य वैज्ञानिकं विश्लेषणं महर्षिणा पाणिनिना स्वस्य 'अष्टाध्यायी' इति विश्वप्रसिद्धे ग्रन्थे कृतम्। प्रत्ययाः अस्य व्याकरणस्य आधारस्तम्भाः सन्ति, यैः धातुभ्यः शब्देभ्यश्च सहस्रशः पदानि निष्पाद्यन्ते।
- **भारतीय-ज्ञान-स्रोतः:** प्रत्ययज्ञानं वेदान्, उपनिषदः, गीताम्, रामायणम्, महाभारतम्, पुराणानि, काव्यानि, दर्शनानि च सम्यक् अवगन्तुम् अत्यावश्यकम् अस्ति।
- **सांस्कृतिक-उदाहरणानि:** अस्मिन् पाठे प्रयुक्तानि उदाहरणानि यथा - रामः, सीता, कृष्णः, वासुदेवः, पाण्डवः, सरस्वती, गुरुः, शिष्यः, भारतीयः (भारत + ठक् -> ईयः) इत्यादयः भारतीयसंस्कृतेः अभिन्नम् अङ्गम् सन्ति। एतेषां शब्दानां व्युत्पत्तिः प्रत्ययैः एव भवति।
- **भाषा-समृद्धिः:** प्रत्ययानां योगेन संस्कृतभाषायां सूक्ष्मार्थभेदान् प्रदर्शयितुं, नूतनसङ्कल्पनाः व्यक्तुं च अपूर्वा क्षमता वर्तते। यथा - 'गम्' धातोः गतः, गतवान्, गत्वा, गन्तुम्, गमनीयम्, गमनम्, इत्यादि अनेकरूपाणि प्रत्ययैः एव सिद्ध्यन्ति।
