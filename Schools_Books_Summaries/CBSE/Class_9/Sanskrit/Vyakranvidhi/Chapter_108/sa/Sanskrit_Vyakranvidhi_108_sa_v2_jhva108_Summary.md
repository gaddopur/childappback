# [कक्षा ९] व्याकरणविधिः - अध्यायः १०८

## 🌟 मुख्याः अवधारणाः (Core Concepts) 📊

**प्रत्ययस्य परिभाषा:** कस्यापि धातोः शब्दस्य वा पश्चात् ये शब्दांशाः युज्यन्ते, ते प्रत्ययाः कथ्यन्ते।

**प्रत्ययानां वर्गीकरणम्:**
१.  **कृत्-प्रत्ययाः:** ये धातुभिः सह युज्यन्ते (संज्ञा-विशेषण-अव्ययनिर्माणार्थम्)।
    *   उदाहरणम्: गम् + क्त्वा = गत्वा, पठ् + शतृ = पठन्, कृ + तव्यत् = कर्तव्यम्।
२.  **तद्धित-प्रत्ययाः:** ये संज्ञा-सर्वनाम-विशेषणादि-प्रातिपदिकैः सह युज्यन्ते (अर्थपरिवर्तनार्थम्)।
    *   उदाहरणम्: धन + मतुप् = धनवान्, लघु + तल् = लघुता, वसुदेव + अण् = वासुदेवः।
३.  **स्त्री-प्रत्ययाः:** ये पुंलिङ्गशब्दान् स्त्रीलिङ्गे परिवर्तयितुं युज्यन्ते।
    *   उदाहरणम्: अज + टाप् = अजा, नर्तक + टाप् = नर्तिका, देव + ङीप् = देवी।

**प्रत्यययोगस्य सामान्यनियमाः:**
*   प्रत्ययस्य आदौ स्थितस्य कस्यचित् वर्णस्य लोपः भवति (यथा - क्त्वा -> त्वा, तुमुन् -> तुम्)।
*   धातोः शब्दस्य वा अन्ते स्थितस्य वर्णस्य परिवर्तनं भवति (यथा - गुणः, वृद्धिः, सम्प्रसारणम्)।
*   केषुचित् स्थलेषु आगमः (नूतनवर्णस्य योजनम्) भवति (यथा - ल्यप् मध्ये 'त्', क्त मध्ये 'इ')।

## 📘 प्रमुखाः शिक्षणबिन्दवः (Key Learnings) 📈

**१. कृत्-प्रत्ययाः (Kṛt Pratyayas):**

*   **क्त्वा (ktvā), ल्यप् (lyap):**
    *   **अर्थः:** 'कृत्वा' (करके), पूर्वकालिकक्रिया।
    *   **अवशिष्टः अंशः:** क्त्वा -> त्वा; ल्यप् -> य (धातोः पूर्वम् उपसर्गः चेत् ल्यप् भवति)।
    *   **रूपम्:** अव्ययम् (रूपं न परिवर्तते)।
    *   **उदाहरणानि:**
        *   पठ् + क्त्वा = पठित्वा (पठित्वा गृहं गच्छति।)
        *   आ + गम् + ल्यप् = आगत्य (आगत्य सः वदति।)
        *   प्र + नम् + ल्यप् = प्रणम्य (गुरुं प्रणम्य पठति।)

*   **तुमुन् (tumun):**
    *   **अर्थः:** 'कर्तुम्' (करने के लिए), क्रियायाः प्रयोजनम्।
    *   **अवशिष्टः अंशः:** तुम्।
    *   **रूपम्:** अव्ययम्।
    *   **उदाहरणानि:**
        *   पठ् + तुमुन् = पठितुम् (सः पठितुं विद्यालयं गच्छति।)
        *   गम् + तुमुन् = गन्तुम् (अहं गन्तुम् इच्छामि।)
        *   दा + तुमुन् = दातुम् (सः धनं दातुम् आगतः।)

*   **शतृ (śatṛ), शानच् (śānac):**
    *   **अर्थः:** 'कुर्वन्/कुर्वाणः' (करता हुआ), वर्तमानकालिकक्रियायाः बोधकं विशेषणम्।
    *   **अवशिष्टः अंशः:** शतृ -> अत् (परस्मैपदिधातुभिः); शानच् -> आन/मान (आत्मनेपदिधातुभिः)।
    *   **रूपम्:** विशेषणम् (त्रिषु लिङ्गेषु रूपाणि भवन्ति, विशेष्यानुसारं विभक्ति-वचन-लिङ्गानि)।
    *   **उदाहरणानि:**
        *   पठ् + शतृ = पठत् (पुं. पठन्, स्त्री. पठन्ती, नपुं. पठत्) -> पठन् बालकः।
        *   गम् + शतृ = गच्छत् (पुं. गच्छन्, स्त्री. गच्छन्ती, नपुं. गच्छत्) -> गच्छन्ती बालिका।
        *   सेव् + शानच् = सेवमान (पुं. सेवमानः, स्त्री. सेवमाना, नपुं. सेवमानम्) -> सेवमानः भक्तः।
        *   लभ् + शानच् = लभमान (पुं. लभमानः, स्त्री. लभमाना, नपुं. लभमानम्) -> लभमाना छात्रा।

*   **क्त (kta), क्तवतु (ktavatu):**
    *   **अर्थः:** भूतकालिकक्रिया।
    *   **अवशिष्टः अंशः:** क्त -> त; क्तवतु -> तवत्।
    *   **रूपम्:**
        *   क्त: कर्मणि/भावे (विशेषणरूपेण अपि), त्रिषु लिङ्गेषु। (अकर्मकधातुभिः कर्तरि अपि)।
        *   क्तवतु: कर्तरि, त्रिषु लिङ्गेषु (पुं. गतवान्, स्त्री. गतवती, नपुं. गतवत्)।
    *   **उदाहरणानि:**
        *   गम् + क्त = गतः, गता, गतम् (तेन ग्रामः गतः। / सः ग्रामं गतः।)
        *   कृ + क्त = कृतः, कृता, कृतम् (मया कार्यं कृतम्।)
        *   गम् + क्तवतु = गतवत् (पुं. गतवान्, स्त्री. गतवती) -> रामः गृहं गतवान्। सीता गृहं गतवती।
        *   पठ् + क्तवतु = पठितवत् (पुं. पठितवान्, स्त्री. पठितवती) -> छात्रः पाठं पठितवान्।

*   **तव्यत् (tavyat), अनीयर् (anīyar), यत् (yat):**
    *   **अर्थः:** 'कर्तव्यम्' (करना चाहिए / करने योग्य), विधिलिङ् अर्थः।
    *   **अवशिष्टः अंशः:** तव्यत् -> तव्य; अनीयर् -> अनीय; यत् -> य।
    *   **रूपम्:** कर्मणि/भावे, विशेषणरूपेण, त्रिषु लिङ्गेषु।
    *   **उदाहरणानि:**
        *   कृ + तव्यत् = कर्तव्यम् (मया कार्यं कर्तव्यम्।)
        *   पठ् + अनीयर् = पठनीयः (एषः ग्रन्थः पठनीयः।)
        *   दा + यत् = देयम् (जलं देयम् अस्ति।)
        *   श्रु + यत् = श्रव्यम् (इदं गीतं श्रव्यम्।)

*   **ण्वुल् (ṇvul), तृच् (tṛc):**
    *   **अर्थः:** कर्तृवाचकसंज्ञा (करने वाला)।
    *   **अवशिष्टः अंशः:** ण्वुल् -> अक; तृच् -> तृ।
    *   **रूपम्:** संज्ञा (त्रिषु लिङ्गेषु ण्वुल्, तृच्-अन्तशब्दाः पुंलिङ्गे 'कर्तृ' इव चलन्ति)।
    *   **उदाहरणानि:**
        *   नी + ण्वुल् = नायकः (नयति इति नायकः)
        *   पठ् + ण्वुल् = पाठकः (पठति इति पाठकः)
        *   कृ + तृच् = कर्तृ (पुं. कर्ता)
        *   दा + तृच् = दातृ (पुं. दाता)

*   **क्तिन् (ktin), ल्युट् (lyuṭ):**
    *   **अर्थः:** भाववाचकसंज्ञा (करना)।
    *   **अवशिष्टः अंशः:** क्तिन् -> ति; ल्युट् -> अन।
    *   **रूपम्:** क्तिन्-अन्ताः नित्यं स्त्रीलिङ्गे ('मति' इव); ल्युट्-अन्ताः प्रायः नपुंसकलिङ्गे ('फल' इव)।
    *   **उदाहरणानि:**
        *   कृ + क्तिन् = कृतिः
        *   गम् + क्तिन् = गतिः
        *   पठ् + ल्युट् = पठनम्
        *   लिख् + ल्युट् = लेखनम्

**२. तद्धित-प्रत्ययाः (Taddhita Pratyayas):**

*   **मतुप् (matup), वतुप् (vatup), इनि (ini):**
    *   **अर्थः:** 'तत् अस्य अस्ति' (वाला / से युक्त)।
    *   **अवशिष्टः अंशः:** मतुप् -> मत्; वतुप् -> वत्; इनि -> इन्।
    *   **नियमाः:** अकारान्तेभ्यः प्रायः वतुप्/इनि; इतरस्वरान्तेभ्यः मतुप्।
    *   **उदाहरणानि:**
        *   बुद्धि + मतुप् = बुद्धिमत् (पुं. बुद्धिमान्)
        *   धन + वतुप् = धनवत् (पुं. धनवान्)
        *   गुण + इनि = गुणिन् (पुं. गुणी)
        *   बल + वतुप्/इनि = बलवत् (बलवान्) / बलिन् (बली)

*   **तरप् (tarap), तमप् (tamap):**
    *   **अर्थः:** द्वयोः मध्ये एकस्य आधिक्यम् (तरप् - better); बहूनां मध्ये एकस्य आधिक्यम् (तमप् - best)।
    *   **अवशिष्टः अंशः:** तरप् -> तर; तमप् -> तम।
    *   **रूपम्:** विशेषणम्, त्रिषु लिङ्गेषु।
    *   **उदाहरणानि:**
        *   लघु + तरप् = लघुतरः (रामः मोहनात् लघुतरः।)
        *   श्रेष्ठ + तमप् = श्रेष्ठतमः (छात्राणां मध्ये सः श्रेष्ठतमः।)
        *   मधुर + तमप् = मधुरतमम् (इदं फलम् मधुरतमम्।)

*   **मयट् (mayaṭ):**
    *   **अर्थः:** प्रचुरता (abundance) / विकारः (modification)।
    *   **अवशिष्टः अंशः:** मय।
    *   **उदाहरणानि:**
        *   आनन्द + मयट् = आनन्दमयः (जीवनम् आनन्दमयम् अस्ति।)
        *   सुवर्ण + मयट् = सुवर्णमयः (सुवर्णमयः मुकुटः।)
        *   मृद् + मयट् = मृण्मयः (मृण्मयः घटः।)

*   **अण् (aṇ), ठक् (ṭhak):**
    *   **अर्थः:** अपत्यम् (संतान), भावः, समूहः, सम्बन्धः इत्यादि।
    *   **अवशिष्टः अंशः:** अण् -> अ; ठक् -> इक। (आदिस्वरस्य वृद्धिः भवति)।
    *   **उदाहरणानि:**
        *   वसुदेव + अण् = वासुदेवः (वसुदेवस्य अपत्यम्)
        *   मनु + अण् = मानवः (मनोः अपत्यम्)
        *   धर्म + ठक् = धार्मिकः (धर्मेण सम्बद्धः)
        *   नगर + ठक् = नागरिकः (नगरे भवः)

*   **त्व (tva), तल् (tal):**
    *   **अर्थः:** भाववाचकसंज्ञा (state of being, -ness, -hood)।
    *   **अवशिष्टः अंशः:** त्व -> त्वम्; तल् -> ता।
    *   **रूपम्:** त्व-अन्ताः नपुंसकलिङ्गे; तल्-अन्ताः स्त्रीलिङ्गे।
    *   **उदाहरणानि:**
        *   गुरु + त्व = गुरुत्वम्
        *   गुरु + तल् = गुरुता
        *   महत् + त्व = महत्त्वम्
        *   महत् + तल् = महत्ता

*   **तसिल् (tasil):**
    *   **अर्थः:** पञ्चमी विभक्तेः अर्थे (से)।
    *   **अवशिष्टः अंशः:** तस्।
    *   **रूपम्:** अव्ययम्।
    *   **उदाहरणानि:**
        *   ग्राम + तसिल् = ग्रामतः (ग्रामतः आगच्छति।)
        *   वृक्ष + तसिल् = वृक्षतः (वृक्षतः फलानि पतन्ति।)
        *   कुत्र + तसिल् = कुतः (भवान् कुतः आगतः?)

**३. स्त्री-प्रत्ययाः (Strī Pratyayas):**

*   **टाप् (ṭāp):**
    *   **अर्थः:** स्त्रीलिङ्गरूपनिर्माणम्।
    *   **अवशिष्टः अंशः:** आ।
    *   **नियमाः:** प्रायः अकारान्त-पुंलिङ्गशब्देभ्यः। यदि अन्ते 'अक' अस्ति, तर्हि 'इक' भूत्वा 'आ' युज्यते।
    *   **उदाहरणानि:**
        *   अज + टाप् = अजा
        *   बालक + टाप् = बालिका
        *   शिक्षक + टाप् = शिक्षिका

*   **ङीप् (ṅīp), ङीष् (ṅīṣ), ङीन् (ṅīn):**
    *   **अर्थः:** स्त्रीलिङ्गरूपनिर्माणम्।
    *   **अवशिष्टः अंशः:** ई।
    *   **नियमाः:** ऋकारान्त (कर्तृ -> कर्त्री), नकारान्त (गुणिन् -> गुणिनी), शतृ-प्रत्ययान्त (गच्छन् -> गच्छन्ती), केचन अकारान्त (देव -> देवी, नद -> नदी), जातिवाचक (गोप -> गोपी), द्विगुसमास (त्रिलोक -> त्रिलोकी) इत्यादिषु शब्देषु।
    *   **उदाहरणानि:**
        *   कर्तृ + ङीप् = कर्त्री
        *   नद + ङीप् = नदी
        *   गच्छत् + ङीप् = गच्छन्ती
        *   इन्द्र + ङीष् = इन्द्राणी (पत्यर्थे)

## 🧩 सक्रिय-अधिगमः (Active Learning)

*   **क्रियाकलापः (Activity) 🔍:** पाठ्यपुस्तकात् अथवा अन्यसंस्कृतग्रन्थेभ्यः (यथा - पञ्चतन्त्रकथाः, हितोपदेशः) विविधप्रत्ययान्तशब्दान् (कृत्, तद्धित, स्त्री) अन्विष्य तेषां प्रकृति-प्रत्यय-विभागं लिखत। नूतनानि वाक्यानि रचयित्वा तेषु एतेषां शब्दानां प्रयोगं कुरुत।
    *   *उदाहरणम्:* 'पठित्वा' इति शब्दं दृष्ट्वा लिखत - पठ् + क्त्वा। वाक्यम् - बालकः पठित्वा क्रीडति।
*   **चर्चा (Discussion) 🌍:** प्रत्यययोगेन शब्दानाम् अर्थः कथं परिवर्तते? वाक्येषु कर्तृ-कर्म-क्रियापदानां सम्बन्धः प्रत्ययान्तशब्दैः कथं प्रभावितः भवति? (यथा - क्त/क्तवतु प्रत्यययोः प्रयोगेण वाक्यस्य वाच्यपरिवर्तनम्)। शतृ/शानच् प्रत्यययोः प्रयोगेण वाक्यस्य सौन्दर्यं कथं वर्धते? एतेषां विषयेषु चर्चां कुरुत।

## 🌏 भारतीयसन्दर्भः (Bharatiya Context) 📊

संस्कृतभाषायां प्रत्ययानां स्थानम् अत्यन्तं महत्त्वपूर्णम् अस्ति। एतेषां प्रत्ययानां साहाय्येन एव अल्पीयसां धातूनां, प्रातिपदिकानां च आधारेण विपुलः शब्दभण्डारः निर्मितः भवति। अनेन भाषायां सूक्ष्मार्थभेदान् प्रकटयितुं सामर्थ्यम् आयाति।

*   **ज्ञानपरम्परा:** 'ज्ञा' धातोः क्त्वा-प्रत्ययेन 'ज्ञात्वा', क्तिन्-प्रत्ययेन 'ज्ञप्तिः', ल्युट्-प्रत्ययेन 'ज्ञानम्', तृच्-प्रत्ययेन 'ज्ञाता' इत्यादयः अनेके शब्दाः निर्मिताः, ये भारतीयज्ञानपरम्परायां (दर्शनेषु, शास्त्रेषु) प्रयुक्ताः सन्ति।
*   **सामाजिक-सांस्कृतिक-शब्दाः:** 'वसुदेव + अण् = वासुदेवः', 'मनु + अण् = मानवः', 'कुरु + अण् = कौरवः', 'यदु + अण् = यादवः' इत्यादयः तद्धितप्रत्ययान्ताः शब्दाः भारतीय-इतिहास-पुराण-समाज-व्यवस्थायाः बोधकाः सन्ति। 'देव + ङीप् = देवी', 'इन्द्र + ङीष् = इन्द्राणी' इत्यादयः स्त्रीप्रत्ययान्ताः शब्दाः सांस्कृतिकमान्यताः दर्शयन्ति।
*   **कर्तव्यबोधः:** 'कृ + तव्यत् = कर्तव्यम्', 'रक्ष् + अनीयर् = रक्षणीयम्' इत्यादयः शब्दाः भारतीयसंस्कृतौ धर्मस्य, नैतिकतायाः, कर्तव्यस्य च बोधं दृढीकुर्वन्ति।

अतः, प्रत्ययानाम् अध्ययनं न केवलं व्याकरणज्ञानार्थम् आवश्यकम्, अपितु संस्कृतवाङ्मयस्य, भारतीयसंस्कृतेः च अवगमनाय अपि अनिवार्यम् अस्ति। एते भाषायाः संरचनात्मक-सौन्दर्यस्य आधारस्तम्भाः सन्ति।
