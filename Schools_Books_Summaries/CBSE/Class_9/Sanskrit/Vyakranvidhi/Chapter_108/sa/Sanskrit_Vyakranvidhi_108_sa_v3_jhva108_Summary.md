## 📘 प्रमुख-शिक्षण-बिन्दवः (Key Learnings)

**प्रत्ययानां विस्तृतविवरणम् उदाहरणैः सह 📈**

**१. कृत्-प्रत्ययाः:** एते धातुभिः सह युज्यन्ते।

*   **क्त्वा (त्वा), ल्यप् (य):** पूर्वकालिकक्रियाम् (prior action) बोधयतः। उपसर्गयुक्तेषु धातुषु 'ल्यप्' (य), अन्यत्र 'क्त्वा' (त्वा) प्रयुज्यते। एतौ अव्यये भवतः।
    *   *यथा:* पठ् + क्त्वा = पठित्वा (पढकर); प्र + नम् + ल्यप् = प्रणम्य (प्रणाम करके)।

    | प्रत्ययः | उपसर्गः? | अर्थः             | उदाहरणम्           | रूपम्   |
    |----------|----------|-------------------|--------------------|--------|
    | क्त्वा    | न        | पूर्वकालिकक्रिया   | गम्+क्त्वा = गत्वा   | अव्ययम् |
    | ल्यप्     | आम्      | पूर्वकालिकक्रिया   | आ+गम्+ल्यप् = आगम्य | अव्ययम् |

*   **तुमुन् (तुम्):** 'कृते' (for the purpose of) इति अर्थे प्रयुज्यते। यदा एका क्रिया अपरस्याः क्रियायाः प्रयोजनं भवति। अयमपि अव्ययः।
    *   *यथा:* पठ् + तुमुन् = पठितुम् (पढने के लिए); सः पठितुं विद्यालयं गच्छति।

*   **शतृ (अत्), शानच् (आन/मान):** वर्तमानकालिकीं क्रियाम् ('करता हुआ') दर्शयतः। परस्मैपदीधातुभिः 'शतृ', आत्मनेपदीधातुभिः 'शानच्' युज्यते। एतौ विशेषणरूपेण प्रयुज्यते, त्रिषु लिङ्गेषु रूपाणि चलन्ति।
    *   *यथा:* पठ् + शतृ = पठन् (पुं.), पठन्ती (स्त्री.), पठत् (नपुं.); सेव् + शानच् = सेवमानः (पुं.), सेवमाना (स्त्री.), सेवमानम् (नपुं.)।

*   **क्त (त), क्तवतु (तवत्):** भूतकालिकक्रियार्थे (past action) प्रयुज्यते। 'क्त'-प्रत्ययः प्रायः कर्मणि भावे वा, 'क्तवतु'-प्रत्ययः कर्तरि प्रयुज्यते। एतौ अपि विशेषणरूपेण कार्यं कुरुतः।
    *   *यथा:* गम् + क्त = गतः, गता, गतम् (कर्मणि/कर्तरि); गम् + क्तवतु = गतवान्, गतवती, गतवत् (कर्तरि)।
    *   *वाक्यप्रयोगः:* रामेण ग्रन्थः पठितः (क्त, कर्मणि); रामः ग्रन्थं पठितवान् (क्तवतु, कर्तरि)।

*   **तव्यत् (तव्य), अनीयर् (अनीय), यत् (य), ण्यत् (य), क्यप् (य):** 'योग्य' अथवा 'चाहिए' (potential passive participle) इति अर्थे भवन्ति। प्रायः कर्मणि भावे वा प्रयुज्यन्ते। कर्ता तृतीयान्तः, कर्म प्रथमान्तं भवति। क्रिया कर्मानुसारिणी।
    *   *यथा:* मया ग्रन्थः पठितव्यः/पठनीयः/पाठ्यः (पठ्+तव्यत्/अनीयर्/ण्यत्)। अस्माभिः सत्यं वदितव्यम्/वदनीयम्।

*   **तृच् (तृ), ण्वुल् (अक):** कर्तृवाचकसंज्ञां (agent noun) रचयतः।
    *   *यथा:* कृ + तृच् = कर्तृ (कर्ता); नी + तृच् = नेतृ (नेता); पठ् + ण्वुल् = पाठकः; गै + ण्वुल् = गायकः।

*   **क्तिन् (ति), ल्युट् (अन):** भाववाचकसंज्ञां (abstract noun) रचयतः। क्तिन्-प्रत्ययान्ताः शब्दाः नित्यं स्त्रीलिङ्गाः, ल्युट्-प्रत्ययान्ताः प्रायः नपुंसकलिङ्गाः भवन्ति।
    *   *यथा:* कृ + क्तिन् = कृतिः; गम् + क्तिन् = गतिः; पठ् + ल्युट् = पठनम्; लिख् + ल्युट् = लेखनम्।

**२. तद्धित-प्रत्ययाः:** एते संज्ञा-सर्वनाम-विशेषणादि-प्रातिपदिकेभ्यः परं युज्यन्ते।

*   **मतुप् (मत्), वतुप् (वत्), इनि (इन्):** 'अस्य अस्ति' अथवा 'अनेन युक्तः' (possessing) इति अर्थे।
    *   *यथा:* बुद्धि + मतुप् = बुद्धिमान्; धन + वतुप् = धनवान्; गुण + इनि = गुणी।

*   **तरप् (तर), तमप् (तम):** द्वयोः मध्ये एकस्य आधिक्यं बोधयितुं 'तरप्', बहूनां मध्ये एकस्य आधिक्यं बोधयितुं 'तमप्' प्रयुज्यते (comparative/superlative)।
    *   *यथा:* लघु + तरप् = लघुतरः; श्रेष्ठ + तमप् = श्रेष्ठतमः। रामः मोहनात् पटुतरः। छात्रेषु रमेशः पटुतमः।

*   **मयट् (मय):** 'प्रचुरता' (fullness) अथवा 'विकारः' (made of) इति अर्थे।
    *   *यथा:* आनन्द + मयट् = आनन्दमयः; सुवर्ण + मयट् = सुवर्णमयः (स्वर्णनिर्मितः)।

*   **अण् (अ):** अपत्यम् (descendant) अथवा भावः (abstract quality) इति अर्थे। आदिवृद्धिः भवति।
    *   *यथा:* वसुदेव + अण् = वासुदेवः (वसुदेवस्य अपत्यम्); कुरु + अण् = कौरवः; गुरु + अण् = गौरवम् (भावः)।

*   **ठक् (इक):** 'सम्बन्धः', 'भावः' इत्यादिषु अर्थेषु। आदिवृद्धिः भवति।
    *   *यथा:* धर्म + ठक् = धार्मिकः; नगर + ठक् = नागरिकः; शरीर + ठक् = शारीरिकम्।

*   **त्व, तल् (ता):** भाववाचकसंज्ञां (abstract noun) रचयतः। 'त्व'-प्रत्ययान्ताः नपुंसकलिङ्गाः, 'तल्'-प्रत्ययान्ताः स्त्रीलिङ्गाः भवन्ति।
    *   *यथा:* महत् + त्व = महत्त्वम्; महत् + तल् = महत्ता; मित्र + त्व = मित्रत्वम्; मित्र + तल् = मित्रता।

*   **तसिल् (तः):** पञ्चमीविभक्तेः अर्थे (ablative sense) प्रयुज्यते। अनेन निर्मिताः शब्दाः अव्ययाः भवन्ति।
    *   *यथा:* ग्राम + तसिल् = ग्रामतः (ग्रामात्); वृक्ष + तसिल् = वृक्षतः (वृक्षात्); तद् + तसिल् = ततः (तस्मात्)।

**३. स्त्री-प्रत्ययाः:** पुंलिङ्गशब्देभ्यः स्त्रीलिङ्गशब्दान् रचयितुं प्रयुज्यन्ते।

*   **टाप् (आ):** अकारान्तपुंलिङ्गशब्देभ्यः स्त्रीलिङ्गे 'आ' युज्यते। यदि अन्ते 'अक' भवति तर्हि 'इक' भूत्वा 'आ' (इका) युज्यते।
    *   *यथा:* अज + टाप् = अजा; सरल + टाप् = सरला; बालक + टाप् = बालिका; शिक्षक + टाप् = शिक्षिका।

*   **ङीप् (ई):** ऋकारान्तेभ्यः, नकारान्तेभ्यः, शतृ-प्रत्ययान्तेभ्यः, मतुप्/वतुप्-अन्तेभ्यः च शब्देभ्यः स्त्रीलिङ्गे 'ई' युज्यते। केभ्यश्चित् अकारान्तेभ्यः अपि 'ई' भवति।
    *   *यथा:* कर्तृ + ङीप् = कर्त्री; गुणिन् + ङीप् = गुणिनी; पठत् + ङीप् = पठन्ती; श्रीमत् + ङीप् = श्रीमती; नदी, देवी, कुमारी।

*   **ङीष् (ई):** इन्द्रादिभ्यः शब्देभ्यः 'जाया' (wife) अर्थे 'ई' (आनुक् आगमः च) भवति।
    *   *यथा:* इन्द्र + ङीष् = इन्द्राणी; भव + ङीष् = भवानी; आचार्य + ङीष् = आचार्याणी (आचार्यस्य पत्नी)।

*   **ति:** युवन् शब्दात् स्त्रीलिङ्गे 'ति' प्रत्ययः भवति।
    *   *यथा:* युवन् + ति = युवतिः।
