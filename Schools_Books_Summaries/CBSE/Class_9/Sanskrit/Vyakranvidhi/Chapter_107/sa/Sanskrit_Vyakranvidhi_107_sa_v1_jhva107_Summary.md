# Class 9 Sanskrit - Vyakranvidhi Chapter 107
**Language:** संस्कृतम्

```markdown
# [कक्षा ९] व्याकरणविधिः - अध्यायः ७ (अव्ययपदानि)

## 🌟 मूलसंकल्पनाः (Core Concepts)

**अव्ययस्य परिभाषा:**
ये शब्दाः त्रिषु लिङ्गेषु (पुंल्लिङ्गे, स्त्रीलिङ्गे, नपुंसकलिङ्गे च), सर्वासु विभक्तिषु (प्रथमातः सप्तमीपर्यन्तम्), त्रिषु वचनेषु (एकवचने, द्विवचने, बहुवचने च) च सर्वदा एकरूपाः एव तिष्ठन्ति, ते **अव्ययपदानि** कथ्यन्ते। तेषु कदापि कोऽपि रूपभेदः (परिवर्तनम्) न भवति।

**श्लोकेन स्पष्टीकरणम्:**
*सदृशं त्रिषु लिङ्गेषु, सर्वासु च विभक्तिषु।*
*वचनेषु च सर्वेषु, यन्न व्येति तदव्ययम्॥*
**अर्थः** - यत् पदं त्रिषु लिङ्गेषु, सर्वासु विभक्तिषु, सर्वेषु वचनेषु च समानम् एव भवति, यस्मिन् कोऽपि व्ययः (विकारः/परिवर्तनम्) न भवति, तत् पदम् अव्ययम् इति कथ्यते।

**📊 अव्ययानां सामान्यवर्गीकरणम् (उदाहरणार्थम्):**
अव्ययानि कार्यस्य/अर्थस्य आधारेण विभिन्नेषु वर्गेषु द्रष्टुं शक्यन्ते:
*   **कालवाचकानि:** (समयबोधकानि) - अद्य (आज), श्वः (आने वाला कल), ह्यः (बीता हुआ कल), इदानीम्/अधुना/सम्प्रति (अब), यदा (जब), तदा (तब), सदा/सर्वदा (हमेशा), प्रातः (सुबह), सायम् (शाम), पुरा (पहले), कदा (कब), अचिरम् (शीघ्र) ।
*   **स्थानवाचकानि:** (स्थानबोधकानि) - अत्र (यहाँ), तत्र (वहाँ), कुत्र (कहाँ), सर्वत्र (सब जगह), अन्यत्र (दूसरी जगह), इतस्ततः (इधर-उधर), उभयतः (दोनों ओर), परितः (चारों ओर), बहिः (बाहर), पुरतः (सामने), अधः (नीचे), उपरि (ऊपर)।
*   **रीतिवाचकानि:** (क्रियायाः विधिं बोधयन्ति) - शनैः (धीरे), उच्चैः (जोर से), सहसा (अचानक), कथम् (कैसे), यथा (जैसे), तथा (वैसे), एवम् (इस प्रकार), वृथा (व्यर्थ), तूष्णीम् (चुपचाप), ईषत् (थोड़ा)।
*   **प्रश्नवाचकानि:** (प्रश्नार्थकानि) - किम् (क्या), कुतः (कहाँ से), कदा (कब), कथम् (कैसे), किमर्थम् (किसलिए)।
*   **समुच्चयबोधकानि:** (पदानि वाक्यानि वा योजयन्ति) - च (और), अपि (भी), वा/अथवा (या), तु (तो), किन्तु/परन्तु (लेकिन)।
*   **निषेधार्थकानि:** (निषेधं सूचयन्ति) - न (नहीं), मा (मत), अलम् (पर्याप्त/मत करो - तृतीया/चतुर्थी योगे)।
*   **निश्चयबोधकानि/अवधारणार्थकानि:** - एव (ही), खलु/नूनम् (निश्चय ही), आम् (हाँ), बाढम् (हाँ, ठीक)।
*   **मनोविकारसूचकानि:** (विस्मयादिबोधकानि) - अहो, हन्त, धिक् इत्यादि (पाठ्ये न सन्ति, सामान्यज्ञानार्थम्)।

## 📘 मुख्य-अधिगमबिन्दवः (Key Learnings)

**१. अव्ययानाम् अपरिवर्तनीयस्वरूपम्:**
अव्ययपदानि वाक्येषु प्रयुक्तानि सन्ति कदापि स्वस्य रूपं न परिवर्तयन्ति। कर्ता, कर्म, क्रिया वा यस्मिन् अपि लिङ्गे, वचने, पुरुषे स्यात्, अव्ययपदं तथैव तिष्ठति।
*   यथा - बालकः **अत्र** क्रीडति। बालिका **अत्र** क्रीडति। बालकाः **अत्र** क्रीडन्ति।

**२. प्रमुखाः अव्ययाः तेषाम् अर्थाः च:**
अस्मिन् पाठे अनेकेषां प्रमुखाणाम् अव्ययानां परिचयः तेषाम् अर्थाः च दत्ताः सन्ति। केचन प्रमुखाः अव्ययाः अर्थैः सह अधः प्रदत्ताः:
*   `अद्य` - आज (Today)
*   `श्वः` - आने वाला कल (Tomorrow)
*   `ह्यः` - बीता हुआ कल (Yesterday)
*   `अत्र / तत्र / कुत्र` - यहाँ / वहाँ / कहाँ (Here / There / Where)
*   `यदा / तदा` - जब / तब (When / Then)
*   `यथा / तथा` - जैसे / वैसे (As / So)
*   `यावत् / तावत्` - जब तक / तब तक (As long as / Till then)
*   `शनैः / शीघ्रम्` - धीरे / जल्दी (Slowly / Quickly)
*   `उच्चैः / नीचैः` - जोर से / नीचे (Loudly / Down)
*   `च / अपि / एव` - और / भी / ही (And / Also / Only)
*   `विना` - बिना (Without) (योगे द्वितीया/तृतीया/पञ्चमी)
*   `सह` - साथ (With) (योगे तृतीया)
*   `नमः` - नमस्कार (Salutation) (योगे चतुर्थी)
*   `बहिः` - बाहर (Outside) (योगे पञ्चमी)
*   `परितः / अभितः` - चारों ओर / दोनों ओर (Around / On both sides) (योगे द्वितीया)
*   `पुरा` - प्राचीन काल में (In ancient times)
*   `इदानीम् / अधुना / सम्प्रति` - इस समय, अब (Now)
*   `वृथा` - व्यर्थ (Uselessly)
*   `सहसा` - अचानक (Suddenly)
*   `यदि / तर्हि` - अगर / तो (If / Then)
*   `यद्यपि / तथापि` - हालाँकि / फिर भी (Although / Still)

**३. वाक्येषु अव्ययानां प्रयोगः (उदाहरणानि):**
*   कच्छपः **शनैः शनैः** चलति। (कछुआ धीरे-धीरे चलता है।)
*   अहं **श्वः** वाराणसीं गमिष्यामि। (मैं कल वाराणसी जाऊँगा।)
*   **सहसा** निर्णयः न करणीयः। (अचानक निर्णय नहीं करना चाहिए।)
*   **यत्र-यत्र** धूमः, **तत्र-तत्र** अग्निः। (जहाँ-जहाँ धुआँ है, वहाँ-वहाँ आग है।)
*   **पुरा** अशोकः नाम राजा आसीत्। (प्राचीन काल में अशोक नाम का राजा था।)
*   परिश्रमं कुरु, **अन्यथा** अनुत्तीर्णः भविष्यसि। (परिश्रम करो, नहीं तो फेल हो जाओगे।)
*   **अलम्** विवादेन। (झगड़ा मत करो।) (तृतीया योगे)

**📈 ४. युग्म-अव्ययानां प्रयोगे विशेषध्यानम्:**
केचन अव्ययाः प्रायः युग्मरूपेण (जोड़े में) एव प्रयुज्यन्ते। वाक्यस्य पूर्णार्थाय एतेषां युग्मानां प्रयोगः आवश्यकः भवति।
*   `यदि` ... `तर्हि` (यदि वर्षति तर्हि मयूराः नृत्यन्ति।)
*   `यद्यपि` ... `तथापि` (यद्यपि सः रुग्णः अस्ति तथापि विद्यालयं गच्छति।)
*   `यावत्` ... `तावत्` (यावत् परीक्षा न आगच्छति तावत् पठ।)
*   `यथा` ... `तथा` (यथा राजा तथा प्रजा।)
*   `यत्र` ... `तत्र` (यत्र नार्यः पूज्यन्ते तत्र देवताः रमन्ते।)
*   `यदा` ... `तदा` (यदा सूर्योदयः भवति तदा कमलानि विकसन्ति।)

## 🧩 सक्रिय-अधिगमः (Active Learning)

**१. गतिविधिः - वाक्यरचनाभ्यासः 🔍**
अधः दत्तैः अव्ययपदैः सार्थकवाक्यानि रचयत। स्वस्य दैनिकजीवनस्य अनुभवान् वा कल्पितस्थितीः वा आधृत्य वाक्यानि लिखत।
*   (क) `सर्वत्र`
*   (ख) `विना`
*   (ग) `शनैः`
*   (घ) `पुरा`
*   (ङ) `यदि...तर्हि`

**२. चर्चा - अव्ययप्रयोगस्य महत्त्वम् 🌍**

*   "यदि वयं युग्म-अव्ययानां प्रयोगं सम्यक् न कुर्मः तर्हि वाक्यस्य अर्थे का हानिः भवितुम् अर्हति?"

## 🌏 भारतीय-सन्दर्भः (Bharatiya Context)

अव्ययपदानि भारतीयसंस्कृतेः, इतिहासस्य, भूगोलस्य च सन्दर्भे अपि सहजतया प्रयोक्तुं शक्यन्ते। एतेन भाषाधिगमः रोचकः प्रासङ्गिकश्च भवति।

**📊 उदाहरणानि:**
1.  **ऐतिहासिकम्:** `पुरा` भारते अनेके प्रतापी राजानः अभवन्, यथा चन्द्रगुप्तमौर्यः, अशोकः च।
2.  **सांस्कृतिकम्:** भारतस्य अनेकेषु भागेषु जनाः `अद्यापि` पारम्परिकान् उत्सवान् सोत्साहं मानयन्ति। दीपावल्यां जनाः `सर्वत्र` दीपान् प्रज्वालयन्ति।
3.  **भौगोलिकम्:** हिमालयः भारतस्य उत्तरस्यां दिशि स्थितः अस्ति। तत्र `उच्चैः` शिखराणि सन्ति। गङ्गा नदी `अत्र` पूजनीया मन्यते।
4.  **सामाजिकम्/आर्थिकम् (सामान्यम्):** `अधुना` भारतदेशः विज्ञान-तन्त्रज्ञानक्षेत्रे प्रगतिं कुर्वन् अस्ति। देशस्य अर्थव्यवस्था `शनैः शनैः` वर्धते इति श्रूयते। (`शनैः शनैः` इति अव्ययस्य प्रयोगः आर्थिकवृद्धेः गतिं वर्णयितुं शक्यते।)
5.  **साहित्यिकम्:** रामायणं महाभारतं च `अतीव` प्राचीने ग्रन्थे स्तः। `अथ` रामायणकथा श्रूयताम्।

एतेषां प्रयोगाणां माध्यमेन वयं पश्यामः यत् अव्ययानि न केवलं व्याकरणस्य भागाः सन्ति, अपितु ते अस्माकं विचाराणां भावनानां च अभिव्यक्तौ महत्त्वपूर्णं स्थानं धरन्ति।
```
